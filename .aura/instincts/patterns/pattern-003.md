# DePIN（去中心化物理基础设施网络）

## 一句话定义
DePIN = Decentralized Physical Infrastructure Networks。用区块链代币激励，以去中心化方式连接物理硬件（GPU、传感器、存储、网络）的网络。本质是一种新的「共享经济」——贡献越多，收益越多。

## 核心原理

### WHAT-WHY-HOW 框架
- **What**：识别项目的核心业务（共享算力？共享存储？共享数据？）
- **Why**：为什么需要去中心化？（成本更低？抗审查？无需许可接入？）
- **How**：代币激励 + 物理硬件 + 智能合约协调

### 与 AI 的关系
本轮周期 DePIN 围绕 AI 三要素展开：
- **算力**（Compute）：io.net, Aethir, Heurist, Render, Akash
- **数据**（Data）：Helium, Hivemapper
- **算法**（Algorithms）：Bittensor

其中算力类项目最受关注——AI 训练和推理的 GPU 需求爆发，去中心化 GPU 网络是降低成本的自然方案。

## 主要赛道

| 赛道 | 代表项目 | 说明 |
|------|---------|------|
| 去中心化算力 | io.net, Aethir, Render, Akash | 聚合闲置 GPU 用于 AI 训练/推理 |
| 去中心化存储 | Filecoin, Arweave, Storj | 替代 AWS S3 |
| 去中心化网络 | Helium, Pollen Mobile | 替代电信基站 |
| 去中心化数据 | Hivemapper, DIMO | 众包地图和车辆数据 |

## 为什么重要

1. **AI 算力需求爆发**：GPU 供不应求，去中心化算力网络提供弹性供给
2. **成本优势**：闲置算力的边际成本远低于 AWS/Google Cloud
3. **抗审查**：无需许可接入算力，AI 开发者不被云厂商封禁
4. **资本关注**：io.net、Aethir 等明星项目巨额融资

## 相关概念
- [[ai-crypto]] — DePIN 是 AI+Crypto 的重要子集，尤其是算力方向
- [[rwa]] — DePIN 是"物理世界资产"上链的另一种范式

## 我的立场
DePIN 是 Crypto 少有的"真实需求"赛道——GPU 算力确实紧缺，去中心化确实有成本优势。但挑战在于：闲置算力的可靠性和标准化不如 AWS，企业客户切换动力不足。核心问题是代币激励能否持续覆盖硬件提供者的运维成本。
