# Web 3.0

## 一句话定义
基于区块链技术的去中心化互联网范式，核心主张是"用户创造、用户所有、用户控制、协议分配"——与 Web 2.0 "用户创造、平台所有、平台控制、平台分配"形成根本对立。

## 核心原理
Web 3.0 通过区块链的共识引擎和密码学协议，实现"无须信任的交互系统"（trustless interaction）。数据不再存储在单一公司的中心化服务器上，而是根据内容寻址、分散存储在多个节点。用户通过私钥掌握对自己数据和资产的控制权，无需通过中间机构授权即可进行价值转移。

Web3 Foundation 将其技术栈定义为 L0-L4 五层架构：
- **L0**：基础设施和网络层（P2P 覆盖协议、平台中立计算描述语言如 EVM/Wasm）
- **L1**：协议层（数据分发如 IPFS、零/低信任交互如 Polkadot/Bitcoin、瞬时数据消息）
- **L2**：中间件层（状态通道、Plasma、加密存储、预言机、分布式秘密管理、重型计算）
- **L3**：开发者 API 和语言层（Solidity、Vyper、Rust、ethers.js、web3.js）
- **L4**：DApp 浏览器层（MetaMask、Status、Parity、imToken）

## 为什么重要
Web 3.0 致力于解决 Web 2.0 时代的根本矛盾：用户产生的数据不属于用户，而被科技巨头垄断并以此牟利。如果 Facebook 倒闭，用户的所有社交关系、发布内容也随之消失。Web 3.0 试图通过去中心化的技术架构将数据所有权归还用户，将价值分配从平台转向协议和社区。

## 三代互联网范式对比

| 维度 | Web 1.0 (只读) | Web 2.0 (读写) | Web 3.0 (价值) |
|------|---------------|---------------|----------------|
| 时间 | ~1991-2004 | ~2004-至今 | 2014-萌芽 |
| 范式 | 平台创造/所有/控制/受益 | 用户创造/平台所有/控制/分配 | 用户创造/所有/控制/协议分配 |
| 代表 | 雅虎、新浪、网景 | Google、Facebook、YouTube | Ethereum、Polkadot、IPFS |
| 核心技术 | HTML/URI/HTTP | 社交网络、移动互联网 | 区块链、智能合约、密码学 |
| 数据所有权 | 平台 | 平台 | 用户 |

## 基本特性
- **去中心化**：信息根据内容寻址，同时存储在多个位置，无单一故障点
- **去信任化与无权限化**：参与者直接交互无需受信任中介，任何人都可不经授权参与
- **人工智能与机器学习**：基于语义网和自然语言处理，计算机理解信息如人类
- **连通性与无边界网络**：信息和内容无处不在，通过多个应用访问，物联网设备全面连接

## 定义的二分性
Web 3.0 存在两个不同版本的定义：
1. **Tim Berners-Lee 版（语义网）**：机器可读的集成通信框架，数据可跨越应用和系统实现语义互操作。由 W3C 和 Linked Data 社区推动。
2. **Gavin Wood 版（去中心化 Web）**：基于区块链和密码学的无须信任交互系统。由 Crypto 社区推动，是目前主流讨论的 Web 3.0。
3. **Alex Danco 版（实用主义定义）**：web3 "只是一个环境，围绕一套新标准建立共识：一切都是智能合约地址，一切都是 tokenID，一切都是钱包地址。" 这些区块链工件作为中间"文件"重新出现，使可互操作、可组合的社交机制具有竞争力。来自 Shopify 区块链团队负责人的务实认知——web3 的核心不是宏大叙事，而是抽象层次降低后的新型可组合性。来源：[[来源_2022-05_代币商业_Shopify_NotBoring]]

两个版本目前融合度极低，技术哲学和组织形态几乎无交集。Alex Danco 的定义跳出了 Tim Berners-Lee 语义网和 Gavin Wood 去信任化区块链的两分法，提供了一种围绕"新标准共识"的实用主义框架。

## ⚠️ Contradiction
- 来源 1（本文）认为"Web3 在速度、效率和成本上将逐渐赶上 Web 2.0"——2026 年实际观察：以太坊 L1 TPS 仍远低于中心化支付网络，L2 碎片化增加了用户体验摩擦。速度/效率/成本的追赶进度比 2022 年预期缓慢。

## 我的立场
Web 3.0 的核心理念——用户拥有数据和资产——在方向上是正确的，但"一切去中心化"在工程上有其代价（延迟、成本、UX 摩擦）。当前更务实的路径是 Web 2.5：关键资产和身份上链，应用体验保持 Web 2.0 的流畅度。完全去中心化不是终点，而是手段。
