# 链上数据基础设施 (Onchain Data Infrastructure)

## 一句话定义
为加密市场提供链上数据索引、分析、可视化、评分和情报的中间件层，是连接原始链上数据和商业决策的管道。

## 赛道分层

### 层 1：数据索引与查询
- [[dune-analytics]] — 开创性 SQL 查询平台，社区驱动，3,000+ 数据集
- [[flipside-crypto]] — 类似 Dune，侧重 SDK 和数据 API
- [[subquery]] — 去中心化数据索引协议
- [[the-graph]] — 去中心化查询协议

### 层 2：专业分析/情报
- [[nansen]] — 链上标签 + 聪明钱追踪，$1.2 亿融资
- [[messari]] — 研究报告 + 资产数据终端
- [[glassnode]] — 链上指标 + 宏观分析
- [[coinglass]] — 合约数据 + 爆仓/持仓数据
- [[token-terminal]] — 收入/估值/P/S 指标
- [[defillama]] — TVL 聚合 + 收入/费用数据

### 层 3：通用数据入口
- [[coingecko]] — 价格 + 市值 + 交易量基础数据
- [[coinmarketcap]] — 同 CoinGecko，币安旗下
- [[debant]] — 钱包/协议持仓分析

### 层 4：专用工具
- [[nftscan]] — NFT 数据 API
- [[bitscrunch]] — NFT 反欺诈数据分析
- [[dappradar]] — DApp 排名和活跃度数据

## 关键趋势
- 从"显示数据"到"提供洞察"：Messari 200+ 员工覆盖研报 + 终端
- 数据源合并：Dune + Flipside 正向 SDK/API 服务化演进
- AI 接入数据：智能合约分析/异常检测/MEV 数据是新的增长点

- [[ai-agents]] — Agent 是链上数据的新增消费方
