# ERC-8004

## 一句话定义
ERC-8004 是 AI Agent 在以太坊上的身份、声誉和验证标准，为 AI Agent 经济提供链上信任层——相当于 AI Agent 世界的「工商局+大众点评+资质认证中心」。

## 核心原理
ERC-8004 设计极其精简，仅包含三个链上注册表：

1. **身份注册表（Identity Registry）**：每个 AI Agent 获得一个 ERC-721 NFT 作为身份标识。Agent 的 NFT 指向一个标准化的「Agent 卡片」，包含名称、技能、端点和元数据。因遵循开放标准，任何浏览器或市场都可以索引它，实现跨平台无许可发现。

2. **声誉注册表（Reputation Registry）**：客户和其他 Agent 可提交结构化反馈（按技能或任务打标签），并可附加 x402 支付证明——只有真正付过钱的客户才能评价，避免刷单。所有声誉信号都是公共品，任何人可基于这些数据构建自己的信誉评分系统。

3. **验证注册表（Validation Registry）**：对于高价值任务，Agent 可请求第三方验证——TEE（可信执行环境）预言机、质押担保推理或 zkML 验证。一个声称能做金融分析的 Agent 可以通过密码学证明它确实运行了特定模型并产生特定结果。

## ERC-8004 与 x402 的关系
- **x402 解决支付问题，ERC-8004 解决信任问题**，真正的自主 AI 经济两者缺一不可
- 类比：x402 = ERC20（支付标准），ERC-8004 = Etherscan（可查可验证的注册表）
- x402 的创建者 Erik Reppel（Coinbase）同时也是 ERC-8004 的签署方
- ERC-8004 的提出者之一、以太坊基金会 dAI 团队负责人 Davide Crapis 表示：「ERC-8004 将支持多种支付方式，但拥有 x402 扩展有助于开发者体验。」

## 工作流程示例
1. 客户 Agent 通过身份注册表找到分析师 Agent Alice，查看 NFT 身份卡片
2. Alice 有 156 个好评、89% 完成率，附带有 x402 支付证明的真实评价
3. 通过 x402 支付 100 USDC 到智能合约托管（非直接转账）
4. 第三方验证者 Bob 检查质量并在验证注册表签名确认
5. 合约自动释放资金给 Alice，客户留下评价
6. 整个过程无需人工干预，Agent 自主完成商业交易

## 关键参与方
- 2025 年 8 月 13 日：[[davide-crapis]]（以太坊基金会）、MetaMask 的 Marco De Rossi、独立 AI 开发者 Jordan Ellis（与 Google A2A 团队关系密切）联合提交 EIP-8004
- 2025 年 10 月：最终版本签署方包括 MetaMask、Google 的 Jordan Ellis 和 Coinbase 的 Erik Reppel（x402 创建者）
- 为 Google 的 Agent-to-Agent (A2A) 协议增加信任层

## 受益项目
### 基础设施层
- [[taiko]] — L2 执行层，10 月 24 日部署 ERC-8004 注册表，成为 Agent 活动潜在主战场
- [[eigenlayer]] — 安全层，验证者质押 ETH 做担保，正在将 8004 集成到 200+ AVS

### 中间件层
- S.A.N.T.A — x402 和 8004 的支付桥梁，处理跨链支付（如 Solana Agent 雇佣以太坊 Agent）
- Unibase — Agent 记忆层，10 月 26 日在 BNB 链实现 x402+8004 集成

### 应用层
- [[virtuals]] — ACP 协议更新全面支持 8004 标准，平台上发行的 Agent 自动获得链上身份和声誉系统

## 为什么重要
- ERC-8004 填补了 AI Agent 经济的信任基础设施空白：没有身份和声誉系统，Agent 间的协作只能通过盲盒式信任进行
- 作为以太坊标准，ERC-8004 具备链上原生的可组合性——任何支持 NFT 的钱包都可以查看、转让甚至交易 Agent 身份
- 结合 x402（支付）+ Google A2A（通信）+ ERC-8004（信任），构建完整的「加密 AI 经济 = 发现 AI Agent + Agent 之间交流 + 可验证的计算」叙事

## 我的判断
ERC-8004 在概念上是一个关键的基础设施标准。三注册表设计（身份+声誉+验证）覆盖了 Agent 协作所需的核心信任原语。但与所有区块链标准一样，价值捕获不在标准本身，而在标准的采用情况和围绕标准构建的应用。关键观察指标：Devconnect Trustless Agents Day（2025 年 11 月 21 日）是否出现杀手级应用、Taiko 等 L2 上的注册表实际使用量、Virtuals ACP 集成后的数据。需要警惕标准本身不一定带来代币价值的叙事误区。
