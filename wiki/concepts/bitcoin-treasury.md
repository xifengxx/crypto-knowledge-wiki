# 比特币财库 (Bitcoin Treasury)

## 一句话定义
上市公司将比特币纳入资产负债表作为财库储备资产的策略，由 MicroStrategy 在 2020 年开创。

## 核心逻辑
- **资产替代**：将现金/债券储备替换为比特币，预期 BTC 长期升值跑赢通胀和现金贬值
- **信号效应**：持币向市场传递"看好比特币未来"的信号，吸引比特币信仰者投资者
- **融资杠杆**：发行可转债/优先股 → 融资买入 BTC → BTC 上涨 → 股价上涨 → 更多融资空间

## 关键企业
- [[microstrategy]] — 开创者，持 50 万+ BTC
- [[metaplanet]] — 日本版 MicroStrategy
- [[the-blockchain-group]] — 欧洲版，100 亿欧元融资授权
- [[bit-digital]]、[[nakamoto-holdings]] — 小型跟进者
- [[nano-labs]]、[[windtree]] — BNB 财库路径

## PCV 概念延伸
比特币财库正在进化至 Protocol Controlled Value（协议控制价值）：不仅是持仓，更形成"发行债券 → 买入 BTC → BTC 升值 → 回购/分红"的飞轮。见 [[pcv]]。

## 相关概念
- [[stablecoins]] — 稳定币发行方的美债储备，与 BTC 财库形成"链上储备资产"的两极
- [[pcv]] — PCV 机制，财库模式的升级版本
