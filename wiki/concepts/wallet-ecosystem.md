# 钱包生态 (Wallet Ecosystem)

## 一句话定义
加密市场的用户入口层，从私钥管理工具进化为 DApp 浏览器 + DeFi 前端 + 身份管理的超级应用。

## 钱包类型演变

### 类型 1：浏览器扩展钱包
- [[metamask]] — 以太坊钱包鼻祖，3000 万+ MAU
- [[phantom]] — Solana 钱包领导者，集成 Swap/Staking/Blinks
- [[rabby]] — DeFi 专用，交互体验领先
- [[backpack]] — Solana 原生，交易 + NFT + 空投集成

### 类型 2：移动端钱包
- [[trust-wallet]] — 币安旗下，多链 + DApp 浏览器
- [[bitkeep]] — Bitget 旗下，多链 + Swap
- [[onekey]] — 硬件+软件一体化
- [[argent]] — StarkNet 智能钱包，社交恢复

### 类型 3：托管/机构钱包
- [[safe]] — 多签 DAO 资金管理标准
- [[fireblocks]] — 机构级 MPC 托管
- [[cobo]] — 托管 + 钱包技术一体化

## 关键趋势
- 钱包正在从"工具"进化为"入口"——内置 Swap/Staking/借贷/Blinks
- 链抽象钱包（多链统一体验）是 2025 年最大的 UX 进步
- MetaMask Snap + Phantom Blinks = 钱包从"被动保管"到"主动执行"
