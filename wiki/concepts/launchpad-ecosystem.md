# 发射平台生态 (Launchpad Ecosystem)

## 一句话定义
加密项目发行代币的一级市场渠道，从 VC 私募到 Pump.fun 的"一键发币"，发射平台正在从工具进化为链级流量引擎。

## 演变三阶段
- **阶段 1 (2020-2022)**：Balancer LBP、Miso、Fair Launch — 以 DEX 为中心的公平启动，流程复杂
- **阶段 2 (2023-2024)**：Pump.fun Bonding Curve 模式 — 一键发币 + 自动做市 + 快速毕业到 Raydium
- **阶段 3 (2025)**：多链竞争 + 垂直分化 — 每条链都有原生发射台，Meme/AI Agent/社交各有专属平台

## 关键趋势
- 发射平台正在取代 VC 成为最主要的代币发行渠道
- 毕业率极低（LaunchLab 0.84%），"发射容易，存活难"
- Meme → AI Agent → SocialFi 发射平台的分化预示了下一阶段
