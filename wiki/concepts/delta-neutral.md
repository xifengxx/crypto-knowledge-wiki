# Delta-Neutral / 收益套利

## 一句话定义
Delta中性策略是指在对某一资产同时持有多头和空头头寸，使得组合对资产价格变动的净敞口为零，在此基础上从多空两端分别获取收益（资金费率 + 现货生息）的交易方法。

## 核心原理

### Delta中性的数学基础
Delta衡量的是组合价值对标的资产价格变动的敏感度。Delta中性意味着Delta = 0——无论标的价格涨跌，组合净值不变。

最简单的构建方式：持有1 ETH现货 + 在永续合约平台做空1 ETH = Delta中性。ETH涨$1，现货赚$1，空头亏$1，净损益 = $0（忽略手续费和滑点）。

### 收益来源分解
保持Delta中性的目的不是对冲风险，而是从**两端**同时获取收益：

**空头端（永续合约）**：资金费率（Funding Rate）。永续合约通过资金费率机制使合约价格锚定现货价格。当多头需求大于空头时，多头向空头支付资金费；反之空头向多头支付。在牛市中，资金费率通常为正，做空方获得正向收益。

**多头端（现货）**：资产本身的生息方式。ETH可通过Lido质押获得~3% APY（stETH）；通过Pendle PT代币可获得更高固定收益；BTC可通过Lombad/LBTC等协议生息。

### 杠杆的作用
杠杆放大收益也放大风险：
- 2x杠杆：期货端使用50%保证金（$33K做空 $100K策略规模中的$33K名义），释放更多资本用于现货端生息
- 杠杆越高 → APY越高 → 但强平价格越近 → 价格上涨导致的强平风险越大

## 为什么重要

1. **协议化应用**：Ethena将Delta中性策略产品化为USDe稳定币，开创了"收益稳定币"品类，2025 Q2 AUM达$66亿
2. **机构策略标准化**：收益套利是交易员和基金中最受欢迎的策略之一，提供高波动调整后回报（Sharpe ratio优于纯多头）
3. **市场结构信号**：资金费率的正负和大小反映市场情绪——持续高正费率 = 市场过热/杠杆多头拥挤；转负 = 看空情绪或锁仓代币持有者的对冲行为
4. **资本效率优化**：相比纯现货持有，Delta中性策略在不承担方向性风险的前提下叠加了年化10-37%的额外收益

## 三种市场中性套利模式（JacobZhao 2025.04 框架）

### 资金费率套利（Funding Rate Arbitrage）
永续合约通过资金费率机制锚定现货价格。历史上正资金费率（多头付空头）占80%+场景，策略为买入现货+做空永续合约。Ethena将这一策略协议化，首次使零售用户低门槛参与。

### 期现套利（Cash-and-Carry Arbitrage）
利用现货与交割期货的价差（基差），在Contango（期货>现货）时买入现货+做空期货，或在Backwardation时反向操作。适合大资本投资者，需容忍仓位锁定并预期基差收敛。常见于传统金融背景交易员。

### 跨所套利（Cross-Exchange Arbitrage）
利用同一资产在不同交易所的价差构建中性头寸。主要交易所间的价差已大幅收窄，需自动交易脚本+高波动+小市值代币。操作复杂度高，不再适合散户。Hummingbot等工具可供技术用户使用。

## 关键风险

1. **资金费率转负**：市场转熊或杠杆多头平仓 → 空头方向资金费率转负 → 空头端从收入变为支出
2. **强平风险**：杠杆放大了价格波动的影响，价格上涨可能导致空头仓位被强制平仓
3. **对冲失效**：极端行情下现货和衍生品价差可能扩大，Delta中性假设被打破
4. **低流通量代币的特殊风险**：锁仓代币的持有者（内部人/投资者）在Perp上做空以"获利了结" → 资金费率大幅转负 → 套利策略无利可图

## 我的立场
Delta中性策略的逻辑是优雅的，但名字有误导性——"中性"指的是价格敞口中性，不代表风险中性。它本质上是做多波动率、做空市场情绪的统计套利。真正的风险不在于方向，而在于资金费率的结构性转变（牛市→熊市）以及低流通量代币市场中信息不对称带来的费率扭曲。理解了这个策略，就能理解为什么Ethena在牛市中表现优异，而熊市中的表现尚未被验证。
