# 稳定币正在重塑传统金融体系

## 核心主张
稳定币不是加密圈内部的交易工具，而是在系统性地替代传统金融（银行、支付、资管）的下游功能。从跨境支付开始，逐步侵蚀商业银行的地盘。更深层地，稳定币正在**重构全球信用中介体系**——将存款从新兴市场银行转移到美债和美国大银行，其影响可比后 Basel III 时代银行 → NBFI 的转移。

> 当前目标：$300B（2025 年底）→ $1T（2030）AUM

## 替代机制：银行脱媒如何发生

### 证据 1：存款替代（Bank Deposit Substitution）
每 $1 稳定币 = ~$0.875 短期美债/Repo + ~$0.125 GSIB 银行存款（以 Circle 为例：$61B USDC = $53B UST/Repo + $8B 现金）。

用户将本地银行存款转为 USDC/USDT → 存款从区域/商业银行转移到美债 + 大银行（BNY Mellon 等）→ 本地银行失去存款基础 → 信用创造能力萎缩。

### 证据 2：信用创造转移
以阿根廷为例：$20k 从 BNA 银行 → USDC：
- 阿根廷 M1/M0 乘数 ~1.2x：$20k × 1.2 = $24k 本地信用创造消失
- 变为：$17,500 美债 + $8,250 美国信用创造
- 影响在 M1 的 1% 不可见，10% 时可感知 → 届时监管将被迫干预

### 证据 3：美债需求 → 非银行信贷
- 稳定币发行方 = 美债第 12 大买家，向 Top 5 迈进
- $1T 规模 → 短期美债价格不敏感的巨量买方 → 扭曲收益率曲线
- $1T 后 → 发行方被迫复制银行贷款组合（商业信贷、MBS）
- 平行于后 Basel III 银行 → NBFI 转移（Apollo/KKK/Blackstone 崛起的逻辑）

### 证据 4：链上收益前沿
Ethena 打开了链上美元收益的 Overton Window → 未来 Vault 将跟踪各种链上/链下策略 → "链上收益有效前沿" → 部分 Vault 可能向被传统银行抛弃的 EM 地区放贷，形成闭环

## 支撑证据

1. **规模证据**：年链上结算额 35 万亿美元，已超 Visa。B2B 支付 $100B+/年化，同比增长 4x

2. **效率证据**：汇款 ~0.1% vs 传统 7-8%；到账几分钟 vs 2-5 天；7×24

3. **获客成本为零**：区块链 = 后端，不需银行网点。CAC=0

4. **新兴市场渗透**：阿根廷加密 App AUM $416M = M1 的 1.1%；B2B 支付 4x 年增长

5. **正在发生的替代**：
   - 稳定币发行方 → 替代央行 + 成美债大买家（[[tether]] / [[circle]]）
   - 代币化基金 → 替代传统 MMF（[[blackrock-buidl]]，$29 亿 AUM）
   - 链上收益协议 → 替代储蓄/理财（[[ethena]] / Aave / Maker）
   - 稳定币支付公司 → 替代跨境 SWIFT（Bridge / Rain / RedotPay）

## 反对证据

1. **监管不确定性**：GENIUS 法案仍在立法中；EM 政府可能在 M1 流失 10% 时关闭兑换通道
2. **银行反击**：PayPal PYUSD、银行系代币化存款正在推出
3. **用户基数仍小**：3000 万钱包 vs 数十亿银行账户

## 待验证假设
- **假设 1**：GENIUS 法案通过 → USDC 受益最大（已验证趋势中）
- **假设 2**：EM 政府达到临界点（~M1 的 10%）时可能限制稳定币兑换
- **假设 3**：$1T 后稳定币发行方多元化到商业信贷和 MBS
- **假设 4（新）**：稳定币将以类似后 Basel III NBFI 崛起的路径，形成新的非银行信贷中介体系
