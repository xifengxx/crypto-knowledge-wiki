# Vertex Protocol

## 基本信息
- 类型：链上交叉保证金期货交易所
- 定位：融合中心限价订单簿（CLOB）和AMM模型的混合交易平台
- 部署链：Arbitrum、Mantle、Sei、Blast、Base（五条链）
- 交易对：50+个
- 附加功能：本地借贷市场、现货交易
- 代币：VRTX

## 核心业务/产品
- **永续合约交易**：交叉保证金模式，用户在五条链上均可交易
- **Vertex Edge**：内部流动性引擎，聚合所有已部署链上的流动性，提升市场深度、减少滑点
- **现货交易**：除衍生品外提供现货交易市场
- **借贷市场**：本地借贷功能，用户可将资产用于期货交易的保证金
- **VRTX Vertical Program**：代币经济模型升级——降低VRTX发行量、增加做市商激励、自动复利质押奖励。新质押者可立即获得最高质押回报率（来自VRTX发行量 + 交易费用 + 提前解锁者忠诚奖励），质押APY通常在20-30%之间

## 技术架构（混合 CLOB-AMM）

Vertex 的混合设计核心组件包括：

- **链上 CPAMM（Constant Product AMM）**：使用 xy=k 公式，位于协议层作为默认状态的智能合约。"Slo-Mo Mode"运行，通过智能合约（而非 API）充当被动做市商。AMM 池流动性通过离链排序器与自动化交易者流动性合并，提供统一流动性来源。
- **离链排序器（Off-Chain Sequencer）**：CLOB 作为独立节点运行（计划通过 Vertex 治理去中心化）。HFT 友好 API，订单撮合延迟 5-15ms，吞吐量 15,000 TPS。性能可媲美 CEX 水平。
- **AMM 故障保护**：排序器宕机时自动降级——用户仍可像 Uniswap 一样与 AMM 交易，但保留交叉保证金账户和集成产品（现货/永续/借贷市场）。
- **下单与链上操作分离**：排序器处理订单撮合，但抵押品提取、账户清算、AMM 兑换等操作仍需链上风险检查。

### 混合设计优势
- AMM 确保始终有基础流动性
- 同时支持被动 LP 流动性和主动限价订单，兼顾高/低流动性资产
- 用户可选择直接链上交易（绕开排序器）
- 交易在 Arbitrum 协议层执行，Gas 费用低于以太坊 L1

### Three Sigma 安全审计
- **周期**：14 周，覆盖现货/永续市场、交叉保证金系统和风险引擎
- **发现的关键漏洞**：预言机操纵风险（强化喂价机制）、流动性池操纵（增加清算函数检查）、重入漏洞（防止未授权递归调用）

## 竞争优势
- **混合流动性模型**：CLOB + AMM结合，兼顾订单簿的定价精度和AMM的流动性保障
- **跨链流动性聚合**：Vertex Edge统一五条链的流动性池
- **CEX 级性能**：5-15ms 撮合延迟 + 15,000 TPS，HFT 友好 API
- **残障安全**：AMM 层在排序器故障时充当备份

## 关键数据
- 日均现货交易量：约 1000 万美元（Arbitrum 上前 10 DEX）
- 撮合延迟：5-15ms
- 吞吐量：15,000 TPS

## 风险 / 争议
- 多链部署带来跨链桥/互操作风险
- 离链排序器当前由 Vertex 团队运行，存在中心化风险（计划治理去中心化）
- 混合 DEX 无法完全消除滑点，大额交易仍可能因 AMM 池和订单簿的交互产生价格影响
