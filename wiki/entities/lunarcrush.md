# LunarCrush

## 基本信息
- 类型: company
- 成立时间: 2018
- 创始人: Joe Vezzani (CEO), Evan Kennedy (COO)
- 总部: 美国加州洛杉矶/Newport Beach
- 定位: Web3 社交智能分析平台，追踪并量化加密资产、股票、NFT 等标的的社交媒体活动
- 融资: Series A $500 万（2023），估值 $3000 万
- 主要投资方: Draper Round Table / Draper Associates（Tim Draper）、INCE Capital、MoonPay、EMURGO、Blockchain Founders Fund

## 核心业务/产品

LunarCrush 是一个实时社交情报平台，每小时处理 **3000-5000 万条社交帖子**，覆盖 **6+ 网络**（X/Twitter、Reddit、YouTube、TikTok、Instagram、主流新闻源），利用 AI 驱动的实体识别、情感分析和影响力加权，将社交信号转化为可交易的市场洞察。

**核心指标：**

| 指标 | 说明 |
|---|---|
| **Galaxy Score** (0-100) | 综合社交活跃度、情绪和市场动量的整体健康分，50 以上表示正向 |
| **AltRank** | 相对排名，综合社交和市场动量对所有标的排序，#1 为最强 |
| **Social Dominance** | 标的在同类话题中的社交讨论占比（%） |
| **Engagement per Mention** | 每条提及的互动深度（信号质量指标） |
| **Sentiment Score** | AI 情感分析，衡量帖子中 bullish/bearish 比例 |

**主要功能：**
- 实时社交搜索与趋势检测
- AI Companion — 交互式 AI 解释市场变动与社交趋势
- Creator Rankings — 按参与度/影响力排名关键 KOL
- 个性化 Dashboard — 可定制关注的资产、创作者和类别
- 对比工具 — 并列对比资产的社交与市场表现
- 告警系统 — 社交活动激增时推送通知
- API 访问 — 供交易机器人、AI 应用集成数据

**客户与服务：**
- 大型交易所客户: Coinbase、Kraken、HTX、Binance
- 订阅价: $30/月（个人），显著低于竞品 $1000/月
- 免费层级可用
- iOS/macOS 移动应用
- Claude Connector 集成，支持在 AI 工作流中查询实时社交数据

**最新动态（2025）：**
- 与 **OpenServ** 合作，将数据接入 Telegram 小程序和 AI Agent 工作流
- 推出 **Dash.fun** — 社交情绪驱动的实时仪表盘
- 与 **OriginTrail** 合作启动 Social Intelligence Paranet — 去中心化知识图谱，BUZ 代币激励

## 竞争优势 / 护城河
- **数据规模与广度**：每小时千万级社交帖子，覆盖 6+ 平台和多语言，非单一平台依赖
- **独家指标体系**：Galaxy Score、AltRank、Social Dominance 等专有指标已成为行业参考标准，被 TradingView 等平台集成
- **定价策略**：$30/月对个人用户极具性价比（竞品通常 $1000/月），拓宽用户覆盖面
- **头部客户背书**：Coinbase、Kraken、Binance 等顶级交易所使用其数据，形成信任壁垒
- **AI 能力**：AI Companion 和 Claude Connector 集成，将社交智能带入 LLM 时代
- **多元化扩展**：从加密扩展至股票、NFT、文化趋势，降低单一市场风险

## 风险 / 争议
- **数据源依赖风险**：核心数据依赖 Twitter/X、Reddit 等外部平台，API 策略变化或访问限制将直接影响产品质量（如 Twitter API 收费改革后影响显著）
- **Web3 原生性存疑**：非去中心化架构，属于 Web2 集中式分析平台，与 Web3 去中心化叙事不完全一致
- **竞争激烈**：社交分析赛道有 Santiment、The Tie、LunarPay 等竞品，且头部交易所可能自建同类工具
- **情绪噪音**：社交情绪数据固有的大量噪音和操纵风险（如机器人账号、拉盘喊单群）影响数据质量
- **融资规模较小**：$500 万 Series A 相对于其他加密基建项目规模偏小，可能限制研发和市场扩展速度

## 我的判断
LunarCrush 在加密社交数据分析领域建立了明确的品牌认知和产品壁垒。$30/月的定价策略在个人用户市场有竞争力，但 $500 万 Series A 规模偏小，需关注其在 AI 时代如何进一步差异化。与 LLM（Claude Connector）和 AI Agent 框架（OpenServ）的集成是正确方向——社交情绪数据 + AI 代理是 DeFAI 趋势下的重要数据层。公司如何应对 Twitter/X API 政策变化和竞品追赶将是关键变量。
