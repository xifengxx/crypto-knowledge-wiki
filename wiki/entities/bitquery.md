# Bitquery

## 基本信息
- 类型：区块链数据索引与 API 提供商
- 专注领域：链上数据查询、交易流追踪、钱包分析、代币分析
- 核心产品：Bitquery GraphQL API、实时交易流（Trade Streams）、Mempool 监控
- 官网：https://bitquery.io
- 文档：https://docs.bitquery.io

## 核心业务/产品
- **Bitquery GraphQL API**：多链统一数据查询接口，支持 Solana、Ethereum、BSC 等多条区块链
- **Pumpfun Trade Streams**：实时 Pumpfun 交易流数据 API，提供代币、价格、滑点等交易详细数据
- **链上分析博客**：定期发布区块链定量研究，涵盖 Memecoin 交易动态、MEV 攻击、Solana 生态等主题

## 关键数据
- 数据所分析的 Pumpfun 交易集：5,000 笔交易，约 11 分钟窗口，9 个代币（来源：[[来源_2025-06_滑点_Pumpfun_Bitquery]]）

## 竞争优势 / 护城河
- 多链数据覆盖能力，统一 GraphQL API 降低开发者集成成本
- 专注于 Solana 等高性能链的实时数据产品（Trade Streams），在 Memecoin 交易分析领域有差异化定位
