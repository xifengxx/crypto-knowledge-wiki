# WorldCoin

## 基本信息
- 赛道: 人类身份验证（Proof of Humanity）/ AI时代身份基础设施
- 创始人: Sam Altman（OpenAI CEO）、Alex Blania
- 主要产品: World ID（虹膜扫描身份验证）+ World App（钱包）+ WLD代币

## 核心业务
通过Orb设备进行虹膜扫描，生成唯一的World ID，证明用户是真实人类而非AI Agent。随着AI生成内容泛滥和AI Agent普及，"证明你是人类"成为一种基础设施级需求。

## Agent 身份验证布局（2025-2026）
- **品牌更名**：前身为 Worldcoin，现更名为 "World"
- **AgentKit**：2026 年 3 月发布的 Agent 工具包，与 [[x402]] 集成。核心流程：虹膜验证 → World ID → 零知识证明委托给 Agent → 服务端验证「这个 Agent 背后是一个真人」但看不到是谁
- **核心价值**：反女巫攻击——不管你跑多少钱包和 Agent，系统知道归属同一个人
- **定位**：作为四条 Agent 身份验证路径之一的生物识别路线代表

## 关键数据
- 融资: $1.15亿（Blockchain Capital领投，a16z等参投，2023年5月C轮）
- 代币: $WLD
- FDV: $2200亿（2024年11月文章数据，为加密AI赛道最高）
- 近 1800 万验证用户（2026 年 5 月数据）
- 在全球多个国家部署Orb设备进行虹膜扫描注册
- 虹膜扫描在多国遇到监管阻力

## 竞争优势/护城河
- Sam Altman的AI行业背书和资源网络
- 先发优势：唯一大规模部署的生物特征身份验证网络
- 虹膜扫描的技术门槛和硬件部署壁垒
- 随着AI Agent数量爆炸式增长，"人类证明"的需求确定性增强

## 风险/争议
- 隐私争议：生物特征数据的收集、存储和使用引发全球监管关注
- 多国监管调查：肯尼亚、德国、法国等多国对其数据收集行为展开调查
- 代币经济学争议：FDV极高但流通量极低，存在通胀压力
- 中心化风险：Orb硬件和虹膜数据库高度中心化
