# Zerebro（ZerePy 框架）

## 基本信息
- 类型：AI Agent 框架 + 创意 AI 内容平台
- 代币：$ZEREBRO
- 框架名：ZerePy（Python 编写）
- 定位：聚焦创意内容生成（社交媒体/NFT/音乐/数字艺术）的 AI Agent 框架
- 背景：ZerePy 源自模块化版本的 Zerebro 后端

## 核心业务/产品
- **ZerePy 框架**：开源 Python 框架，支持在 X（Twitter）上部署 AI Agent，集成 OpenAI/Anthropic LLM
- **核心功能**：命令行界面管理 Agent、X 平台集成（发布/回复/点赞/转发）、模块化连接系统
- **用例覆盖**：社交媒体自动化、音乐/Meme/NFT 内容创作、数字艺术和区块链内容平台
- **Zentients Launchpad**：Agent 发行平台（规划中）
- **ZerebroSOL**：与 [[sanctum]] 合作推出的 Solana 流动性质押代币

## 训练数据策略（"自由化 AI"）
Zerebro 的差异化在于使用非传统数据集微调 LLM，以"解锁"被企业安全对齐限制的创造力：
- Truth Terminal 对话记录
- 模拟精神分裂症的对话数据
- Z 世代俚语
- Reddit、4chan、Twitter 等平台的互联网文化内容
- 加密货币 KOL 见解和去中心化系统知识
- ⚠️ 上述训练数据描述来自赞助内容（Blockworks 未独立验证），方法论细节可能被夸大

- **AI 模型发展**：旗舰协作模型 + 具类人个性和幽默感的智能体模型
- **ZerePy 框架**：已发布的开源 Python Agent 部署框架

## 竞争优势 / 护城河
- Python 语言对 AI/ML 开发者零门槛，可吸引大量 Python 生态开发者
- 与 ai16z（Eliza）的合作产生协同效应，Eliza 贡献者正向 ZerePy 迁移
- 创意 AI 赛道差异化定位——四大框架中唯一专注数字艺术和内容创作
- 社区狂热程度高，市值（$4.24 亿）在市占率仅 5% 的情况下已超越 Rig

## 风险 / 争议
- 应用范围最窄——创意内容领域之外几乎不适用
- 需要模型微调才能产生创造性产出，开箱即用能力有限
- GitHub 星星仅 181（四框架中最低），开发者生态极早期
- 市值（$4.24 亿）与市占率（5%）之间的巨大差距引发估值泡沫担忧
- 框架功能相对单一（主要是社交平台 Agent 部署），缺乏多模态或游戏等扩展能力
- ⚠️ 项目官方信息主要来自赞助内容（Blockworks 未独立验证），"自主发币/出专辑/做 NFT"等成果可能被包装夸大
