# Fetch.ai (FET)

## 基本信息
- 赛道: Web3+AI 基础设施 / AI Agent 平台
- 代币: FET（总供应量 11.52 亿，流通 10.43 亿，Binance 上市）
- 成立时间: 2018 年
- 市值（2023.12）: 约 5.34 亿美元

## 核心业务
基于区块链的机器学习平台，让传统产品通过 FET 代币接入 AI 能力，无需改变底层业务应用。核心产品包括：
- **Agentverse**: 无代码管理服务，简化 Web3 项目的 AI Agent 部署
- **Open Network**: 利用 Web3 网络进行 Agent 寻址与命名
- **DEX 增强交易产品**: 面向 DEX 的 AI 增强交易工具

## 融资
- 2022.03: 推出 1.5 亿美元发展基金，MEXC Global 领投，火币和 Bybit 参投
- 2023.03: DWF Labs 投资 4000 万美元，用于部署去中心化机器学习、自主代理和网络基础设施

## 竞争优势
- 老牌 AI+Crypto 项目，有 5 年以上持续开发历史
- 完整的 Agent 部署和管理工具链
- Binance 上市，流动性好
- 与 DWF Labs 的战略合作关系

## 风险
- AI Agent 叙事在 2023 年底仍处于概念验证阶段
- 面临 Virtuals、Olas 等新一代 Agent 平台的竞争
- DWF Labs 作为做市商，其投资不等于基本面背书
