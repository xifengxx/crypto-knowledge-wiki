# THORChain

## 基本信息
- 定位：去中心化跨链自动做市商（AMM）应用链，支持用户跨链交易非包装的原生资产
- 代币：RUNE
- 构建框架：Cosmos SDK
- 核心特色：实现 BTC 直接兑换 ETH 等不同链原生资产，无需跨链包装（Wrapped Asset）

## 核心业务/产品
- 跨链原生资产 DEX：通过流动性池实现不同区块链原生资产之间的直接现货兑换
- RUNE 作为兑换媒介：每个流动性池由 RUNE + 另一链原生资产组成，兑换路径为 A-RUNE-B
- THORFi 生态：后续发展有借贷、储蓄等 DeFi 产品

## 关键数据
- 因项目代码漏洞被黑客成功攻击 3 次（2021年），损失高达上千万美元
- RUNE 代币在早期经历显著价格波动，与安全事件高度相关

## 竞争优势 / 护城河
- 真正的跨链原生资产兑换——不需要 wBTC 等包装代币，减少封装信任假设
- 通过 RUNE 作为统一流动性媒介解决跨链流动性碎片化问题
- 基于 Cosmos SDK + Tendermint 共识，具备应用链主权

## 风险 / 争议
- 多次严重安全漏洞导致重大资金损失（上千万美元），反映应用链代码安全审计的挑战
- RUNE 作为强制兑换媒介增加了每笔交易的成本（两次兑换而非一次）
- 跨链清算和预言机依赖的复杂性

## 相关事件时间线
- 2021年中：THORChain 主网上线
- 2021年7月：遭遇首次重大黑客攻击，损失约 $8M
- 2021年7月-8月：连续遭遇第二次和第三次攻击，总损失上千万美元
- 2022年及之后：逐步修复安全漏洞并恢复运营
