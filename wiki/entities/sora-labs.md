# Sora Labs

## 基本信息
- 类型/赛道: AI Agent 基础设施 / AI 开发框架
- 生态: Solana
- 成立时间: 2025年1月前（代币上线约2025年1月中旬）
- 团队: 未公开
- 融资: 未披露
- 代币: SORA

## 核心业务/产品
Sora Labs 是一家专注于区块链产品的 AI 公司，产品矩阵包括 4 个 GitHub 开源项目：

1. **Zen**（核心产品）: 用 Go 语言构建的开源 AI 对话框架，定位为功能强大且易于构建的 AI Agent 框架，与 Swarms 同为 AI Agent 框架赛道
2. **Hana**: 基于 Zen 框架的 Twitter AI 代理
3. **Toolkit**: 基于 Go 和 Rust 开发，帮助开发和管理与 AI 模型无缝协作的工具
4. **Solana Toolkit**: 扩展基本 Toolkit，提供 Solana 特定功能

目标是让 AI 为从个人开发者到大型组织的所有人所用，降低 AI 开发门槛。

## 竞争优势 / 护城河
- Go 语言 AI 框架差异化定位（与主流 Python AI 框架形成差异化）
- 完整的产品矩阵：从框架到应用（Hana）到区块链工具（Solana Toolkit）
- 先有开源产品后发代币，降低 rug pull 风险
- 代币锁定 6 个月体现项目方长期承诺

## 风险 / 争议
- 团队匿名，缺乏透明度
- 框架采用率未知，尚无大规模开发者生态数据
- Go 语言在 AI/ML 领域生态相对薄弱，可能限制增长天花板
- 市值较小（$10M+），流动性风险较高
