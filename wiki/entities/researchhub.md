# ResearchHub

## 基本信息
- 类型: 协议 (Protocol)
- 定位: DeSci 领域的去中心化学术出版平台，旨在成为"科学界的 GitHub"
- 创始人: Brian Armstrong（Coinbase CEO）和 Patrick Joyce
- 代币: $RSC（ResearchCoin，ERC-20，总供应量 10亿枚）
- 融资: 2023年6月完成 500万美元 A轮融资，由 Open Source Software Capital 领投
- 主要方向: 开放的科研出版、同行评审、科研资助和学术内容策展

## 核心业务/产品

ResearchHub 提供开放的科研出版和讨论工具，核心功能包括：

### 1. 资助（Grants）
用户可以使用 RSC Token 创建资助任务，向社区请求完成特定任务。资助类型包括：
- **同行评审（Peer Review）** — 请求对论文手稿进行评审
- **问题解答（Answer to Question）** — 请求对特定问题提供解答
- **科研资助（Funding）** — 研究人员上传研究提案，从用户处获得 RSC Token 资助

### 2. 期刊（Journals）
存档来自同行评审期刊和预印本服务器的论文，用户可以浏览学术文献并参与讨论。但许多同行评审论文受限于付费墙。

### 3. 研究中心（Hubs）
按学科分类的预印本论文存档。所有论文均为开放获取（Open Access），任何人都可以阅读完整内容并参与讨论。

### 4. 实验记录本（Lab Notebook）
在线协作工作区，允许多个用户共同撰写论文。类似于 Google Docs 或 Notion，支持无缝集成至 ResearchHub 并直接发布。

### 5. RH 期刊（RH Journal）
ResearchHub 的自有学术期刊，具有以下特点：
- **高效评审周期**: 同行评审 14天，最终决策 21天内完成
- **同行评审激励机制**: 引入 Token 激励以解决传统评审体系中激励机制不匹配的问题

### RSC Token（ResearchCoin）经济模型
- 总供应量: 10亿枚 ERC-20 Token
- 主要用途:
  - 治理投票（Governance Voting）
  - 打赏其他用户（Tipping Other Users）
  - 悬赏计划（Bounty Programs）
  - 同行评审激励（Incentives for Peer Reviewers）
  - 研究论文策展奖励（Rewards for Curating Research Papers）

## 竞争优势 / 护城河
1. **创始人背书**: Coinbase CEO Brian Armstrong 亲自创立，为 ResearchHub 带来了加密行业最顶级的品牌信誉和资源网络
2. **全流程出版工具**: 从资金募集（Grants）到论文协作（Lab Notebook）到出版（Journals/Hubs/RH Journal）再到同行评审，覆盖学术出版全价值链
3. **Token 激励完整性**: RSC Token 覆盖了同行评审、论文策展、内容打赏、资金募集等所有科研场景，形成了完整的激励闭环
4. **已建立用户基础**: 作为 DeSci 领域最早的出版平台，在学术社区中有一定的品牌认知度

## 风险 / 争议
1. **付费墙困境**: 期刊部分仍有大量论文受限于付费墙，用户只能查看摘要——这说明 ResearchHub 尚未能打破传统出版商的壁垒
2. **学术声誉积累缓慢**: 新平台难以短期内建立与传统期刊（如 Nature、Science）相媲美的学术声誉，影响高质量稿源的获取
3. **Token 价值支撑**: RSC Token 的价值高度依赖 ResearchHub 平台的实际使用量，如果学术社区采用率不足，Token 价格可能缺乏长期支撑
4. **竞争格局**: 面临 ScieNFT、deScier 等其他 DeSci 出版平台以及 arXiv 等传统预印本平台的竞争
