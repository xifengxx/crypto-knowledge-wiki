# Auki Network

## 基本信息
- **赛道**: 去中心化空间智能 / 空间计算协议
- **核心产品**: Posemesh 技术
- **定位**: 在保护隐私和保持去中心化的同时实现实时空间感知能力，为物理 AI 提供空间智能支持
- **关键词**: 隐私保护空间智能、去中心化 3D 虚拟孪生、空间协调

## 核心业务/产品
Auki Network 通过其 Posemesh 技术提供去中心化空间智能解决方案：

- **Posemesh** — 一种保护隐私的去中心化空间感知协议，可在不牺牲隐私和去中心化特性的情况下实现实时空间感知
- **3D 虚拟孪生** — 推动现实世界 3D 虚拟孪生的去中心化发展
- **空间协调** — 利用 DePIN 和 DePAI 技术推动空间协调

## 在 DePAI 中的定位
Auki Network 在 DePAI 生态中扮演空间智能层的角色，为物理 AI 系统提供：
- 实时的空间感知能力
- 隐私保护的环境理解
- 去中心化的空间数据协调
