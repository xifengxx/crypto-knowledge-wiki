# Hardhat

## 基本信息
- 类型 / 赛道: 以太坊智能合约开发框架
- 开发团队: Nomic Labs
- 基础语言: JavaScript + TypeScript
- 后端库: ethers.js
- 定位: 最主流、最广泛采用的智能合约开发框架

## 核心产品/功能
- 本地区块链节点（Hardhat Network）用于测试和调试
- 支持 TypeScript（领先于对手 Truffle 的 TypeScript 支持）
- 内置 console.log 调试功能
- 插件生态丰富
- 正在开发下一代高级开发平台（Slang/Rethnet）

## 竞争优势
- 测试运行速度领先
- 以开发者体验为中心的团队持续迭代
- 广泛的社区采用和生态支持
- 相比 Truffle 更稳定的 TypeScript 支持

## 历史地位
- 2021年起逐渐超越 Truffle 成为事实上的 JavaScript 智能合约开发框架
- 被绝大多数顶级 DeFi 项目采用
- 作者评价为 "strongly recommended" 给喜欢 JavaScript 或希望使用最流行框架的开发者
