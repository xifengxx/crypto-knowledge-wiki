# Yoko Li (a16z 合伙人)

- 身份：风投公司 Andreessen Horowitz (a16z) 合伙人
- 专注领域：开发者工具、基础设施、人工智能

## 核心业务
Yoko Li 是 a16z 在开发者工具和 AI 基础设施领域的关键投资人，重点关注 AI 原生工具生态的构建。她是推动 AI Agent 与工具交互标准化的重要行业思想领袖之一。

## 关键观点（MCP 与 AI Agent 生态）

### MCP 的核心价值
Yoko Li 认为 MCP 可能成为 AI 与工具交互的默认接口，类比于 API 在互联网时代的作用。她强调行业迫切需要统一的标准接口来规范 Agent 的执行、数据获取和工具调用方式。

### 八大未解决挑战
在 2025 年 4 月的深度分析中，Yoko Li 系统性地列出了 MCP 在企业级部署前必须解决的八大挑战：托管与多租户、身份验证机制、权限控制、Gateway 中间层、Server 发现与注册、有状态执行、标准化客户端体验、调试机制。

### 五项前瞻预测
她提出了 MCP 对 AI 工具生态的五项颠覆性预测：开发者公司的新竞争维度、市场驱动的工具定价、文档即基础设施、API 从终点变为起点、托管范式的根本转变。
