# CreatorBid (CB)

## 基本信息
- 类型: AI Agent 发射台 / 启动平台
- 网络: Base
- 代币: $BID（2025年1月预计 TGE）
- 定位: 在 Base 上一键部署、训练和代币化 AI 智能体的平台

## 核心业务
CreatorBid 允许用户在 Base 网络上快速启动 AI 智能体。智能体具备内容创作、社交媒体管理、自动交易等能力，可通过 Agent Keys 代币化，并在 Uniswap 上交易（需要初始流动性 >= 7.4 ETH）。

每个智能体获得唯一的 Agent Name Service (ANS) NFT 作为链上标识符，ANS 可自由交易。

## 核心机制

### 公平启动
防狙击机制确保智能体代币公平分发。在 Aion5100 发布期间成功抵御了 DDoS 攻击。

### 2% 交易税 + 自主资金库
所有智能体交易收取 2% 费用，直接进入智能体自有资金库（非平台抽成）。智能体可自主管理和再投资资金库资产，实现激励一致性。这一设计防止了跑路行为。

### Agent Keys 代币化
用户通过 Agent Keys 获得智能体所有权和经济权益。锁定代币可获得 Creator Points，用于解锁高级功能（图像生成、AI 聊天）、专属社区和治理权。

### 创作者积分 (CreatorPoints)
根据会员总价值 (TVM) 动态分配，TVM 随平台 TVL 调整。$BID 代币推出前，用户通过启动高性能智能体并锁定代币来提升积分。

## 关键数据（截至 2024年12月）
- 已部署智能体: 3,700+
- 累计交易量: 26,000 ETH
- 累计收入: 300 ETH
- TVL: ~2,700 万美元
- 智能体总市值: ~1.42 亿美元
- 月活用户: 6 万+
- 头部智能体: Algo, Aion5100, Draiftking

## 生态合作
- **Bittensor (TAO)**: 首批利用 Bittensor 子网的 AI Agent 平台，子网提供功能扩展和 TAO 排放奖励
- **Olas (OLAS)**: mech 协议实现 Agent 间技能调用，第三方可开发定制化技能插件
- **Aethir / IoNet**: GPU 算力支持
- **Safe / Brahma**: 资金库自动化管理
- **Wormhole**: 跨链互操作性
- **Alphanomics**: 链上数据支持

## 竞争格局
与 [[virtuals]] 同属 Base 生态 AI Agent 发射台。CB 的差异化在于 Olas mech 集成（Agent 间协作）、Bittensor 子网支持（去中心化 AI 技能市场）和创作者积分机制。

## 风险 / 争议
- 平台仍处于早期，TGE 尚未完成
- TVL 数字存在矛盾（同一文章中出现 2,700 万和 1.5 亿两套数据）
- 依赖 Base 生态，受 L2 竞争格局影响
- 代币经济模型未经完整市场周期验证
