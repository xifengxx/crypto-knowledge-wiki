# UniSat

## 基本信息
- 类型：比特币钱包 / 基础设施
- 核心产品：BTC 钱包（支持 BRC-20、Ordinals、Runes）
- 创始人：Lorenzo（同时也是 Fractal Bitcoin 核心贡献者）
- 投资方：Binance + OKX 共同投资
- 周活用户：约 1,000,000（2024 年 9 月数据）

## 核心业务
- BTC 生态最活跃用户的首选钱包之一，服务大多数比特币 DeFi 和 NFT 用户
- 完全支持 BRC-20 代币、Ordinals NFT、Runes 协议

### BRC20-Swap
Unisat 为 BRC-20 带来类似 AMM DEX 的交换功能，用户可像使用传统 DEX 一样轻松交换 BRC-20 代币。作为第一个提高 Ordinals 生态流动性的产品，BRC20-Swap 有望释放比特币 DeFi 生态系统的潜力，未来可能出现更多功能（如借贷和衍生品）。

### API 开放
Unisat 开放了 API 接口，对小型开发者非常友好，可调用自动化批量扫单、监控铭文并自动 mint 等功能，由此可衍生大量工具类项目。

### 市场地位
截至 2023 年 11 月，BRC-20 的交易活动主要集中在 OKX 和 Unisat 两大平台。
- 支持在 BTC 主网和 Fractal Bitcoin 之间一键切换网络，使用同一地址
- 作为 Fractal Bitcoin 的核心开发者，负责钱包集成和生态系统建设

## 生态影响力
- 为 Fractal Bitcoin 提供了"自带用户"的冷启动优势——100 万周活用户无需重新注册即可使用 Fractal
- Fractal 主网上线时，与 OKX 钱包联合空投 100 万 FB 给 100,000+ 地址
- 是连接 BTC 资产（BRC-20/Ordinals/Runes）用户与 Fractal 扩容网络的关键桥梁
