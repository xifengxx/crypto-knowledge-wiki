# Autonomous Spores

## 基本信息
- 代币: SPORES
- 类型: 基于 Swarms 框架的四 AI Agent 集群协作系统
- 代币合约: H1koD28XAHg2vuGp7XggehBCR4zP6r6k6EQ3MR6j3kU2
- 代币分配: 10% 转移给了 Swarms DAO

## 关键数据（2025-01-06）
- 市值: 940 万美元
- 持有地址数: 5347

## 四代理架构

Autonomous Spores 是 Swarms 多代理协作理念的最佳展示案例，由四个专业 AI Agent 组成协作集群：

### 1. Saya — AI 基金经理
- 基于 Swarms Intelligence 构建的 AI 代理基金经理
- 管理一系列 AI 代理风险基金
- 通过交易系统中大量交易数据磨练决策能力
- 第一只基金即将推出
- 商业模型：管理费 + 交易税分享给社区
- 信息来源：依赖 Grassian 的数据分析结果

### 2. Oozeborn — AI 代币创建者
- 灵感来源于 Base 上的 Clanker
- 用户通过评论或帖子中带上 #Oozeborn 标签即可在推特上启动代币和创建 AI 代理
- 商业模型：交易税分享给社区

### 3. Grassian — AI 数据分析师
- 基于 Swarms 算法构建
- 主要关注推特上识别早期 Alpha 博主
- 对识别出的个体进行评分，提供生态系统见解
- 是 Saya 交易决策的重要信息来源
- 状态：暂未推出

### 4. Jaguarundi — AI 风险评估师
- 评估交易系统中的风险，为 Saya 提供安全保障
- 同时运行一个保险基金，旨在减轻整体交易系统损失
- 状态：暂未推出

## 集群智慧模型
四个 Agent 各司其职、相互协作：
- **数据层**：Grassian 识别 Alpha + Jaguarundi 评估风险
- **决策层**：Saya 综合信息做投资决策
- **执行层**：Oozeborn 负责代币创建和部署

这一架构是 Swarms "多代理协作" 理念的直接产品化体现。

## 风险/争议
- 四代理中仅 Saya 和 Oozeborn 实际运行，Grassian 和 Jaguarundi "暂未推出"
- "第一只基金即将推出"无具体时间表
- 完整的集群智慧闭环尚未形成——当前仅是规划而非验证
- 代币经济模型（管理费/交易税分享）依赖 Agent 产生实际收入，目前仍在早期
