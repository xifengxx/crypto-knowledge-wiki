# Covalent

## 基本信息
- 类型: 数据查询层协议
- 代币: CQT
- 支持网络: Ethereum、BNB Chain、Avalanche、Ronin、Fantom、Moonbeam、Klaytn、HECO、SHIDEN 及主流 Layer2 网络

## 核心业务/产品
Covalent 提供数据查询层，用户可通过 API 形式快速调用区块链数据。支持全数据类型查询（交易、余额、日志等）以及按协议维度的数据查询。

## 竞争优势
Covalent 最突出的特点是跨多链查询能力 —— 无需像 The Graph 那样为每条链重新建立 subgraph 索引，通过改变 Chain ID 即可切换查询目标链。CQT 代币持有者可用于抵押和为数据库上新等事件投票。
