# Paragraph

## 基本信息
- 类型：Web3 通讯/内容发布平台
- 赛道：创作者经济 / 内容货币化
- 定位：Web3 版 Substack
- 创始人：Colin Armstrong（2021年创立）
- 融资：2022年10月完成 170 万美元融资（Lemniscap 领投，FTX Ventures、Binance Labs、GCR、Seed Club Ventures 参投）
- 官方：https://paragraph.xyz/

## 核心业务/产品
- **内容货币化**：帮助 Web3 领域作者、DAO 和 NFT 社区通过一体化的通讯服务将内容货币化
- **Token 门控会员**：内容创建者和社区建设者可以使用 NFT 或 ERC-20 Token 通过会员机制管理用户或粉丝
- **去中心化通讯**：与 Substack 相比，增加了链上 Token 门控和 NFT 会员功能

## 风险 / 争议
- FTX Ventures 参投方已于2022年11月破产，可能影响后续融资或合作关系
- Web3 通讯平台的市场规模有限，与 Substack 的竞争面临冷启动问题
