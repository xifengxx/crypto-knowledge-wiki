# AIOS

## 基本信息
- 类型/赛道: AI Agent 基础设施 / 人工智能代理操作系统
- 生态: Solana
- 成立时间: 2025年1月前（代币上线约2025年1月中旬）
- 团队: 未公开（社区质疑为"国人盘"）
- 融资: 未披露

## 核心业务/产品
AIOS 是将大语言模型（LLM）嵌入到操作系统层的人工智能代理操作系统。核心架构包括：
- **AIOS 内核**: 处理 LLM agent 的调度、上下文切换、内存管理、存储管理、工具管理、Agent SDK 管理等
- **AIOS SDK（大脑）**: 为开发者提供统一的 LLM 和工具接口
- **界面层**: 支持 Web UI 和终端 UI
- **AIOS Chain**: 计划中的自有链，主网上线后 Solana 上的流通 AIOS 可选择迁移

目标是构建 LLM 智能体的操作系统和生态，简化多种 LLM 和工具的集成与管理，降低 AI Agent 开发和部署的技术门槛。
