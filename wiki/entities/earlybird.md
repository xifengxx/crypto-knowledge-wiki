# Earlybird

## 基本信息
- 类型: Solana 上的 Pre-IPO 多空交易市场
- 团队: 原 Hyperspace（Solana NFT 市场）团队
- 核心成员: Kamil Mafoud、Santhosh Narayan（均前摩根士丹利投资分析师）
- 背景投资: Dragonfly、Pantera（来自 Hyperspace 时期融资）
- 状态: 申请制封闭测试

## 核心业务/产品
Earlybird 定位为面向散户的下一代私募股权交易平台，让用户可以在 IPO 前做多或做空未上市公司。其产品形式尚未全面公开，但从 dev 测试网可见与 Ventuals 类似——利用链上衍生品或模拟资产，让用户押注未上市公司的估值涨跌。

### 团队背景
- 团队脱胎于 Hyperspace（Solana 主导的 NFT 市场），2024 年关闭 NFT 业务后转型 Pre-IPO
- 两位联合创始人都有摩根士丹利工作经验和多年投资分析师背景
- 华尔街人脉在该领域可能比加密货币人脉更重要

### 技术环境
- 基于 Solana 搭建，利用 Solana 高速低费的优势适合实时交易
- 可能采用订单簿或 AMM 做市商机制提供比传统 OTC 更连续的流动性
- 用户地区限制和资质要求相对宽松（较开放的去中心化路线）

## 关键数据
- 产品仍处于封闭测试阶段
- 开发测试网提供 $10,000 体验金

## 竞争优势 / 护城河
- 团队华尔街背景：摩根士丹利经历 + 投资分析师经验，私募股权领域资源和人脉优势
- Solana 高性能链的支持
- 已有加密风投 Dragonfly、Pantera 背书

## 风险 / 争议
- 产品尚未正式上线，商业模式未经市场验证
- 与 Ventuals 同样面临定价和合规两大核心问题
- 依赖衍生品模式，不涉及真实股权交割
- Solana 上已有类似尝试（PreStocks、Mango Markets mStock 等），竞争格局初显
