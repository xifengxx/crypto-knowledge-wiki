# Balance（原E-PAL）

## 基本信息
- **类型**：Web3 综合游戏平台 + L2 游戏链
- **赛道**：GameFi / 游戏基础设施 / SocialFi（陪玩社交）
- **前身**：E-PAL（北美最大陪玩平台）
- **成立时间**：E-PAL 2020年3月推出1.0；Balance 2023年3月成立Web3团队
- **总部**：美国洛杉矶
- **团队**：四名联合创始人，CEO曾创立视觉小说平台"武侠梦"（被腾讯收购），COO为Oasis Pastoral联合创始人，另两位在美国上市公司资本管理和DeFi/GameFi领域有经验
- **融资**：
  - 2020年9月：a16z领投300万美元种子轮
  - 2021年7月：Galaxy Interactive领投A轮（a16z参投）
  - 2024年9月：a16z + Galaxy Interactive领投3000万美元，参投方包括Animoca Brands、Aptos Labs、YouTube联合创始人Steve Chen、Riot Games CEO Marc Merrill、英雄联盟总监Thomas Vu等

## 核心业务/产品

### Balance 平台
Web3 游戏一站式平台，整合游戏访问、购买、资产交易、社交互动、空投等功能：
- **Balance Passport**：统一身份认证，跨不同区块链网络的注册和登录，融合用户信息、游戏数据、资产、成就徽章、社交媒体
- **资产交易市场**：去中心化跨链资产交易，所有资产以EPT代币定价
- **游戏购买**：支持EPT支付购买Web3游戏及热门Web2游戏虚拟商品（英雄联盟、守望先锋2、绝地求生、CS:GO物品和皮肤）
- **AI游戏伙伴**：利用AI技术创建虚拟角色用于社交互动（2024年10月路线图）

### Balance zkEVM
基于zk-rollup的Layer 2游戏链，EVM兼容：
- 即时交易、大规模可扩展性、零Gas费用
- 使用Solidity和现有以太坊开发框架
- AI集成：训练超20万行智能合约代码的AI模型，可根据文档自动生成Token/NFT/DEX/Staking等智能合约并自动部署
- 2024年8月主网上线，计划12月扩展兼容Solana、Avalanche

### EPT 代币
总供应量10亿枚，分配：40%奖励池 / 15%团队 / 15%投资者 / 15%生态基金会 / 10% Launchpool+公募 / 3%市场营销 / 2%市值管理
应用场景：应用搭建费用支付、质押收益、治理投票、网络节点运营维护、支付和交易媒介、优先访问游戏Alpha/Beta测试、社交激励机制

## 竞争优势 / 护城河
- **陪玩流量壁垒**：E-PAL作为北美最大陪玩平台的420万活跃用户基础，是纯Web3游戏平台不具备的获客优势
- **a16z+Galaxy豪华资本背书**：顶级风投+游戏行业名人（Riot CEO、英雄联盟总监、YouTube联合创始人）的信任信号
- **AI开发者工具**：用AI降低智能合约编写门槛，可能吸引传统Web2游戏开发者
- **跨Web2/Web3支付**：EPT可用于购买Web2热门游戏虚拟商品，桥接两个世界

## 风险 / 争议
- **转化漏斗不透明**：420万Web2陪玩用户转化为Web3链上用户的路径和效率完全没有数据支撑
- **"零Gas费"可持续性**：零Gas通常意味着第三方补贴而非真正消除成本，依赖EPT代币经济的正反馈飞轮
- **竞争激烈**：Ronin（游戏专用L1 + zkEVM路线图）、Oasys（育碧/世嘉背书）、TON（Telegram 10亿用户）等已有游戏链的竞争
- **代币解锁压力**：15%团队+15%投资者+15%生态基金会合计45%的代币面临解锁抛售风险
- **PR文章包装过度**：MarsBit原文带有强营销色彩，需区分宣传和实际产品交付

## 我的判断
Balance是一个典型的"Web2流量+Web3基础设施"叙事项目。其核心假设是陪玩社交场景能成为Web3游戏大规模采用的入口——这个假设本身合理（陪玩天然涉及支付、声誉、资产交易），但执行难度极高。420万陪玩用户中的绝大多数可能从未使用过钱包或交易所，转化教育成本巨大。a16z的连续三轮加注（种子→A→新一轮）表明对这个团队的信心，但同时也意味着机构筹码集中——散户参与时需考虑解锁抛售的时间节点。建议关注Balance zkEVM主网上线后的真实链上数据（活跃地址、交易量、TVL），而非营销文章中的用户数字。
