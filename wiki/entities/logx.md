# LogX Network

## 基本信息
- 类型：跨链永续合约流动性基础设施 / Perp DEX
- 赛道：DeFi 衍生品 / 跨链流动性聚合
- 核心定位：通过跨链流动性调配和 DAMN AMM 池，实现多市场间的流动性杠杆化

## 核心业务/产品

### 跨链流动性调配
允许在任意链上创建永续合约交易前端，并在所有市场间实现流动性杠杆化——整合多链流动性资源，打破单链 DEX 的流动性孤岛。

### DAMN 离散资产市场中性 AMM 池
- **DAMN** = Discrete Asset Market Neutral（离散资产市场中性）
- 整合多种彼此独立的资产，构建对市场行情不敏感的投资组合
- 使用 USDT、USDC、wUSDM 等稳定资产，借助预言机实现永续合约交易
- 核心价值：在市场剧烈波动期间维持流动性，对冲市场波动对投资组合的影响

### 生态扩展
- 覆盖市场不仅限于金融，还包括选举、体育等非金融预测场景
- 已公布产品路线图，目标成为跨链 Perp 交易基础设施

## 竞争优势 / 护城河
- 跨链流动性聚合的定位解决 Perp DEX 流动性割裂的核心痛点
- DAMN 机制在剧烈波动行情下维持流动性的能力构成差异化优势
- 与 [[hyperliquid]]、[[dydx]] 并列被提及为生态扩展最广的 Perp DEX

## 风险 / 争议
- 跨链流动性调配在技术实现上极为复杂，存在跨链桥安全风险
- 与 [[orderly-network]] 定位相近，面临直接竞争
