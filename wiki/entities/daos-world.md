# daos.world

## 基本信息
- 类型: DAO 对冲基金发行平台
- 区块链: Base（Ethereum L2）
- 灵感来源: Solana 上的 [[daos-fun]]
- 主平台开发者: @AzFlin
- 核心创新: 允许任何人创建代币化的交易基金，通过预售→Uniswap V3 上线→基金经理主动管理的流程运作
- 状态: 早期阶段（截至 2025-01），设有紧急退出机制，无跑路记录

## 核心业务/产品

### 基金发行五步流程
1. **预售募资**: 用户通过预售购买基金份额，为基金筹集初始资金
2. **代币上线**: 预售完成后，代币在 Uniswap V3 上线，每笔交易收取 1% 费用
3. **基金经理交易**: 基金经理使用预售筹集的资金进行交易，持续一段设定时间
4. **收益分配**: 交易期结束后，所有代币持有者根据持有比例分配交易收益或亏损
5. **持续交易**: 在整个过程中，代币在 Uniswap 上持续交易，交易动态影响基金的"真实"价格

### 单边流动性机制
- 在 Uniswap 上启动资金池时，流动性是单边的（仅限基金代币侧）
- 预售参与者无法立即抛售代币——需要外部 ETH 流动性进入后才能交易
- 这一设计与 pump.fun 的即时可交易性形成结构性对立

### 基金经理权限
- 基金经理可调用区块链上任意智能合约
- 支持的策略：杠杆交易、套利策略、借贷协议杠杆挖矿等
- 理论上可实现任意 DeFi 策略

## 关键数据
- 每笔交易 Uniswap V3 费率: 1%
- 基金经理 LP 费用分成: 0.4%
- 平台 LP 费用分成: 0.6%
- 截至 2025-01 跑路事件: 0
- 支持 DeFi 策略类型: ≥3种

## 竞争优势 / 护城河
- Base 生态原生，继承 Coinbase 用户基础和低 Gas 优势
- 单边流动性设计强制延长持有期，理论上降低 pump-and-dump 风险
- 基金经理可通过基金净值机制为代币提供"基础价值"，区别于纯 memecoin

## 风险 / 争议
- **基金经理风险**: 如果基金经理做出错误决策（如将所有资金投入迅速下跌的 memecoin），基金基础价值将归零
- **智能合约风险**: 平台仍处于早期阶段，存在未发现的漏洞可能
- **信任依赖**: 作者通过"个人认识开发者"建立信任——这种模式无法规模化，与 daos.fun 通过 AI Agent 解决信任问题的路径形成对比
- **紧急退出争议**: 部分用户可能视紧急退出按钮为安全机制，部分可能视其为管理方控制风险
- **流动性风险**: 单边流动性设计虽然阻止了预售参与者即时抛售，但也可能导致代币缺乏买方流动性
