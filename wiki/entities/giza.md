# Giza (ARMA)

## 基本信息
- **类型**: AI Agent 自主收益优化平台
- **定位**: 专注于最大化稳定币存款收益的自主收益优化智能体
- **链**: Mode Network (L2)
- **关键产品**: ARMA（自主收益优化智能体）

## 核心业务
ARMA 是一款自主收益优化智能体，专为最大化稳定币（USDT、USDC）的存款收益而设计。通过 Mode 的借贷协议（Ionic、LayerBank、Ironclad）持续评估借贷利率，将资金动态分配到收益最高的池中。

### 主要功能
- **自托管智能账户**: 账户抽象技术确保用户对资金的完全掌控
- **自动再平衡**: 动态调整资产至最具收益的借贷池
- **自动复利**: 将收益自动再投资以实现长期收益最大化

- 部署 7400+ 智能体
- 完成 20,000+ 自主交易
- APR 达到 9.69%
