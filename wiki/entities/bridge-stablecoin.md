# Bridge（稳定币基础设施平台）

## 基本信息
- 类型：稳定币基础设施平台
- 成立时间：2022 年（推测）
- 创始人：Zach Abrams, Sean Yu
- URL: https://www.bridge.xyz/
- 定位：通过简单 API 为 fintech 公司提供稳定币卡发行、出入金和结算基础设施
- 收购：2024 年 10 月被 Stripe 以 $11 亿收购

## 核心业务/产品
- **稳定币卡发行 API**：Fintech 公司可通过 Bridge API 发行 Visa 联名卡，用户用稳定币余额支付，Bridge 在后台将稳定币转换为法币结算给商户
- **稳定币支付网关**：为企业提供 USDC 收付能力
- **出入金桥梁**：链接法币和稳定币系统

## 关键数据
- 被 Stripe 以 $11 亿收购（2024.10），是 Stripe 历史上最大收购
- 与 Visa 合作推出稳定币卡发行方案（2025），首批覆盖阿根廷、哥伦比亚、厄瓜多尔、墨西哥、秘鲁、智利
- 通过 Bridge API 发卡，Fintech 客户无需自建稳定币转换基础设施

## 竞争优势 / 护城河
- Stripe 收购后获得全球最大在线支付处理商的商户网络
- 简单的 API 集成，与 Visa 网络直接对接
- 覆盖拉美高需求市场（稳定币通胀保值刚需）
