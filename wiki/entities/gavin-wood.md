# Gavin Wood

## 基本信息
- 身份：以太坊联合创始人、Polkadot 创建者、Web3 Foundation 创始人
- 角色：核心开发者、协议架构师、Web 3.0 概念的定义者
- 关键贡献：以太坊 Solidity 编程语言早期开发、以太坊黄皮书作者、Parity 客户端开发

## 核心贡献

### Web 3.0 概念的重新定义
2014 年，Gavin Wood 在博客文章《DApp：Web 3.0 是什么》（以及后续《Insights into a Modern World》）中重新定义了 Tim Berners-Lee 最初提出的 Web 3.0 概念。不同于 Berners-Lee 的"语义网"（机器可读的集成通信框架），Wood 的 Web 3.0 指向一种基于区块链技术的去中心化互联网——利用共识引擎和密码学协议实现"无须信任的交互系统"，使各方之间能够直接进行创新交互而无需中介。

Wood 将 Web 3.0 的终极目标概括为："**更少信任，更多事实（Less trust, more truth.）**"

### 技术贡献
- 以太坊早期核心开发：编写以太坊黄皮书（技术规范）、开发 Parity 以太坊客户端
- Polkadot：异构多链互操作协议，通过中继链+平行链架构实现跨链通信和共享安全
- Web3 Foundation：推动 Web 3.0 技术栈标准化和生态建设

## 思想体系
Gavin Wood 的 Web 3.0 愿景强调：
- 协议层面的去中心化信任，而非依赖中心化机构
- 用户对数据和资产的自主控制（私钥即所有权）
- 信息由用户自己发布、保管、不可追溯且永远不会泄露
- 用户任何行为无需中间机构帮助传递

## 相关实体
- [[ethereum]] — 联合创立并开发早期核心基础设施
- [[polkadot]] — 创立并领导的异构多链协议
- Tim Berners-Lee — Web 1.0 发明者，Web 3.0 语义网版本的定义者，与 Wood 的定义路径不同

## 我的判断
Gavin Wood 是 Web 3.0 叙事最关键的塑造者之一——他不仅提供了技术架构（Polkadot/Substrate），更提供了意识形态框架（"Less trust, more truth"）。但他的愿景（Polkadot 成为所有链的底层安全层）在 2022-2024 年间面临来自 Cosmos IBC 生态和以太坊 L2 生态的激烈竞争，Polkadot 生态的应用活跃度低于同期 Solana 和以太坊 L2。技术架构的优雅不等于市场采用的成功。
