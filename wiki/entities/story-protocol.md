# Story Protocol

## 基本信息
- 定位：IPFi（知识产权金融）底层公链，将 IP 资产代币化上链
- 赛道：RWA / IP 金融化
- 技术架构：基于 Cosmos-SDK 的 EVM 兼容 L1 区块链
- 融资：1.4 亿美元（IOSG 等参投）；a16z 领投（位列 28 个项目之一）
- 创始人：SY Lee
- 测试网：Odyssey（最终测试网），近 100 个生态合作伙伴
- 愿景：让 IP 成为与 BTC/股票/债券同级的机构级资产类别

## 核心业务
### 技术组件
- **可编程 IP 许可证（PIL）**：基于代码的合约模板，将链下许可条款映射到区块链上。三种预定义模板：(1) 非商业社交混音 (2) 商业使用但禁止转售/衍生品 (3) 商业混音（允许转售和衍生品）。用户可自定义条款。
- **许可代币（License Tokens, ERC-721）**：授予使用 IP 或创建衍生品的权利，可通过付费铸造或二级市场购买。销毁许可代币即接受条款并开始创作衍生品。
- **版税代币（Royalty Tokens, ERC-20, 供应量 10 亿枚）**：代表 IP 产生的收入份额，来自铸造许可费、IP 使用收入和衍生品收入分成。类似资产支持证券，将未来现金流代币化。
- **争议模块**：IP 侵权举报和仲裁机制，目前由 Story Protocol 法律团队担任仲裁员，未来可能交给第三方。

### IPFi 三阶段路线
1. **Core DeFi**（最先上线）：复用 DEX/借贷/LST/Launchpad 等基础 DeFi 设施
2. **Structured IPFi**：IP 抵押品借贷（CDP）、版税 RWA 代币化、IP 资产捆绑组合
3. **Experimental IPFi**：全新金融原语——跨 IP 指数基金、IP 衍生品、链上许可自动执行

### 核心价值主张
- IP 衍生品可编程性：类似 Git 的版本控制机制，跟踪 IP 资产之间的多级父子关系，自动执行版税分配
- L1 统一架构防止流动性碎片化：同一 IP 资产（如 $MOODENG）在不同链上的多个版本被统一到单链，防止价值稀释
- 替代传统中介：取代成本高昂的咨询和律师事务所（当前近 80% 的 IP 许可通过中介完成）
- IP 已是数万亿美元资产类别，通过透明性（降低定价成本）+ 可访问性（融资便利）+ 可组合性（更大 IP 宇宙）可进一步扩大

### 实际应用案例
- **meme 币衍生品控制**：通过版税模块增加推出 meme 衍生币（如 $NEIRO、$Neiro、$NEIROETH）的成本，阻止无序扩散
- **Azuki IP NFT**：展示 IP NFT 如何通过衍生品创造和利润分配让 IP 所有者和衍生品创造者都获得商业化收入
- **Pudgy Penguins**：Luca Netz 在亚马逊售出 20,000+ 玩具时，与个人 NFT 持有者签署部分授权的过程极其繁琐——Story 旨在自动化这一流程

## 挑战
- 链上 IP ≠ 现实世界版权/专利保护（法律承认是最大瓶颈）
- 传统 IP 持有者（Disney/Warner）切换到链上的动机不明确
- IP 的非标准化特性需要全新的 AMM 和借贷模型设计
- AIGC 时代的版权问题未解决：Gen AI 生成内容是否应被视为未经授权衍生品或全新 IP 尚无法律框架
- Web3 仍处于创新扩散模型的早期采用者向早期大众过渡阶段

## 我的判断
Story Protocol 是加密最宏大的叙事之一——把全球最大的资产类别搬上链。但挑战也是最根本的：法律承认问题。先建 Core DeFi 再建 IP 专属设施的渐进策略是正确的。文章未讨论法律承认这一核心风险的实质性应对方案，这是明显的信息偏差。如果 AIGC 版权法规率先明朗化而 Story 未在此之前建立生态位，将面临既有法律和新 AI 版权法规的双重挤压。

## 创始人的 IP 哲学
创始人 Jason Zhao 在其 哲学学报（JasonZhao.substack.com）中阐述了 Story 的存在理由：
- IP 定义为"独创性的原子单位（atomic unit of ingenuity）"——涵盖科研、品牌、创意、个人 NIL——是 **61 万亿美元**的资产类别
- AI 如同入侵物种吞噬互联网数据，若不加补偿机制，IP 创造者将不再"种植"新想法——这是新的 Napster 时刻
- 核心逻辑链：IP 必须软件化才能生存 → 只有区块链让人真正拥有软件 → 只有区块链让人真正拥有 IP
- Story 被定位为"超结构"（hyperstructure）：永久性加密经济网络，全球 IP 存储库（新亚历山大图书馆）
