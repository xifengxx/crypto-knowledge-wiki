# Theta Network

## 基本信息
- **赛道**: DePIN / CDN（内容分发网络）/ 去中心化视频
- **成立时间**: 2017
- **公链**: 自有链（Theta Blockchain，基于 Tendermint）
- **代币**: $THETA（治理和质押）、$TFUEL（Gas 和支付）

## 核心业务/产品
Theta Network 是一个去中心化的视频流媒体和 CDN 网络。用户通过共享闲置带宽和计算资源来中继视频流，获得 $TFUEL 代币奖励。Theta.tv 是其生态内的去中心化直播平台。Theta 已与 Google Cloud、Samsung、Sony 等传统巨头建立合作。

## 关键数据
- 2021 年牛市期间为市值最高的 DePIN 项目之一（曾进入加密市值前 10）
- 双代币模型：$THETA（治理/质押）+ $TFUEL（Gas/支付）

## DePIN 赛道定位
属于数字资源网络中的计算网络（Compute Networks）→ CDN Networks 子类别。与 Livepeer（去中心化视频转码）形成视频 DePIN 赛道互补——Theta 负责分发层（CDN），Livepeer 负责处理层（转码）。

## 竞争优势 / 护城河
- 先发优势和品牌认知：从 2017 年至今持续运营，经历过完整牛熊周期
- 企业合作：Google Cloud 作为验证节点，Samsung 预装 Theta 钱包
- 视频赛道的刚需性：视频流量占互联网带宽的 80%+，CDN 是确定性需求

## 风险 / 争议
- 币价表现：2021 年高点后下跌超 90%，代币经济模型是否可持续存疑
- 中心化依赖：Google 和 Samsung 的合作关系是否真正去中心化
- 与 Web2 CDN（Cloudflare/Akamai）的竞争力：速度和可靠性差距
