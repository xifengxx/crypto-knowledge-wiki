# Core Scientific

## 基本信息
- 类型: 区块链基础设施和比特币挖矿企业
- 赛道: 比特币挖矿 / AI高性能计算
- 成立时间: 2017年
- 上市时间: 2022年1月20日
- 交易所: NASDAQ | 股票代码: CORZ
- 总部: 美国

## 核心业务
Core Scientific是美国区块链基础设施龙头，运营北美最大规模的比特币挖矿设施，提供比特币挖矿和托管服务，客户包括机构和零售矿工。近年来向高增长领域扩展，AI计算业务（如GPU集群）快速扩张，实现收入多元化。

## 关键数据
- 2025年5月月涨幅: 34.81%
- 运营北美最大规模的挖矿设施
- 客户类型：机构和零售矿工
- 第二增长曲线：AI计算业务（GPU集群）

## 竞争优势 / 护城河
- 北美最大规模的矿业基础设施网络
- 从挖矿向AI/HPC计算的转型能力（与CoreWeave路径相似）
- 规模效应带来的低成本优势

## 风险 / 争议
- 比特币减半后挖矿收入承压
- AI基础设施赛道竞争加剧
- 能源成本和监管变化风险

## 相关事件时间线
- 2017: 成立
- 2022-01-20: 在纳斯达克上市，代码CORZ
- 2024-06-04: 与CoreWeave签署12年期合同，预计总收入$35亿，提供AI/HPC基础设施服务
- 2025: AI计算业务扩张，月涨幅34.81%
