# x402

## 基本信息
- 类型：AI Agent 自主支付协议，基于 HTTP 402 Payment Required 状态码
- 创建者：[[coinbase]] + [[cloudflare]]（2025 年 5 月联合发布）
- 当前治理：x402 基金会（Linux 基金会管理，2026 年 4 月 2 日接管）
- 许可：Apache 2.0（零协议费用，零供应商锁定）
- 结算链：Base（以太坊 L2，Gas 费约 0.001 美元/笔），Solana 承载 65% 交易量

## 核心设计
x402 的逻辑可以概括为：Agent 请求资源，服务器回复「支付 0.001 美元」，Agent 用 USDC 签名付款，资源在同一个 HTTP 请求周期内交付。没有账号，没有订阅，没有 API 密钥。关键设计选择是将支付和身份完全分离——协议只关心「这笔钱到了没有」，不关心「谁付的」。这让 x402 对 Agent 极其友好（不需要注册/不需要证明是谁），但代价是不会阻止 Agent 超额支出或恶意支出。

## 发展时间线
- **2025 年 10 月**（估计）：$PING 成为首个通过 x402 发行的代币，铸造成本 ~1 美元/次，成功获 5000 枚 $PING，收益约 18 倍，30 天内产生超 15 万笔 x402 交易（约 14 万美元），为 x402 首次大规模压力测试
- **2025 年 5 月**：Coinbase 和 Cloudflare 联合发布 x402 V1
- **2025 年 12 月**：x402 V2 升级，新增可复用会话、多链支持和自动服务发现
- **2026 年 3 月 18 日**：Stripe + Paradigm 投资 Tempo 发布 MPP（Machine Payments Protocol），与 x402 共享 HTTP 402 底层签名机制，但额外支持订阅、流式计费、取消和退款，并打通 Visa 信用卡通道
- **2026 年 4 月 2 日**：Coinbase 将 x402 捐赠给 Linux 基金会，22 个创始成员成立 x402 基金会
- **2026 年 5 月 7 日**：AWS AgentCore Payments 集成 x402，Google Pay.sh 兼容 x402 和 MPP 两套协议

## 关键数据
- 69,000 个活跃 Agent（截至 4 月底）
- 1.65 亿笔累计交易
- 约 5000 万美元累计交易额
- 日均实际交易额约 28,000 美元，平均每笔 0.20 美元
- 约一半为测试和刷量
- 整个 Agent 支付活动占稳定币总交易量的 0.0001%
- 从开源项目到 Linux 基金会接管：11 个月（技术史罕见的速度）
- Solana 承载近 65% 的 x402 交易量

## 竞争协议
- **MPP（Machine Payments Protocol）**：Stripe + Paradigm 通过 Tempo 发布，支持订阅、流式计费、退款，打通 Visa 信用卡通道。发布首日 100+ 服务接入，包括 Anthropic、OpenAI、Shopify
- **MoonAgents Card**：MoonPay 的虚拟 Mastercard 借记卡，Agent 直接从链上钱包消费
- **Stripe 虚拟借记卡**：企业和 Agent 平台可程序化批量发行一次性虚拟借记卡，走 Stripe 法币结算网络
- **Visa Trusted Agent Protocol**：密码学签名给 Agent 发凭证
- **Mastercard Agent Pay**：信用卡网络延伸到 Agent

## 竞争优势 / 护城河
- Linux 基金会治理 + Apache 2.0 许可，供应商锁定风险最低
- 22 个创始成员涵盖云计算三巨头、卡组织两巨头、全球最大电商 SaaS、主要稳定币和区块链基础设施
- 设计极简——只解决支付这一件事，不绑定身份、不绑定特定区块链
- 类比：被定位为支付领域的 TCP/IP

## 风险 / 争议
- 日均交易量极小（28,000 美元），真实商业需求尚未跟上基础设施铺设速度
- 支付与身份完全分离的设计意味着安全性完全依赖外部层
- MPP 作为竞争协议可能分裂 Agent 支付生态
