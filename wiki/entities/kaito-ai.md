# Kaito AI

## 基本信息
- 定位: AI 驱动的 Web3 加密信息搜索引擎 → 演进为以 KOL 图谱为核心的社交数据 + 营销撮合平台
- 代币: 以 Yaps 积分系统 + KAITO 代币闻名（2025 年 TGE）；Yaps 每天 25000 个/25 万+ 用户
- 融资: 550 万美元 A 轮（2023.06.22），估值 $8750 万，Superscrypt 和 Spartan 领投；另有两轮融资合计 $10.8M（含种子轮 $5.3M + A 轮 $5.5M，Dragonfly/红杉中国/Jane Street 参与）
- 定价: Kaito Pro $833/月（年付）/ $1099/月（月付）；基础版早期 $129/月。2024.06 实现盈利，年增长 >100x

## 核心业务/产品

### 早期：AI 搜索引擎 MetaSearch
- 一键搜索加密领域所有平台: Twitter、Discord、治理论坛、Mirror、Medium 等
- 运用 Auto GPT 框架 + 多个 ChatGPT 后端构建代理网络
- AI 功能: 排名、主题挖掘、个性化、推荐、语音转文本转录、AI 生成内容优化

### 演进：三大方向探索

Kaito 的产品方向经历了三次迭代（与竞争对手 Ferryboat Research 的 Alex 方向选择高度一致）：

1. **自用 Alpha 工具**（放弃）：越开发越倾向内部使用，不适合大规模用户。不收费用户不珍惜，收费则用户质疑"为什么不直接自己用"。曾在市值小的项目中基于文本挖掘+情绪分析测试量化策略，对小市值情绪驱动型项目有效，但无法标准化

2. **社区新闻/GPT 类工具**（部分探索）：基于 Twitter 分时数据 + GPT 接口生成即时社区新闻。问题：(1) 用户付费意愿不够强——效率提升但未针对核心痛点；(2) GPT 调用成本高导致毛利率偏低，调用行为多出于促活而非收入

3. **KOL 图谱 + 营销撮合**（最终选择）：转向构建 KOL 影响力评分系统，为项目方提供精准投放参考。两个关键指标：
   - **正确性**：KOL 对项目的判断是否准确（时间戳验证——是否在上涨前讨论）
   - **核心圈层（Smart Follower）**：衡量影响力深度，聪明账户互动越多权重越高

——选择这一方向是为了获得更大市值空间，而非停留在 Alpha 工具的小而美路线

### 当前：Yap 积分系统 + 社交飞轮
- Yaps 积分 = 声誉加权注意力，KOL 影响力代币化
- Yap 活动战略逻辑三层：(1) 免费 KOL 杠杆减少营销成本；(2) TGE 促使用户主动绑定账户授权数据 → 逐步脱离 Twitter API 依赖；(3) 供需正循环（用户绑定 ↑ → 项目方兴趣 ↑ → 数据撮合飞轮）
- 商业模式对标：阿里妈妈/巨量引擎（广告撮合引擎）

### InfoFi 定位
Kaito 被公认为 InfoFi（信息金融，SocialFi 的 AI 升级版）最成功的代表产品。InfoFi 定义为"将各种载体的信息及其衍生物和供应链进行代币化"。Kaito 通过 AI 算法将难以量化的内容本身、内容触达、社交关系等抽象地量化为 Yaps，为项目方和市场提供了衡量影响力的绝对参考系。其核心意义在于改变了 SocialFi 竞争格局的利益关系：
- 传统 SocialFi：散户资金买单名人影响力、平台中间抽成
- Kaito InfoFi 模式：散户注意力买单内容影响力 → 项目方为内容买单 → 平台通过服务获益
- Kaito 作为一个巨大的非定向 agency，为内容和影响力提供传播路径和回报方式

## 竞争优势 / 护城河
- **数据清洗能力是核心壁垒**：采集数据相对简单，但加权、清洗、去噪需要经验和直觉。中文 CT 噪音高、滞后英文 24-48 小时即为一例——数据清洗是"看家本领"
- **Twitter API 成本结构形成的天然护城河**：商用 API 成本随调用量线性增长 + 月度调用次数上限 → ToB 高定价是必要选择，也阻挡了低端竞争者
- **KOL 图谱的网络效应**：更多 CT 用户绑定 → 数据更精准 → 项目方投放需求增加 → 吸引更多用户绑定，形成飞轮
- **Yap 活动创造的数据资产化路径**：通过 TGE 将用户主动授权的数据转化为自有资产，逐步降低对 Twitter API 的政策风险敞口
- Web3 原生搜索引擎——传统搜索引擎对加密信息索引覆盖不足

## 风险 / 争议
- 2025-2026 年 KAITO 代币空投引发大量争议（Yaps 积分分配的公平性问题、KOL 垄断、"KOL 矩阵撸毛平台"批评）
- Twitter/X API 政策变化构成系统性风险——API 若进一步收紧，商业模式根基动摇
- Yap 系统的注意力经济天然不可持续：财富效应降低后注意力必然转移
- 算法黑箱——Smart Follower 机制对小白不友好，并非公信力评价系统

## 我的判断
Kaito 是 2023 年底 AI+Crypto 盘点中少数在两年后仍保持高关注度的项目，且其从"AI 搜索引擎"到"KOL 图谱平台"的转型路径展示了一个清晰的战略判断：在 Twitter API 结构性约束下，ToB 高定价 + 数据清洗护城河 + 用户数据绑定是最优解。Yap 活动不仅是一次成功的注意力营销，更是一次数据资产的战略性转移——从依赖 Twitter API 到拥有用户主动授权的自有数据资产。但 2025-2026 年代币空投的巨大争议也提醒：注意力挖矿模式容易走偏，从"让观点输出成为习惯"的理想退化为"KOL 矩阵撸毛"是真实风险。
