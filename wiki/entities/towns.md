# Towns

## 基本信息
- 定位：去中心化社交协议，"链上 Discord"
- 融资：$25.5M A 轮（2023.02，a16z 领投，Benchmark / Framework 参投）
- 上线：2024 年 10 月（开发近 2 年）
- 技术栈：River Protocol（专用 L2 + 链下流节点 + Base 智能合约）

## 核心功能
- **Space = NFT**：每个群组 = 独立可编程链上资产，代表社区所有权和管理权
- **付费会员制**：前 N 人免费 → 后入组收费/阶梯价/持特定代币或 NFT 准入
- **E2E 加密**：协议层端到端加密，不依赖中心化服务器
- **UX 封装**：无钱包登录 + MPC 内置钱包 + 创建者预支 Gas

## 竞争对比
| | Towns | Warpcast (Farcaster) |
|---|---|---|
| 模式 | 群组/社区（Discord 模式）| 信息流（Twitter 模式）|
| 融资 | a16z $25.5M | a16z 参投 |
| 商业化 | 付费会员+门票 | 订阅+小费 |

## 核心挑战
用户没有为了"去中心化"放弃 Discord/Telegram 的动机。Towns 策略：蓝筹 NFT 社区冷启动（Azuki/Doodles/企鹅）。
