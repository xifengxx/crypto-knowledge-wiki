# Ultra

## 基本信息
- 类型: 区块链游戏发行平台 / 游戏分发基础设施
- 成立时间: 信息不详（2022年已有产品）
- 代币: UOS
- 融资: 累计约 1,138 万美元（种子轮+预售+Bitfinex）

## 核心业务/产品
Ultra 定位为区块链游戏分发平台（类似区块链版 Steam），核心功能包括：

1. **游戏分发平台**（Ultra Games）：上传、分发和更新游戏
2. **跨平台 SDK**：支持 MacOS、Windows、Linux、Android、iOS、Nintendo、Xbox 和 PlayStation
3. **地理围栏定价**：在不同地区实施有竞争力的定价策略
4. **NFT 创建和销售**：从单一界面创建、编程和销售 NFT
5. **游戏化任务系统**：启动和管理"游戏化任务"
6. **消息和通知系统**：支持开发者与玩家的沟通

## UOS 代币
UOS 是 Ultra 生态系统的核心代币，具有以下功能：
- 所有购买游戏、虚拟物品和服务需使用 UOS
- Staking UOS 提供区块链资源管理服务质量保障
- 用于忠诚度计划、广告、数字商品交易
- 支持投票、投注应用程序、锦标赛、打赏等

## 关键数据
- 种子轮 + 预售 + Bitfinex 总共融资 $11,381,611
- Ultra Games 定位为区块链游戏分发平台，在 Valve 对区块链持有敌意的市场背景下提供替代方案

## 竞争优势 / 护城河
- 在 Valve（Steam）明确对区块链表示敌意的时期，Ultra 定位为区块链游戏的替代分发渠道
- 全平台覆盖（PC/主机/移动端）
- 一体化 SDK 降低开发者多平台适配成本
