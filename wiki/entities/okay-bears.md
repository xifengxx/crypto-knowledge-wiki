# Okay Bears

## 基本信息
- 类型: PFP NFT 项目
- 公链: Solana
- 发行量: 10,000 个 NFT
- 发行价格: 1.5 SOL
- 发售时间: 2022年4月26日（Whitelist-sale 7,400个 / Public-sale 2,500个）
- 发售方式: 白名单+公开发售
- 稀有度机制: 属性计数越少越稀有（4种属性336个最稀有 → 7种属性1846个最常见）
- 曾被称为: "Solana 上的 BAYC"

## 核心业务/产品
- **Solana PFP NFT 系列**: 10,000 个熊主题头像 NFT，风格简约有留白，不做哈哈大笑的夸张表情
- **生态体系 "Bear Market"**: 线上市集（与 [[magic-eden]] 合作）+ Token门控电子商务（Shopify）+ 线下快闪店
- **项目slogan**: "We're all gonna be okay"（WAGBO）
- **文化定位**: 契合熊市低迷情绪，宣扬"一切都会好起来"

## 关键数据
- MINT 后 24 小时内创下超过 **1,200 万美元** 销售记录
- 至截稿前销售额达到 **38,558 个 ETH**
- 地板价从 30+ SOL 涨至 200+ SOL（约一个月内）
- 稀有度分布：4属性336个 / 5属性2,509个(25.09%) / 6属性5,309个(53.09%) / 7属性1,846个(18.46%)

## 竞争优势
1. **叙事时机恰当**: 在熊市中以"务实品牌路线"替代"宏大元宇宙叙事"——路线图聚焦品牌建设而非难以交付的游戏/元宇宙
2. **文化意识形态契合**: 以熊为主题的图像 + "We're all gonna be okay"的口号，精准对接熊市低迷情绪
3. **审美中性普适**: 熊的形象无种族/宗教/性别偏见，受众面广，适合作为社交媒体头像
4. **简约留白风格**: 给予足够想象空间，便于持有者和品牌进行二次创作
5. **线下优先策略**: 从线下讲好品牌故事反哺线上，走"品牌"路线而非技术路线，交付压力小
6. **Solana 生态锚点**: 被视为 Solana NFT 的"首都级"项目，链上其他项目出圈都会加强其共识

## 项目路线图（七大板块）
1. **熊市场（Bear Market）**: NFT 市场 + 电商 + 线下快闪
2. **作坊（Work Shop）**: 与草根社区及全球品牌合作，CSR 企业社会责任
3. **画廊（Gallery）**: 支持艺术家线上线下展览
4. **公园（The Park）**: 社区 Discord（仅持有者可进入，"没有OG，没有国王，没有农民"）
5. **工作室（Studio）**: 未来空投、Lo-fi 专辑、艺术故事
6. **精品店（Boutique）**: IRL 商品、限量收藏品、时尚品牌联名
7. **平台（Platform）**: 主题演讲、社区资助和孵化器（The Honeypot）

## 我的判断
Okay Bears 是 Solana 生态在 2022 年熊市期间的现象级 PFP NFT 项目，其成功核心在于"天时地利人和"——熊市情绪为熊主题提供了天然共鸣，务实品牌路线相较于宏大元宇宙叙事更符合低迷环境下的用户期待，中性普适的画风扩大了受众基础。然而作为一篇由 KOL 个人发布的投研报告而非官方白皮书，其数据截止于报告发布日，后续实际发展（是否兑现了七大板块路线图）需另外查找。
