# G.A.M.E (Generative Agent engine for Multiple Environments)

## 基本信息
- 类型: 无代码/低代码 AI Agent 框架
- 开发方: Virtuals 团队
- 平台: Virtuals Protocol (Base 链)
- 定位: 模块化 AI Agent 开发平台，降低技术门槛

## 核心架构
采用模块化设计，多个子系统协同工作，共同控制 AI Agent 的行为、决策和学习过程：

### Agent Prompting Interface
开发者与 Agent 行为交互的主要入口。

### Perception Subsystem
负责处理输入数据并将其转化为适合格式。

### Strategic Planning Engine
负责根据输入信息生成具体行动计划。

### 其他子系统
用户仅需修改各模块的参数便可参与 Agent 设计，无需编写代码。

## 市场地位（2025.01）
- 与 Eliza、Swarms 形成 "三足鼎立" 之势
- 市占率约 20%（2024.12 数据）
- 使用项目：200+（2024.12），日请求 15 万次+，周增长 200%+

## 核心特点
- **模块化设计**：框架清晰易懂，无需额外设计
- **低代码/无代码界面**：大幅降低技术门槛
- **快速部署**：特别适合不关心复杂技术设置、追求快速上线的项目

## 局限
对于需要深度定制或完全控制 Agent 各个方面的复杂项目不太适用。

## 适用场景 vs 竞品
- 适合快速启动、非技术团队 → vs Eliza（需深度定制能力者）
- 无代码/API 驱动 → vs Rig（需 Rust 编程能力者）
- 游戏 + 通用 → vs ZerePy（窄化创意社交者）
