# Relation Labs

## 基本信息
- 类型: 多链去中心化社交图谱协议
- 赛道: SocialFi / 社交数据基础设施

## 核心业务/产品
Relation Labs 正在构建一个多链去中心化 Web3 社交图谱，目标是让 Web3 数据生产者拥有 100% 的数据所有权，在 Web3 生态中以开放简单的方式创造和收获数据价值。

**Relation One**：社交 DApp，用户添加多链地址后可快速定义 Web3 人格标签并建立好友网络。用户可创建 Relation ID，拥有完全所有权和隐私保护的数据空间，自行管理数据权限并决定存储内容（联系人、智能合约钱包、DApp 许可证、拥有的 NFT 等）。若用户愿意通过授权向 DApp 或相关利益方提供数据价值，也可赚取代币。

**Relation Graph**：用 Rust 语言编写和部署的智能合约图数据库，是 Relation Link Tool Suite 的核心引擎。使开发者更容易查找、连接、分析和洞察 Web3 关系数据。

## 竞争优势 / 护城河
- Rust 编写的专用图数据库，在性能上可能有优势
- 多链 + 人格标签的定位区别于单链社交图谱方案
- 用户数据变现机制（授权数据换代币）提供了明确的激励

## 风险 / 争议
- 2022 年底项目处于早期阶段，实际采用情况未知
- 与 CyberConnect 的定位接近（底层社交图谱数据库），差异化待验证
