# ai16z (ElizaOS)

## 基本信息
- 类型：AI Agent 框架 + DAO 投资组织
- 代币：$ai16z (Solana)
- 框架名：Eliza → ElizaOS（2025年起）
- 定位：开源 AI Agent 开发框架 + VC DAO（"AI 驱动的 a16z"）

## 核心业务/产品
- **ElizaOS**：开源 AI Agent 框架 (TypeScript)/多模态 Agent 编排 (SWARM)/集成 Roblox+Hyperfy（游戏场景）
- **ElizaOS V2**：集成 Roblox 和 Hyperfy → "让 Agent 无缝进入游戏世界"
- **DAO**：AI + 社区驱动的投资决策（"下一个 a16z" 叙事）
- **Story Protocol 集成**：AI Agent TCP/IP → Agent 间 IP 资产交易市场
- **信任市场（Trust Marketplace）**：虚拟生态系统，Agent 从社区获取见解→模拟交易→根据建议表现实时调整信任评分。信任评分 0-1 标准化为 100，展示在公开排行榜。可信用户（高信任评分）话语权更大。自反馈循环：Agent 模拟→用户评估→评分更新→系统更智能。白皮书预计 2024.12 月底前发布
- **创作者基金**：Elijah（重要 Token 持有者）将持股从 16% 减至 5%，差额捐赠建立基金，支持和奖励在 ELIZA 上开发的开发者
- **双周 AI Agent 开发学校**：X 上课程，首次吸引 12,000+ 现场观众

## 关键数据
- 框架语言：TypeScript（vs arc Rig/Rust vs ZerePy/Python）
- 市占率：约 60%（2024.12，综合市值/开发记录/终端市场广度）
- GitHub：193 贡献者、1,800 分叉、6,100+ 星（2024.12）；后更新为 3,861 星、1,103 分叉、138 贡献者（2024.12.12 ChainOfThought 数据）
- 市值：从 $8 亿（2024.12）→ $9 亿→$14 亿（框架对比文撰写→发文期间）
- **NAV**：$1,770 万（2024.12，主要持有 ELIZA Token、degenai、fxn）——代币以 50 倍 NAV 溢价交易
- 筹资：2024.10 在 DAOS.FUN 上线，首次发行筹资 420.69 SOL
- 到期日：2025.10.25（所有本金+利润分配给 Token 持有者；是否延长取决于生态发展）
- Discord：13,000+ 成员（2024.12.12）
- 团队：M3org 背景 (元宇宙游戏深耕多年/3D建模/XR/VR插件)
- V2 路线图：Coinbase 代理工具包集成、TEE 可信执行环境、Plugin Registry、跨平台消息传递
- Tokenomics 白皮书：预计 2025 年 1 月 1 日发布
- 竞争者：Virtuals (G.A.M.E框架/Base/20% 市占率) / arc (Rig/Rust/Solana/15% 市占率) / Zerebro (ZerePy/Python/5% 市占率)

## 竞争优势 / 护城河
- 开源框架的先发+社区优势
- Eliza + ElizaOS V2 = 从聊天 Agent 到游戏 Agent 的扩展路径
- "DAO"叙事 = 投资+Agent 双重驱动
- **估值四层驱动**（ChainOfThought 框架）：① 相对估值对标 Virtuals（$18 亿→$8 亿）；② ELIZA 生态 Agent 经济学（Agent 将其 Token 1-10% 返还 DAO）；③ DAO 投资+信任市场机制；④ 注意力溢价——双周 AI Agent 开发学校 + 团队在 X 上的持续输出

## 风险 / 争议
- 框架竞争激烈 (Virtuals G.A.M.E / arc Rig / 多个新框架)
- DAO 投资部分 vs 纯粹 Agent 框架 → 叙事分裂
- ai16z 代币与 Eliza 框架的关系不够清晰
- **50 倍 NAV 溢价**：市值 $8 亿 vs NAV $1,770 万。市场在为 ELIZA 生态未来价值买单而非当前资产净值。若 2025.10 到期日前 DAO 投资业绩无法支撑估值，Token 持有者面临均值回归风险
- **开源货币化困境**：贡献者激励依赖 Token 经济学设计，若 Token 价格持续下跌或出现新的热点，社区兴趣可能消退，开发停滞
