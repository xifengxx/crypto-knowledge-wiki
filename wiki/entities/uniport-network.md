# UniPort.Network

## 基本信息
- 定位：基于 Polygon CDK 及 UPSD 稳定币系统构建的比特币再质押链
- 技术栈：Polygon CDK + Cosmos SDK 双链架构
- 核心组件：UniPort zk-Rollup Chain（BTC 再质押功能）、UniPort Chain（L1 互操作链）、UPORT Bridge（全链资产流通桥）
- 代币：UP 治理代币完全空投给社区
- 集成方：ceffu、babylon

## 核心业务
UniPort.Network 是兼容 EVM 的 BTC L2，通过集成 ceffu 和 babylon 让 BTC 持有者可以赚取多种再质押收益。

UPORT Bridge 自称能实现比特币生态资产全链流通，在比特币生态系统资产与 UniPort.Network 双链系统整合方面发挥关键作用，使其成为连接比特币、EVM 生态系统以及更广泛的比特币生态系统的关键枢纽。

## 竞争优势
- 双链架构（Polygon CDK zk-Rollup + Cosmos SDK L1）在技术组合上有差异化
- UP 完全空投给社区（无 VC 分配），具有一定社区吸引力
- 集成 Babylon + ceffu 的 BTC 再质押收益策略

## 风险
- 架构复杂（Polygon CDK + Cosmos SDK + UPORT Bridge），整合风险高
- 收益来源依赖 Babylon 和 ceffu 的外部协议可持续性
