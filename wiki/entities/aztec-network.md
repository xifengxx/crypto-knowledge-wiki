# Aztec Network

## 基本信息
- 类型: 以太坊 ZK-Rollup（隐私 Layer 2）
- 赛道: 隐私保护 / 零知识证明 / Layer 2 扩容
- 总融资: $1.19 亿
- 投资方: Paradigm、a16z 等
- 技术: PLONK 证明机制（行业标准 ZK 证明系统）

## 核心业务/产品
Aztec Network 是以太坊上首个私有 ZK-rollup，为去中心化应用程序提供隐私保护和扩展性。

### 技术架构
- 基于 UTXO 数据架构（与 Bitcoin 类似），而非以太坊的账户模型
- 构建"隐私抽象"层——为开发者提供智能合约隐私，支持：
  - 默认匿名
  - 私有状态读/写功能
  - 私人智能合约功能执行
- 隐私在状态变量和函数层面可编程——开发者将隐私纳入合约本身，调用所期望的函数

## 竞争优势 / 护城河
- 以太坊首个私有 ZK-rollup——先发优势
- PLONK 证明机制为行业标准，技术方案成熟度高
- Paradigm + a16z 双顶级 VC 背书

## 风险 / 争议
- UTXO 模型与以太坊账户模型的兼容性挑战——开发者需要学习新的编程范式
- 隐私 Rollup 的合规风险——监管机构可能将隐私交易视为 AML 风险
