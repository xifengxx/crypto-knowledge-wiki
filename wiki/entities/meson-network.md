# Meson Network

## 基本信息
- 类型: 去中心化 CDN（内容分发网络）
- 投资方: SevenX Ventures
- 支持: AR (Arweave)、IPFS 等去中心化存储方案

## 核心业务/产品
Meson Network 是一个去中心化 CDN 网络，通过挖矿形式聚合闲置服务器，调度带宽资源并将其服务于文件及流媒体加速市场。解决的问题是去中心化存储层因数据量大产生的拥堵（如 IPFS 的大文件下载缓慢）。

服务对象包括传统网站、视频、直播及区块链存储方案。
