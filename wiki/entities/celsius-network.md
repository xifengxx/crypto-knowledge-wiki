# Celsius Network

## 基本信息
- 类型: CeFi加密贷款平台（零售+机构）
- 创始人: Alex Mashinsky
- 成立时间: 2017年
- 倒闭: 2022年7月申请第11章破产保护
- 总部: 新泽西州Hoboken

## 核心业务/产品
- 向零售用户提供加密资产计息账户（CelYield）
- 加密抵押贷款
- 机构贷款业务

## 关键数据
- 2021年Q4-2022年Q1高峰期与Genesis、BlockFi并列CeFi前三强，三家合计76%市场份额（$26.4B）
- 高达36.6%的机构贷款账簿为无抵押贷款（相比行业标准的严重风险失控）
- 破产时欠客户约$47亿
- 最大持股人/融资：Series B融资$7.5亿（2021年10月估值$30亿+），加拿大养老基金CDPQ和WestCap参与
- 2023年11月重组方案获批，NewCo（Fahrenheit LLC）接管资产

## 倒闭原因
1. **风险管理极度薄弱**：36.6%无抵押机构贷款是CeFi行业最大风险失误之一
2. **stETH/ETH脱锚暴露**：大量持有stETH且在stETH折价时无法及时应对流动性需求
3. **资产-负债期限错配**：承诺"随存随取"但贷出长期限贷款
4. **内部操作失误**：大量资金锁在DeFi协议中，用户提现潮触发流动性危机
5. **财务重组**：2024年NewCo重组开始偿还客户
