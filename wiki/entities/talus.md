# Talus Network

## 基本信息
- 类型: Layer 1 区块链（AI 专用）
- 赛道: AI + Crypto / Move 语言生态
- 融资: 首轮 $300 万（Polychain Capital 领投，dao5/Hash3/TRGC/WAGMI Ventures/Inception Capital 参投）
- 天使投资人: 英伟达、IBM、Blue7、Symbolic Capital、Render Network 等科技和区块链公司背景的天使——12 条链中唯一有 Web2 科技巨头背景的个人投资者

## 核心业务/产品
Talus Network 是基于 Move 语言的 AI 专用公链平台，专注于去中心化人工智能。利用 Move 语言的安全性、速度和开发体验优势，为去中心化应用培养多样化的智能代理（AI Agent）生态系统。

### AI Agent 用例
- **钱包分析**: 实时监测交易状态，提升用户资产管理体验
- **DeFi 优化**: 优化流动性管理，自动化链上投资组合，提升资金效率和收益
- **DAO 治理**: 支持 DAO 的自动化资产管理和治理决策
- **通用 Agent 经济**: 参与者可以从可访问资源的通用协议中构建 AI 应用程序的新经济

## 竞争优势 / 护城河
- Move 语言 + AI 专用链的定位在当前赛道中具有差异性——既不是通用 AI Agent 平台（如 Virtuals），也不是通用 L1
- 英伟达/IBM 天使投资人的参与暗示 AI 行业的认可度
- 强调"安全性和速度"——Move 语言的形式化验证特性天然适合 AI Agent 的资产操作场景

## 风险 / 争议
- $300 万融资额极低——在 AI+Crypto 赛道中资源严重不足
- AI Agent 在链上的实际需求和性能瓶颈尚未被验证
- 与 Virtuals（Base 上 AI Agent 平台）、Bittensor（去中心化 AI 网络）等竞争，生态资源差距悬殊
