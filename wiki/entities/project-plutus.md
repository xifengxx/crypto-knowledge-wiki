# Project Plutus

## 基本信息
- 类型: AI 交易代理 / Trading Agent
- 链: Solana
- 代币: $PPCOIN（通过 Pumpfun 发行）
- 关键事件: 2025 年 1 月 16 日获 Solana AI 黑客松 Trading Agents 赛道冠军，奖金 $15,000

## 核心业务/产品
- **"分析 + 交易一体化"AI 代理系统**：既能像 [[aixbt]] 那样进行市场研究分析，又能通过配备资金的钱包执行自主交易
- 核心理念：Project Plutus 认为"仅提供研究分析是不够的（指向 aixbt 的局限），还需要具备自主交易能力"
- 主要功能：自动化交易策略执行、投资组合管理优化、根据用户设定的财务目标完成交易
- 用户可投资并提取资金（AUM 模式）
- 在研功能：让 Agent 评估项目的 Github 代码质量，扩展分析维度

## 关键数据
- Solana AI 黑客松 Trading Agents 赛道冠军（$15K 奖金）
- 文章发布时（2025-01-16）市值约 $1720 万，受获奖消息影响冲击价格新高

## 代币经济
- 持有超过 5,000,000 枚 $PPCOIN 可解锁更多高级分析功能
- 模式类似 [[cookie-dao]] 的代币质押机制，为代币提供实际用途（非纯治理代币）

## 竞争优势 / 护城河
- "分析+交易"双模块差异化定位，直接对标单功能竞品（aixbt 仅分析不交易）
- AUM 模式让用户资金可进可出，区别于纯信号服务
- 黑客松冠军的品牌背书

## 风险 / 争议
- $PPCOIN 通过 Pumpfun 发行，Pumpfun 代币通常缺乏长期价值支撑
- 自主交易 Agent 的技术风险：AI 交易策略的实际表现未经长期验证
- 团队背景未在公开信息中披露
