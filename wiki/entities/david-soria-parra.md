# David Soria Parra

## 基本信息
- 类型: 工程师
- 所属公司: Anthropic
- 角色: MCP（Model Context Protocol）联合创造者，Anthropic 内部开发者工具负责人
- 背景: 在开发者工具领域有丰富经验（版本控制系统、LSP 等），2024 年 7 月加入 Anthropic

## 核心贡献
- MCP 概念的原创提出者——受 LSP 启发，意识到 Claude Desktop 和 IDE 功能割裂是 M×N 集成问题，提议"做一个类似 LSP 的东西，把 AI 应用与扩展之间的通信标准化"
- 在找到 Justin 之前独自琢磨数周，完善了初步构想
- 在 IDE 中完成了 MCP 的多个概念验证，展示协议在开发环境中的应用
- 不倾向于在本地场景使用 HTTP 进行授权认证（与 Justin 存在内部争议）
- 强调 MCP 的目标是"简化服务器的构建流程，便于 LLM 能够参与进来"
- 认为"对于模型下一波能力的提升，最大的瓶颈可能在于与外部世界交互的能力"
