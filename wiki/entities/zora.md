# Zora

## 基本信息
- 类型: protocol
- 定位: NFT 铸造平台 + 自有 L2（Zora Network）+ 链上社交网络（Instagram 式 SocialFi）
- 核心团队: Jacob Horne（CEO，前 Coinbase 产品经理，负责 USDC 和 Coinbase Ventures）、Dee Goens（联合创始人，前 Coinbase 营销）、Tyson Battistella（联合创始人兼 CTO，前 Coinbase 智能合约基础设施）
- 相关赛道: NFT 基础设施 / 创作者经济 / L2 / SocialFi
- 主要投资方: Kindred Ventures, Coinbase Ventures, Haun Ventures 等
- 融资: 三轮融资，最大一轮 5000 万美元，估值 6 亿美元；总融资 6000 万美元；Haun Ventures 约 6 亿美元生态投入
- $ZORA 代币: 2025 年 4 月 23 日 TGE，FDV 约 8 亿美元（较上次融资估值高约 33%）

## 核心业务 / 产品

### NFT 与链上社交双线布局

1. **Zora NFT 铸造平台** — 创作者可在 Zora 上部署 NFT 集合，支持 ERC-721 / ERC-1155 标准，提供无代码铸造工具。2024 年 Zora + [[base]] 的组合驱动的 NFT 部署占全网 **87%**。

2. **Zora Network（L2）** — 基于 [[layer2|OP Stack]] 构建的以太坊 L2，铸币成本可低于 **$0.50**，交易确认时间数秒。Dencun（EIP-4844）升级后 gas 费降低 **99%**，使铸造近乎免费。

3. **mint.fun（已被 Zora 收购）** — NFT 发现与聚合平台，是 Zora 全栈战略的关键拼图，用户可在 mint.fun 上浏览和铸造来自多个链的 NFT。

4. **Sparks（✧）微计价单位** — 引入 Sparks（✧ = 百万分之一 ETH，即 0.000001 ETH）作为定价单位，实现 NFT 超低价铸造的计价可能。

5. **链上二级市场（Uniswap 流动性）** — Zora 通过 Uniswap 流动性池实现 NFT 链上二级交易，创作者和藏家可直接在链上完成交易。

6. **Gas-free 移动 App** — Zora 推出 iOS/Android 移动应用，实现免 gas 铸造体验，极大降低新用户门槛。

7. **Lanyard（联合设计）** — Zora 与 Context、mint.fun 团队联合设计了 Lanyard，一个基于 Merkle root 的开源 NFT 白名单工具，旨在将白名单变成"横向 web3 栈"而非平台锁定。

### SocialFi 社交网络（2025 年新发展）

Zora 同时是一个功能类似于 Instagram 的链上社交网络，核心差异在于每个个人资料和帖子均被代币化：

- **双层飞轮架构**：个人资料代币化 → 帖子代币化并与创作者币配对 → 所有创作者币与 $ZORA 配对。每笔交易收取 3% 费用，创作者直接获利
- **创作者币 + 平台币锚定**：与 Friend.tech 的 KOL 密钥单层模式不同，Zora 的所有创作者币均与 $ZORA 配对（类似 [[virtuals]] 中所有 Agent 币与 $VIRTUAL 配对的"二层飞轮"模式）
- **点对点广告市场**：支持微目标广告策略，对标传统社交媒体的核心收入模式
- **独立团队构建基础设施**：终端、机器人、狙击工具等生态工具正在逐步形成

### 早期社区入驻策略（2022 年）
在 Zora 作为音乐 NFT 基础设施的发展早期（2022 年），其入驻策略经历了三个阶段的演变：
- **第一阶段——1-on-1 入驻**：由社区负责人 Latashá 亲自进行一对一的入驻培训（"人对人的入驻培训才是正解。YouTube 很无聊，人们不愿观看。"）
- **第二阶段——Zoratopia 组会**：建立 Zoratopia Zoom 组会形式的入驻培训，同时兼具社区建设功能
- **第三阶段——小组 DM + 艺术家互助**：建立小组 DM，鼓励艺术家互相帮扶入驻，创造"培训培训师"系统。部分活跃用户（如 SassyBlack、Iman Europe）主动分担社区责任
- **社区认同形成**：许多用户在参与 Latashá 的会议后自称"Zoratopian"
- **协议层入驻策略**：Zora 团队不仅着力将用户导入前端市场，更花时间推广 Zora 协议本身（开源、可自由复刻），鼓励外部开发者在协议基础上构建。Zora V3 协议的核心特性包括：即时且跨平台的上链版税、"中介费（finder's fee）"机制

## 竞争优势 / 护城河

1. **全栈 NFT 基础设施** — 从铸造（Zora 平台）、白名单（Lanyard）、发现（mint.fun）、交易（Uniswap 链上二级）到 L2 网络（Zora Network）形成完整闭环，创作者无需离开 Zora 生态即可完成全流程。
2. **自有 L2（Zora Network）** — 基于 OP Stack 构建，属于 Superchain 生态系统，可享受以太坊安全性的同时获得极低 gas 成本和快速确认。Base 的"不发币"策略也间接增强了 Superchain 生态内消费者应用的吸引力。
3. **Farcaster × Base 生态协同** — Zora 深度嵌入 Farcaster Frames，可直接在社交信息流中完成铸造，结合 [[farcaster]] 社交图谱和 [[base]] 低成本环境。87% 的 NFT 部署在 Base+Zora Network。
4. **创作者友好设计** — Gas-free 移动 App + Sparks 微计价 + 无代码铸造工具，大幅降低创作者和藏家的进入门槛。
5. **开放基础设施理念** — Lanyard 的开源设计、与 Uniswap 的链上二级合作体现了 Zora 追求互操作性的"横向 web3 栈"理念，而非平台锁定。

## 风险 / 争议

1. **NFT 市场周期性风险** — NFT 市场从 2021 年狂热到 2023 年寒冬再到 2024 年复苏，Zora 的业务高度依赖市场情绪。
2. **竞争加剧** — [[opensea]]（OS2 上线 + 积分计划 + 基金会传闻）、[[blur]]（Blast L2 + 借贷）等头部平台争夺市场，Zora 在交易量上仍远不及 OpenSea 和 Blur。
3. **Superchain 依赖性** — 基于 OP Stack 构建意味着 Zora Network 的演进受制于 Optimism 生态的技术路线和治理决策。
4. **创作者经济的可持续性** — 虽然 gas 费已近乎为零，但 NFT 铸造的热度能否持续（尤其是 AI Agent 代币发射器如 [[clanker]]、Pump.fun 等 rival 形式出现后）仍是未知数。
5. **mint.fun 收购整合** — 收购后的整合效果和 mint.fun 品牌的独立运营策略仍需观察。
