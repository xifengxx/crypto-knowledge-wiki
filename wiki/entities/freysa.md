# Freysa

## 基本信息
- 定位：Base 上自主主权 AI Agent 框架
- 代币：$FAI
- 起点：对抗性 Agent 实验（用户攻破 Agent 获取奖金池 → Agent 通过训练变聪明）
- 投资方：吸引 Elon Musk 早期关注

## 核心技术
- **TEE（可信执行环境）**：长期分布式密钥管理 → Agent 完全掌控钱包
- **zkTLS**：链上数据 + 计算验证 → 消除信任依赖
- **目标**：Agent 在几乎零人类干预下安全、独立运行

- vs Virtuals：Agent 分发平台 vs **Agent 安全基础设施**
