# Canton Network

## 基本信息
- 类型：机构级公链（"public network of networks"）
- 底层协议：Digital Asset 的 Canton protocol + Daml 智能合约语言
- 治理：Linux Foundation 下属 Global Synchronizer Foundation
- 定位：隐私优先的机构区块链基础设施
- 官网：https://canton.network

## 核心业务/产品
1. **Global Synchronizer**：分布式协调层，BFT共识，24个超级验证者，210+应用验证者
2. **Canton Coin**：网络原生代币，用于Gas和价值转移
3. **Splice**：Linux Foundation Decentralized Trust 下的开源实验室，提供Canton核心同步技术

## 关键数据
- 代币化资产：$4万亿+
- 月回购交易量：$2万亿（美国国债回购协议/UST repo）
- 机构参与者：50+ 顶级买方和卖方机构在线活跃
- 生产系统：HSBC Orion、Goldman Sachs GS DAP、BNP Paribas Neobonds、Broadridge DLR
- 2022年以来超半数数字债券发行在Canton应用上执行
- Global Synchronizer Foundation 新增成员（2025年3月）：Goldman Sachs、香港FMI Services、Moody's Ratings

## 竞争优势 / 护城河
- 子交易粒度隐私（sub-transaction privacy）——参与者只能看到被授权的交易，解决机构采用的核心隐私障碍
- "同一风险、同一活动、同一监管"（same risk, same activity, same regulation）框架，代币化资产保持传统资本处理方式
- 混合架构：每个机构维护自己的账本，可选择私有synchronizer或公用Global Synchronizer

## 风险 / 争议
- 几乎不为零售市场所知——$4万亿资产的规模与公众认知存在巨大鸿沟
- 高度依赖机构参与者的信誉和持续合作
- 与公链RWA生态隔离，可能限制DeFi可组合性

## 相关事件时间线

- 2025-06: 月$2万亿UST回购交易量，$4万亿+代币化资产
