# HoloworldAI (AVA)

## 基本信息
- 类型: AI Agent 3D 视听框架
- 关联项目: @AVA_holo（旗舰 Agent）, @HoloworldAI（框架本体）
- 赛道: AI Agent / 数字人 / 3D Avatar
- 生态: 多平台（Twitter, 3D 环境）

## 核心业务/产品
推出首个 3D 视听框架，让 AI Agent 拥有 3D 身体、语音功能以及更鲜明的个性化特征。与传统纯文本 Agent 不同，Holoworld 的 Agent 具备视觉外观和音频交互能力，拓展了 Agent 在娱乐、社交和虚拟世界中的使用场景。

## 关键差异化
- **3D 身体**: Agent 不再是纯文本框，具备可视化形象
- **语音交互**: 支持自然语音输出，增强交互沉浸感
- **鲜明个性**: 框架层面支持 Agent 个性化定制，不止于功能

## 产品细节（来自 Bankless 2024.11）
- **孵化方**：Binance 孵化
- **Agent Market**：部署于 Base 链，社区共同创建和货币化 IP
- **盈利模式**：会员制、品牌合作、代币化互动
- **部署平台**：群聊、私信、Twitter、Telegram、Discord

### 三种预设模板
1. **Memecoin Shiller**：全天候推广指定 Meme 币的 Agent
2. **Market Wizard**：集成 DeFiLlama 和 CoinGecko，提供实时市场数据、价格追踪和 DeFi 见解
3. **Roleplay Companion**：专注沉浸式叙事

### 五步创建流程
1. 选择从零开始或使用模板
2. 定义角色大脑（名称/昵称/分类/简介/语音/头像/可见性）
3. 塑造性格（示例对话/问候语/场景设定）
4. 装备知识库（PDF/文本/markdown/URL/Lorebook/关键词触发）
5. 设计 3D 头像

## 在 AI Agent 生态中的定位
代表 AI Agent 从"纯文本/对话"向"多媒体/沉浸式"演进的典型案例。与音乐 Agent（zerebro）、直播 Agent（blockrotbot）、动漫 Agent（Lucy）、影视 Agent（KWEEN）共同构成 2024 年 Agent 形态多样化的标志性项目。Binance 孵化和"下一个迪士尼"的定位使其区别于其他纯技术导向的 Agent 平台。
