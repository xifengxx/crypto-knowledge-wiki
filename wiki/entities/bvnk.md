# BVNK

## 基本信息
- **类型**: 企业级稳定币支付基础设施服务商
- **赛道**: 稳定币支付 / B2B 资金管理 / 出入金中间件
- **商业模式**: 为企业提供 API 集成，自动路由交易至最快/最便宜/最可靠的支付通道
- **关键数据**: 处理超过 $100 亿美金年化交易额，年增速 200%，估值 7.5 亿美金

## 核心业务/产品
- 企业级支付基础设施 API，使稳定币集成到企业现有工作流程
- 跨境商业支付平台
- 企业账户（持有和交易多种稳定币和法定货币）
- 商户服务（接受客户稳定币支付）
- 多轨解决方案：将本地银行、加密流动性提供商和法币下链结合到单一支付引擎
- 嵌入式 KYC/KYB 解决方案

## 关键数据
- 年化处理交易额 $100 亿+（2025 年 Q1）
- 年增速 200%
- 估值 7.5 亿美金
- 客户覆盖非洲、拉美、东南亚等新兴地区
- 典型客户案例：非洲/拉美本地支付场景

## 竞争优势 / 护城河
- **自动化路由**：自动将资金通过"最快、最便宜、最可靠的通道"进行路由，实时优化每一笔交易，企业无需手动协调多个中介
- **新兴市场深耕**：在传统银行基础设施薄弱的地区建立了稳定币出入金通道
- **一站式方案**：解决企业大规模采用稳定币时需手动协调流动性提供商、兑换合作伙伴和本地支付渠道的痛点，通过自动化整个支付工作流程降低摩擦

## 风险 / 争议
- 高增长依赖新兴市场监管环境——非洲/拉美/东南亚多地监管尚不明确
- 竞争格局分散，多家支付服务商（如 Bridge/Iron/Juicyway）在相同赛道竞争
- 业务高度依赖稳定币整体采用率——若监管收紧可能导致新兴市场支付通道受阻
