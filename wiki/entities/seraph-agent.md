# Seraph

## 基本信息
- 类型: AI Agent 评价系统
- 生态: Virtuals Protocol（Base 链）
- 定位: 为 AI Agent 生成信任分数和 AI 分数，判断 Agent 内容的可信度和人工生成程度
- 代币: SERAPH（推测，文章未明确代币名）

## 核心业务/产品
- **多维评价体系**: 整合三个数据源进行综合评价
  - **Bittensor**: 访问特定子网判断内容的 AI 生成可能性
  - **Kaito**: 获取事实、见解和情感分析
  - **用户交互数据**: 优化评分算法和 Agent 行为
- **信任分数 / AI 分数**: 帮助用户判断 Agent 输出是否可信、是否 AI 生成
- **模块化架构**: 各组件可独立更新、替换或扩展，支持开发者/社区成员改进评分标准、纳入新数据源、调整参数

## 关键数据
- 最高市值: $55M（约 5500 万美元）
- 当前市值: $13.9M（约 1390 万美元，2024.12.17 数据）

## 竞争优势 / 差异化
- 不做"另一个 AI KOL"，而是做 AI Agent 生态的评价基础设施——类似于 AI Agent 领域的"信用评级机构"
- 模块化设计使评分系统可随 Agent 生态演进，具有长期适应性

## 风险 / 争议
- 市值从 ATH $55M 下跌至 $13.9M（-75%），跌幅显著
- "AI 评价 AI"的准确性尚未被独立验证
- Bittensor 和 Kaito 作为数据源的可靠性依赖第三方
