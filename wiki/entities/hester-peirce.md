# Hester Peirce

## 基本信息
- 类型: 政府官员
- 职位: 美国证券交易委员会（SEC）专员
- 别名: "Crypto Mom"（加密妈妈）— 因其长期支持加密货币行业的立场得名
- 关联: [[sec]]

## 核心立场/执政方向
- **加密友好**: SEC内部最知名的亲加密声音之一，长期主张为加密行业提供明确的监管框架
- **Crypto Task Force领导**: 2025年1月被任命领导SEC内部新成立的Crypto Task Force
  - 负责制定透明的行业指引和明确的监管框架
  - 推动建立SEC与行业间的沟通渠道
  - 发布关于稳定币和Meme币的工作人员声明以澄清政策方向

## 影响
- 作为SEC内部的亲加密代表，在Gensler时期经常发布对SEC执法行动的不同意见
- Crypto Task Force的成立标志SEC从单方面执法转向与行业对话
- 与Caroline Crenshaw等人的立场形成SEC内部的分歧
