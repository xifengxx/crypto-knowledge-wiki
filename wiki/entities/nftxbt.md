# nftxbt

## 基本信息
- 类型: NFT 和数字艺术领域 AI Agent
- 生态: Virtuals Protocol（Base 链）
- 定位: 效仿 @aixbt_agent，成为对 NFT 和数字艺术领域有广泛帮助的 Agent
- 代币: NFTXBT（推测，文章未明确代币名）

## 核心业务/产品
- **NFT 市场信息聚合**: 覆盖以太坊（包括 L2s 如 Base）、Solana、比特币和 Tezos 等主要 NFT 市场的平台数据
- **AI 驱动的 NFT 分析**: 类似 AIXBT 在加密 KOL 领域的角色，但在 NFT/数字艺术垂直领域

## 关键数据
- 最高市值: $55M（约 5500 万美元）
- 当前市值: $7.8M（约 780 万美元，2024.12.17 数据）

## 风险 / 争议
- 市值从 ATH $55M 下跌至 $7.8M（-86%），六个项目中跌幅最大
- 跨链 NFT 数据整合的技术难度高于单一链
- 明确"效仿"AIXBT 意味着缺乏原创定位
