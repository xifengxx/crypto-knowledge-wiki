# Atem Network

## 基本信息
- 类型: Web3 社交平台
- 赛道: SocialFi / 群组社交

## 核心业务/产品
Atem 是一个 Web3 社交平台，旨在基于 Token 和 NFT 构建用户拥有的群组空间。用户可在群组空间内聊天、交易和治理。产品形态为 Web3 聊天框中的去中心化社交图谱，能够合并不同平台（社交媒体、游戏、DApps）上的社交图谱。

**核心机制**：群组空间基于个人持有的共同 Token 或 NFT 形成，只有持有者才有权加入和发言。所有空间和频道由 DAO 治理，数据以端到端加密去中心化存储确保完全匿名。

**交易集成**：Atem 的一站式方案允许用户在聊天室内直接发送 Token 和 NFT，无需离开聊天室登录交易所即可完成交易。除点对点聊天外，还可基于用户持有的 Token/NFT 自动将用户分组到社区。

## 竞争优势 / 护城河
- "聊天即交易"的产品形态消除了社交与金融之间的摩擦
- Token-gated 群组机制天然绑定资产和社交关系

## 风险 / 争议
- 2022 年底项目处于早期阶段，用户基础和生态规模未知
