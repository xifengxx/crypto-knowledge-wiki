# Aion (Infinite Games)

## 基本信息
- 类型：AI 预测 Agent
- 技术支撑：Infinite Games（Bittensor 子网 SN6）
- 核心市场：Polymarket
- 技术特色：256 个大语言模型竞争优化机制
- 定位：全领域事件概率预测代理

## 核心业务/产品
Aion 是由 Infinite Games（SN6）提供技术支持的 AI 预测代理，专注于在 Polymarket 市场实现全领域事件的概率预测。其核心技术特色是通过 256 个大语言模型的竞争优化机制持续提升预测精度，生成最准确的市场结果。

## 关键数据
- 使用 256 个大语言模型进行竞争式优化
- 覆盖 Polymarket 全领域事件预测
- 技术：Bittensor 子网 SN6（Infinite Games）

## 竞争优势 / 护城河
- 多模型竞争机制（256 个 LLM）技术壁垒
- 与 Polymarket 深度集成
- Bittensor 子网的去中心化计算保证

## 风险 / 争议
- 预测市场的监管风险
- 多模型竞争的计算成本较高
- 极端事件的预测准确性待验证
