# Visa

## 基本信息
- 类型：全球卡支付网络（卡组织）
- CEO：Ryan McInerney
- 定位：传统支付基础设施向 Agent 经济延伸的代表，不发行新协议，不碰稳定币，而是将现有信用卡信任网络延伸到 Agent
- 关键高管：Jack Forestell（首席产品官和战略官）
- 上市：NYSE: V

## Agent 支付相关产品/项目
- **Trusted Agent Protocol（TAP）**：用密码学签名给 Agent 发凭证，让 Agent 可以基于 Visa 信用卡网络完成支付
- **Agentic Ready 项目**：已拓展到拉美和亚太，帮助商户和金融机构准备 Agent 支付能力
- **Visa + Lightspark 合作**：支持稳定币和比特币余额的 Visa 借记卡，覆盖 100+ 国家，用链上资产作为余额，Visa 网络作为花钱渠道

## 稳定币/区块链支付基础设施（2025.04 四大战略）

2025 年 4 月 30 日，Visa 发布区块链和稳定币战略路线图，聚焦四大领域：

1. **结算基础设施现代化**：自 2021 年起试点 USDC 结算结算（累计 $2.25 亿+）。发卡行和收单行可直接用 USDC 而非美元通过 VisaNet 结算。[[crypto-com]] 案例：预付时间从 8 天降至 4 天，外汇手续费降至 20-30 bps
2. **全球汇款基础设施（Visa Direct）**：将稳定币集成到 Visa Direct P2P 汇款服务中。2025 年 5 月投资 [[bvnk]]（稳定币基础设施初创企业）
3. **可编程数字货币（VTAP）**：2024 年 10 月推出的 Visa Tokenized Asset Platform，使银行可发行和管理法币锚定数字代币（稳定币、代币化存款），支持智能合约自动化。已与西班牙 BBVA 银行沙盒测试，计划 2025 年在以太坊公链启动试运行
4. **稳定币出入金卡**：与 [[bridge-stablecoin]]（Stripe 收购）、Baanx、Rain 合作提供稳定币卡发行方案。Visa 卡累计处理 $1000 亿+ 加密购买和 $250 亿+ 加密消费。Bridge 方案首批覆盖阿根廷、哥伦比亚、厄瓜多尔、墨西哥、秘鲁、智利

## 关键数据
- 平均交易额：从 2015 年的 55 美元降到了 2026 年的 45 美元（CEO 2026 年财报电话会数据）
- 交易笔数：翻了三倍，达到 3000 亿笔（2026 年）
- 已处理「数百笔」Agent 交易（截至 2026 年 5 月）
- 每年处理超过 3000 亿笔交易的全球网络
- x402 基金会创始成员

## 竞争优势 / 护城河
- 全球最大的卡支付网络，商户接受度无可匹敌
- 将现有信用卡信任网络延伸到 Agent，不要求商户和用户改变支付习惯
- CEO 明确提出 Agent 支付会推动交易向着「金额更小、频次更高、笔数更多」的方向发展，视其为结构性增长机会

## 风险 / 争议
- Agent 交易量极小（数百笔），商业验证尚在早期
- 在 Agent 支付领域面临 Mastercard、Stripe、加密原生协议的多重竞争
