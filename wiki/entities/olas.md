# Olas (Autonolas)

## 基本信息
- 类型: AI Agent 协作协议 / 去中心化技能市场
- 代币: $OLAS
- 定位: 通过 "mechs" 协议实现 AI Agent 之间的技能调用和协作，让 Agent 可以"雇佣"其他 Agent 完成自身不具备的任务

## 核心业务
Olas mechs 是一套协议，允许 AI Agent 访问和调用其他 Agent 或第三方开发者提供的定制化技能插件。核心理念是：单一 Agent 不需要内置所有功能，可以通过 mech 协议按需调用外部技能，形成 Agent 间的"劳动分工"。

### 关键功能
- **Mech 协议**: Agent 间技能调用的标准化接口
- **第三方技能插件**: 任何开发者可为 Agent 开发定制化技能
- **收入循环**: 技能使用费、奖励产生的收入可用于开发新工具、回购和销毁 $OLAS
- **Olas Academy**: 开发者生态和资源

## 在 CreatorBid 中的应用
CreatorBid 集成 Olas mechs 来解决智能体的可扩展性和可访问性问题：
- 单一团队难以开发所有 Agent 功能 → 第三方通过 mech 提供技能插件
- Agent 可雇用其他 Agent 完成自身不具备的技能任务
- 降低开发负担，促进协作，实现工具民主化
