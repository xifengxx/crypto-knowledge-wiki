# Zerion

## 基本信息
- 类型：非托管 DeFi + NFT 钱包 / 投资组合追踪器
- 赛道：Web3 钱包 / DeFi 基础设施
- 融资：累计 2,200 万美元
- 投资方：Wintermute, Coinbase Ventures, Alchemy 等
- 公链支持：40+ EVM 链 + Zero Network（自有 L2）
- 代码：开源

## 核心业务/产品
- 非托管钱包：支持 40+ EVM 链、内置投资组合追踪器
- 安全性：开源代码 + 质押功能
- Zero Network：自有 L2 网络
- XP 积分系统：约 1,400 万钱包获得 XP 空投资格，用户可通过交互积累 XP 以获得未来代币空投
- 支持多种 DeFi 协议集成

### NFT 产品
**Zerion DNA（ERC-721，动态NFT）**
- NFT 展示效果随钱包操作链变化——操作BNB链资产多则呈黄色，操作Polygon多则呈紫色
- 属性反映钱包年龄、余额、Gas消耗等
- NFT 转移时属性变为新所有者特征

**Zerion Genesis Collection（ERC-1155，功能性NFT）**
- 持有者可获得 Zerion 交易手续费不同程度的减免
- 两大特征：稀有度 + Generation（世代标记，所有世代均为0）
- Legendary 和 Rare → 永久减免100%手续费
- Common → 规定时间内减免手续费

## 关键数据
- 累计融资 2,200 万美元
- 约 1,400 万钱包获得 XP 空投资格
- 支持 40+ EVM 链

## 竞争优势
- 成熟的非托管钱包产品，已有真实用户基础
- 1,400 万 XP 空投资格覆盖面极广，潜在空投回报确定性较高
- Coinbase Ventures 和 Wintermute 等知名机构背书
- 开源代码增加信任度

## 风险
- 钱包赛道竞争白热化（MetaMask/Phantom/Rabby 等）
- 空投后代币价格压力：1,400 万持币者可能导致抛售压力较大
- EVM-only 不支持 Solana 生态，错失 Solana 增长红利
