# Surf Protocol

## 基本信息
- 赛道：衍生品交易 / 永续合约
- 所属生态：Merlin Chain (BTC L2)
- 投资方：ABCDE、Inception Capital；入选币安 MVB 加速器计划
- 团队：来自 Amber、火币等机构的前核心成员
- 测试网上线：2024年3月20日

## 核心业务/产品
Surf Protocol 是无许可 AMM 衍生品交易协议，专注 BTC L2：

1. **永续合约交易**：最高 50x 杠杆，初期上线 $BTC/$ETH/$ORDI/$SATS 等主流币种
2. **单资产 LP**：LP 以单一资产提供流动性（无需双币配对）
3. **LP 凭证资金再利用**：提升资本效率
4. **聪本位保证金模式**：以 BTC 最小单位（聪）计价，原生适配 BTC 生态
5. **点对池模式**：类似 GMX 的 GLP 池
6. **盘前交易市场**：未发布项目的盘前交易
7. **产品路线扩展**：盘前交易 → 现货杠杆交易 → 期权

## 关键数据
- 最高杠杆：50x
- 暂无可追溯的链上数据（2024.03）
- 未公布代币发行计划

## 团队背景
团队由 Amber、火币等机构前创始人及核心成员组成。入选币安 MVB（Most Valuable Builder）加速器计划第七季。

## 竞争优势 / 护城河
- 币安 MVB 背书，赛道稀缺（Merlin Chain 首个原生衍生品项目）
- 多个 BTC 生态原生创新设计（聪本位、单资产LP）
- 盘前市场是差异化功能，具有 Meme 币/新代币的发射场景

## 风险 / 争议
- **最早期阶段**：仅测试网，无链上数据，无代币计划
- 衍生品赛道竞争激烈（GMX/GNS/dYdX + 各链竞品），Surf 在 Merlin 生态内有先发优势但生态外无护城河
- 50x 杠杆在 BTC L2 上的清算风险（L2 性能/延迟是否支撑高杠杆？）
