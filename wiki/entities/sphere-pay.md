# Sphere Pay

## 基本信息
- 赛道：Web3 支付基础设施 / 数字货币支付 API
- 定位：专为数字货币设计的一站式支付 API，连接普通用户与稳定币
- 商业模式：不收取软件使用费，从每笔交易中收取 0.3% 固定费用

## 核心业务/产品

### 支付 API
- 为商家提供数字货币支付集成方案
- 提供可定制或预设的前端和用户体验
- 多种定价模式以满足不同商家需求

### 目标客户
- 小型企业（交易量不大或启动成本低的理想选择）
- 希望接受加密货币支付的传统商家

## 关键数据
- 费率：每笔交易 0.3% 固定费用
- 软件使用费：$0（免费开放）

## 竞争优势 / 护城河
- 0.3% 固定费率远低于传统信用卡（2-4%）和 PayPal（2.9% + $0.30）
- 无软件使用费降低商家准入门槛，对小企业友好
- 可定制前端使商家能保持品牌一致性

## 风险 / 争议
- 文章未提供实际用户数或交易量数据
- 支付 API 赛道竞争激烈（Stripe 已支持 USDC 支付、Coinbase Commerce 等）
- 稳定币出入金摩擦问题未解决——Sphere 只管链上部分
- 2024 年 Q4 Sphere 获得 $5M 战略融资并与 Etherfuse 合作（来源：Solana Q4 报告），但该进展未在本文中体现
