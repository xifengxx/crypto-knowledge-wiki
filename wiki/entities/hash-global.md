# Hash Global

## 基本信息
- 类型：加密投资管理公司
- 创始人：James(KK) Shen
- 团队成员：Jessica Feng（Investment Manager, Hash Global BNB Fund）
- 定位：专注于价值功能性代币研究与投资的机构，尤其深度跟踪BNB
- 核心产品：Hash Global BNB Fund

## 核心业务/产品
- **BNB基金**：管理以BNB为核心资产的投资基金
- **估值研究**：自2019年起发布基于货币方程式（MV=PQ）的价值功能性代币估值系列报告，已发布五期
- **BNB节点质押**：参与币安节点质押业务

## 关键研究输出
- 2019年首次提出以货币方程式为基础的价值功能性代币估值框架
- 截至2025年8月已发布五期BNB估值报告
- 估值模型已得到市场初步验证（CZ本人曾评论："Hash Global前几次的预估都实现了"）
- 获得复星集团联合创始人梁信军、原蚂蚁金服首席战略官陈龙、诺亚财富创始人汪静波、凯基国际财富管理主管魏志杰等传统金融界人士的背书

## 竞争优势 / 护城河
- 长期专注单一资产（BNB）的深度研究，形成专业壁垒
- 最早将货币方程式引入加密资产估值领域的机构之一
- 传统金融背景（创始人James Shen及团队背景深厚）
- 获得币安创始人CZ的公开认可

## 风险 / 争议
- 本报告披露持有BNB资产，存在持仓利益冲突（"截至本报告发布日，Hash Global 及其管理的基金持有部分BNB资产，相关分析和观点可能受到持仓影响"）
- 估值模型依赖较多假设（流转速率V的稳定性、长期增长率等），预测精度存疑
