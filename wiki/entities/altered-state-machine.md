# Altered State Machine (ASM)

## 基本信息
- 类型: AI代理协议
- 赛道: AI + Crypto / 链上AI智能体
- 核心架构: 代理 = Form（外形/模型） + Brain（大脑NFT）
- 概念验证: AIFA（AI足球游戏）
- 技术栈: Unity、IPFS、Training Gym

## 核心业务/产品
Altered State Machine (ASM) 是一个去中心化的AI代理协议。ASM中的代理由两部分组成：
- **Form（外形）**：代理的图像或3D模型
- **Brain（大脑）**：基础NFT，包含"基因组"矩阵（一组随机基础值）和"记忆树"（记录状态变化）

GPU云计算提供商使用硬件为特定ASM应用运行训练算法，输出为记忆（memory），以ONNX格式记录在记忆树中，修改价值矩阵以提高该应用场景的技能集。这种训练模式类似PoW区块链的挖矿机制——第2层验证者质押ASM投票权以决定哪些记忆被写入。

## 概念证明
AIFA（AI Football）是ASM的第一个概念验证游戏，使用Unity、IPFS和示例Training Gym的组合。ASM计划将代理应用扩展到更广泛的场景。

## 计划的应用场景
- DeFi交易代理
- 游戏角色代理（NPC）
- 聊天机器人
- 数字助理

## 在AI Agent生态中的定位
ASM是2022年对"去中心化AI训练+链上AI代理"的最早系统化尝试之一。其通过GPU挖矿架构训练AI的思路，预见了后来去中心化AI算力市场（如io.net、Akash Network）的兴起。但ASM的复杂度（链上AI训练的实际成本）使其在2022年阶段以概念验证为主，后续发展有限。
