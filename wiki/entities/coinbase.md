# Coinbase

## 基本信息
- 类型：上市加密交易所 + 基础设施公司 (NASDAQ: COIN)
- 成立：2012年 (Brian Armstrong + Fred Ehrsam)
- 关键产品：Coinbase 交易所 / Base L2 / cbBTC / Coinbase Custody

## 核心业务/产品
- **Coinbase 交易所**：全球最大合规加密交易所之一
- **Base L2**：基于 OP Stack 的以太坊 L2（2023年8月上线/1.5年成为ETH第一L2）
- **cbBTC**：Coinbase 托管的比特币包装代币（$24亿市值/20万持有者）
- **Coinbase Custody**：机构级加密托管
- **BTC ETF 托管方**：BlackRock/Fidelity/Grayscale BTC/ETH ETP 的主要托管方
- **CeDeFi 双轨策略（2025年6月公布）**：在 State of Crypto Summit 2025 上宣布将 DeFi 交易直接集成到主 App 中，用户无需打开独立钱包即可交易链上资产。面向零售提供无缝链上集成（DEX 交易、自托管），面向机构提供 **Verified Pools**（仅限 KYC 验证参与者，合规高保障链上流动性池）。以 Base L2 为核心链上基础设施，实现"DeFi Mullet"模式——平台获得发放费+利差收入，用户获得链上自主权

### Coinbase Wallet → Base App（2025 年 7 月更名）
2025 年 7 月 18 日，Coinbase 在 Base "A new day one" 活动中正式将 Coinbase Wallet 更名为 Base App，从单一加密钱包转型为涵盖资产、支付和社交的 Web3 超级聚合应用。详见 [[来源_2025-07_Coinbase_Wallet_Base_App_Web3超级应用_深潮TechFlow]]。

### Coinbase Wallet（MEME 交易功能，更名前）
- **MEME 资产发现**：支持直接搜索或通过热门 Swap 榜单查看 Base 链等生态的热门代币，项目附带社媒链接与合约信息
- **简易闪兑功能**：支持 Base、Ethereum 等链上的代币互换，可直接完成小额 MEME 代币交易
- **合约风险提示**：在交易前会显示合约验证状态及潜在风险
- **内置 DApp 浏览器**：可访问 LeetSwap、Uniswap 等常见 DEX

差异化亮点：对 Base 链生态的天然适配。默认支持 Base 网络，简化资产转入与钱包连接流程。但功能偏轻量，对于高频频繁交易的玩家辅助能力有限。

来源：[[来源_2025-04_MEME打金_信息差_钱包对比_深潮TechFlow]]
- **x402 协议**：2025 年 5 月与 Cloudflare 联合发布的开源 Agent 自主支付协议，基于 HTTP 402 状态码。2026 年 4 月捐赠给 Linux 基金会，成为支付领域基础标准
- **AgentCore Payments**：与 AWS 合作推出的 Agent 支付 API 微支付解决方案，开发者集成 Coinbase 或 Stripe Privy 钱包
- **Coinbase AgentKit**：让物理世界 Agent 用加密货币自主支付的工具包（如机器狗充电场景）

## 关键数据
- Base: ETH 第一 L2（协议收入$7000万 vs Arb $6000万）
- cbBTC: $24亿市值（挑战 WBTC $130亿）
- BTC 储备: ~98万 BTC（$600亿+，用于 cbBTC+ETP 托管）
- Base 生态：七次破圈/Virtuals $50亿 AI Agent 生态
- 2024年底持有超90亿美元现金及现金等价物
- 2025年以29亿美元收购Deribit，为加密史上最大并购
- **交易费率**：从 2.5% 峰值下降至 1.4%（Artemis 2025.06 分析）
- **美元计价市场份额**：从峰值 60% 降至 ~50%（Meme 币季节最低 32%）
- **USDC 收入净保留**：名义获得 60% 总 USDC 收入，但约 43% 作为收益率转付用户，实际净保留约 34%（约 1.71 亿美元/季）
- **USDC 收入占比**：仅约 15% 总营收，远非纯粹的 Circle/USDC 投资替代品
- **Robinhood 竞争**：Robinhood 零售收入从 Coinbase 的 32%（2022）升至 76%（2024 Q4）
- **衍生产品月交易量**：超 3000 亿美元（2025 Q1 数据）
- **Base 排序器利润**：约 100 万美元/周，利润率约 90%，占所有 L2 毛利润 75%+
- **活跃用户**：2025 年峰值仅为 2021 年峰值的 70%
- **分步估值（SOTP）**：Artemis 估算合计约 957 亿美元（交易所 807 亿 + USDC 290.7 亿 + Base 18.6 亿 + 现金 80 亿），但市场合理反映了结构性风险折价
- **比特币 ETF 冲击**：一年内超 1000 亿美元 AUM，部分取代 Coinbase 作为合规加密入口的地位
- **代币数量激增**：从上轮周期 <100 万增至 >3000 万，DEX 在 Meme 币交易中占绝对优势

## 竞争优势 / 护城河
- 合规+监管信任（美国上市加密公司）
- 98万 BTC 储备 → cbBTC+ETP 托管无法复制
- Base L2 = Coinbase 用户入口（1亿+ KYC 用户 → 链上流量）
- "Coinbase → Base" 是最成功的 CEX→L2 转化路径

## 风险 / 争议
- 监管风险（SEC/CFTC 执法）——但 Trump 任下撤销对 Coinbase 执法，降低了合规门槛，反而削弱了 Coinbase 的监管护城河
- 核心交易所业务三重挤压：比特币 ETF 分流机构资金入口、DEX/Pump.fun 等工具抢占 Meme 币零售流量、Robinhood 等传统金融平台在宽松监管下竞争加密业务
- 费率与市占率双降：交易费率从 2.5% 降至 1.4%，美元市场份额从 60% 降至 ~50%
- USDC 经济被高估：名义 60% 分成实际上仅净保留约 34%（43% 转付用户），利率敏感——降息将严重压缩该收入
- Base 去中心化程度（单一排序器）
- cbBTC 中心化托管 vs WBTC 去中心化争议
- Base vs Solana 的用户规模差距：Solana 日活用户为 Base 3 倍、日交易量为 7 倍
- 活跃用户增长停滞：2025 年峰值仅为 2021 年的 70%

## 并购历史（M&A Timeline）
Coinbase是加密行业最活跃的收购方之一，其收购战略经历了从托管到衍生品的系统化扩展：

| 年份 | 收购对象 | 金额 | 战略目的 |
|------|---------|------|---------|
| 2018 | Earn.com | 未披露 | 获取用户基础和代币分发能力 |
| 2019 | Xapo托管业务 | 未披露 | 奠定Coinbase Custody基础 |
| 2020 | Tagomi | 未披露 | 推出机构交易套件Coinbase Prime |
| 2021 | Agara | $4000-5000万 | 获取印度AI/NLP工程人才 |
| 2022 | FairX | 未披露 | 布局美国合规衍生品市场 |
| 2023 | BRD Wallet | 未披露 | 加强移动钱包战略和用户引导 |
| 2025 | Deribit | $29亿 | 巩固全球衍生品市场地位，获取期权交易量 |

- 2025年收购Deribit为加密史上最大并购交易，对价$29亿，高于谷歌2006年收购YouTube的$16.5亿
- Coinbase的并购策略遵循"能力/生态系统扩展"模式：Xapo（托管）→Tagomi（机构交易）→FairX/Deribit（衍生品）

## 2025年重大事件
- **2025年5月**：成为首家入选标普500指数的加密资产原生公司，为整个加密行业赢得广泛的合法性背书，推动养老金基金、保险公司和资产管理机构将加密资产纳入标准投资组合
- **2025年第二季度**：机构投资者在合规加密资产领域的配置资金同比增长超过40%，Coinbase入选标普500是重要推动因素之一
- **2025年6月17日**：Coinbase首席法律官Paul Grewal表示已向SEC申请no-action letter，希望获得代币化股票产品的合法豁免权。计划一旦获批，依托Base L2链上发行股权代币，实现T+0结算、碎股拆分、实时分红等流程（路透社报道）。此为Robinhood已在欧洲落地的代币化股票的美国版本布局。
- **Base L2与Shopify集成**：联合Shopify推出USDC结账功能，推动稳定币商业支付在电商场景落地
- **Coinbase One Card**：携手美国运通推出首张加密信用卡，打通加密资产在消费端的应用
- **永续合约与衍生品**：在美国推出CFTC合规的永续合约功能，并完成对期权交易所Deribit的收购（2025年，$29亿），加速衍生品市场布局
- **间接成为Circle IPO最大赢家**：Coinbase持有Circle股权，通过USDC储备获得一半剩余收入（"躺赚"50%），在CRCL暴涨超600%的过程中显著受益

## Agent 支付基础设施（2025-2026）
- **x402 协议创建者**：2025 年 5 月与 [[cloudflare]] 联合发布 x402 协议（基于 HTTP 402 状态码），让 Agent 在 HTTP 请求周期内用 USDC 签名付款、无需账号或 API 密钥。2026 年 4 月将 x402 捐赠给 Linux 基金会，22 个创始成员涵盖 AWS/Google/Microsoft/Visa/Mastercard 等全球巨头
- **AgentCore Payments**：与 AWS 合作推出，让跑在 AWS 云上的 AI Agent 通过 Coinbase 或 Stripe Privy 钱包在任务流中自主付费。第一阶段聚焦 API 微支付
- **Coinbase AgentKit**：用于物理世界 Agent 支付。2026 年 2 月，OpenMind 的机器狗 Bits 通过 AgentKit 用 USDC 纳米支付完成充电费结算——全程无人类在场
- **Brian Armstrong 关键判断**：「很快，做交易的 AI Agent 数量会超过人类。它们开不了银行账户，但可以拥有一个加密钱包。」

## 2025年监管里程碑
- **2025年2月**: SEC在Trump任下同意与Justin Sun联合申请60天暂停诉讼
- **2025年5月**: SEC试图减轻Ripple案1.25亿美元罚款但被法院拒绝
- **2025年**: SEC撤销对Coinbase的执法诉讼（此前Gensler时代指控Coinbase作为未注册交易所允许未注册证券二级市场交易），Trump任命的主席Paul Atkins领导的SEC转向Crypto Task Force框架，对行业采取合作态度

## 组织变化
- 2024 年 10 月：Jesse Pollak 进入 Coinbase 八人核心高管团队，同时统领 Base + Coinbase Wallet
- 目标：加速 Base 与 Wallet 整合，让链上业务成为 Coinbase 的主要业务
- Jesse 给 Coinbase Wallet 当前体验打 4/10，目标是 10/10
