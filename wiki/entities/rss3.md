# RSS3

## 基本信息
- 类型: 去中心化数据索引和分发协议
- 衍生自: RSS 协议

## 核心业务/产品
RSS3 允许用户基于地址生成 RSS3 文件，并将自己的 Twitter、Mirror、即刻等社交平台关联到该文件。文件会实时同步用户的资产、内容和行为数据（交易、点赞和转发等），并将这些信息储存在 RSS3 的去中心化网络中。

开发者可在用户允许的情况下，通过不同 API 接口调取用户在不同平台上发布的内容，根据应用特性筛选展示不同信息。
