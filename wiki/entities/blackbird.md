# Blackbird

## 基本信息
- 定位：餐厅共享忠诚度计划 + 链上支付（"Web3 大众点评"）
- 创始人：Ben Leventhal（前Eater创始人/Resy联合创始人，20年餐饮科技经验；Resy 于 2019 年被美国运通收购，Ben 在 AmEx 工作一年后受 Fred Wilson 启发将忠诚度+支付模式搬上链）
- 链：Base（Coinbase L2）
- 代币/积分：$FLY（1 FLY = 1 美分，通过 USDC 在 Base 上以 1:100 购买；定位为平台内稳定币，不可交易）；$F2（治理代币，因 $FLY 定位稳定币而新增）
- 融资：Framework Ventures、Union Square Ventures（Fred Wilson，Coinbase 第一个机构投资人）

## 核心业务
- **FLY积分**：用户在合作餐厅消费赚取FLY，可兑换免费菜品/饮品/好位置；用 $FLY 支付获 10 倍积分返还
- **Blackbird Pay**：2024年7月在 Base 上线，支付费率 **2%**（行业平均 3-4%，节省 ~50%），支持 USDC 购买 $FLY 支付餐费，Blackbird 最终以美元结算给商家。包含美式"分单+单独签小费"功能
- **会员卡 NFT**：Base 上的 ERC-721 NFT，餐厅可通过 NFT 实现众筹
- 餐厅月费：**$89**
- 设计原则：完全隐藏加密元素，终端用户体验 = 传统忠诚度计划。"它不是一款 web3 应用，它是一款餐饮应用，而且是一款很棒的应用"

## 关键数据
- 钱包/会员卡：**40,056** 个钱包持有 **125,571** 个会员卡 NFT（Dune @jhackworth）
- 餐厅签到：**142** 家餐厅产生签到行为
- 第一年采用率增长：**10倍**
- 餐厅渗透率：**~0.6%**
- Blackbird Pay 费率：**2%**（vs 行业 3-4%）
- Framework Ventures联创：6个月未付咖啡钱（用FLY兑换）

## 商业模式：借鉴美国运通的闭环忠诚度系统
美国运通（AmEx）同时作为卡片发行方和商家收单方，在封闭忠诚度+支付系统上建立 **$1,700 亿**商业帝国：
1. AmEx 对商家收 2.5-3%（高于 Visa/MC ~2%）
2. 高费率支撑慷慨奖励 → 吸引高端客户
3. 高端客户高交易量 → 为高费率提供合理性
4. 高交易量产生更多积分 → 增强忠诚度和消费
5. 更多商家加入 → 正向循环

Blackbird 的差异：保留忠诚度运营精髓，但通过区块链降低支付费率（2% vs AmEx 2.5-3%），将零和博弈变为三方共赢。

## 增长飞轮（特洛伊木马策略）
低费率 → 更多餐厅 → 更多用户 → 更多 $FLY 需求 → 10x 积分返还等权益 → 更高忠诚度/消费 → 更大支付量 → Blackbird 从支付和 $FLY 网络中捕获价值。新用户不必了解 Crypto 即可丝滑进入，成为整个 Crypto 世界的新增量。

## 从应用到协议
$FLY（链上消费积分）+ Blackbird Pay（链上信用卡）可抽象为协议供其他行业使用：航空/酒店像对待信用卡积分一样对待 $FLY，奢侈品品牌对持有一定 $FLY 的用户开放新产品。

## 核心愿景
FLY = 餐饮业内保留的共享资本池。用户在一家餐厅赚FLY，在另一家花FLY，行业价值不外流到酒店/机票等

## 我的判断
消费级加密应用的标杆案例。"行业专家+加密工具"组合 > "加密原住民做垂直应用"。FLY不可交易的约束设计是聪明的——避开投机性，聚焦实际效用。Blackbird 证明了"消费类公司变支付公司"的元模式可以用 Crypto 复制——支付不是终局而是飞轮加速器。Ben Leventhal 前两次创业都成功卖出（Eater→Vox、Resy→AmEx），第三次是否能做长期独立公司是最大悬念。
