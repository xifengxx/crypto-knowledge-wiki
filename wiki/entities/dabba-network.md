# Dabba Network

## 基本信息
- 类型: 去中心化无线网络（DePIN）
- 赛道: 电信 / WiFi 接入
- 目标市场: 印度
- 底层链: Solana
- 部署模式: 与传统有线运营商合作的"托管部署"模式

## 核心业务/产品
Dabba Network 是以 Solana 为底层的印度市场专属 DePIN，通过与传统有线运营商合作的"托管部署"模式，在印度各地部署 Wi-Fi 热点，向用户提供高速、低价的互联网接入服务。

## 关键数据（截至2025年4月）
- 累计数据消耗: 8000 TB（3月至4月实现2倍增长）
- 设备销量增长: 29%
