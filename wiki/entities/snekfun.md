# Snek.fun

## 基本信息
- 类型：Meme 币发行平台（Pump.fun 仿盘）
- 区块链：Cardano
- 合作方：$SNEK（Cardano Meme 龙头）+ Splash（Cardano DEX）
- 预热时间：2024年7月底
- 正式上线：2024年9月初
- 定位：Cardano 链上首个专业 Meme 发射平台

## 核心机制
- **Bonding Curve 毕业门槛**：当某代币 75% 供应量被市场买入且市值达到 42,069 ADA 时，在 DEX Splash 上创建包含 25% 供应量的流动性池，并销毁相应 LP
- **LP 销毁设计**：通过销毁流动性提供者证明来增加代币稀缺性，理论上提高市场价值
- 整体机制与 Pump.fun 类似

## 关键数据
- 上线初期面临严重技术问题：钱包 API 超载，官方称每10秒有2万用户涌入
- 用户反馈：交易出现长达5小时的卡顿
- 生态龙头 $SNEK：2023年5月推出，2023年底前两个月涨幅13倍，市值一度突破$1.3亿；跌超70%后2024年9月初市值$500万，截止2024年12月初增长至$5亿

## 竞争优势
- 背靠 $SNEK 品牌——Cardano 生态最强的 Meme 文化符号，具有独立于平台的社区凝聚力
- Cardano 生态内无直接竞品（先发优势）

## 风险 / 争议
- 技术基础设施薄弱（钱包 API 无法承受高并发）
- Cardano 生态 Meme 流动性整体落后于 Solana/Base/BNB Chain
- ADA 的价格波动直接影响生态 Meme 吸引力
