# Courtyard

## 基本信息
- 类型: RWA NFT 交易平台
- 核心业务: 将实物收藏品（如宝可梦卡牌、运动卡等）代币化为 NFT 后进行交易
- 定位: NFT 市场中 RWA 类别的代表平台

## 核心业务/产品
- 实物资产（收藏品）托管后发行对应 NFT
- NFT 持有者可兑换实物藏品
- 结合了实物收藏品验证、托管和链上交易的全流程

## 关键数据
- **2025 年 Q2**：成为按交易量计第二大 NFT 市场（仅次于 OpenSea），超越 Blur 等纯数字 NFT 平台
- RWA NFT 赛道的核心驱动力，推动 RWA NFT 类别交易量季度增长 29%
- 代表了 NFT 领域从纯数字投机向实物资产代币化的方向性转变

## 竞争优势 / 护城河
- 率先将体育收藏卡等实物资产 NFT 化的赛道引领者
- 解决了实物资产代币化中的验证、托管、兑换等关键痛点
- 与 OpenSea 售卖低价 NFT 刷积分行为形成差异化的真实需求交易量

## 风险 / 争议
- 实物托管依赖中心化仓库和第三方验证，存在托管方风险
- RWA NFT 市场尚在早期，整体规模有限
- Q2 交易量可能存在季节性因素
