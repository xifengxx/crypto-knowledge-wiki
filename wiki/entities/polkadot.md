# Polkadot

## 基本信息
- 类型: Layer 0 跨链协议 / 中继链 + 平行链架构
- 共识机制: Nominated Proof of Stake (NPoS)
- 核心架构: 中继链 (Relay Chain) + 平行链 (Parachains) + 平行线程 (Parathreads) + 跨链桥 (Bridges)
- 定位: 异构多链互操作性网络
- 创始人: Gavin Wood（以太坊联合创始人、Solidity 发明者）
- 开发团队: Parity Technologies / Web3 Foundation

## 国库机制（Treasury）
Polkadot 的国库机制是 L1 生态资助模式的重大创新：不依赖外部融资或基金会拨款，而是从链上运营收入中自动截留资金形成一个自循环的资金池。

### 资金来源（4 个通道）
1. **交易费用的一部分**：区块空间使用费自动划入国库
2. **非最优 Staking 比率时的通胀资金**：当质押率偏离理想比例时，部分增发通证进入国库而非直接分配给验证者
3. **平行线程跨链通信拍卖**：平行线程按使用量付费，拍卖收入部分进入国库
4. **Slash 罚金**：节点不当行为被惩罚（Slash）的资金划入国库

### 资金分配机制
- 由理事会（Council）治理决定国库资金的使用方向
- 提案人可向国库申请资金用于对 Polkadot 生态有益的项目建设
- 形成自我强化的飞轮：国库资助 → 生态建设更完善 → 使用增加 → 国库资金池扩大 → 更多资助

### 为什么重要
- 解决了公链生态资助的可持续性问题：不依赖"私募融资→烧钱"模式，而是从链上运营中内生资金
- 可以通过治理调控通胀：决定国库资金的流入和支出可影响 DOT 的通胀/通缩平衡
- 可做成 DAO 形式减少团队中心化治理问题

## 竞争优势 / 护城河
- **共享安全模型**：平行链租用中继链的安全性，降低新链启动门槛
- **Substrate 开发框架**：一键发链基础设施，定制化程度高
- **跨链互操作性原生设计**：比 Cosmos IBC 更紧密的共享安全模型
- **国库自循环资助**：内生资金机制优于依赖外部融资的公链

## 风险 / 争议
- 平行链拍卖机制在熊市中吸引力下降
- 生态复杂度和开发者学习曲线高
- 与 Cosmos 生态在"应用链"叙事上的竞争
- 市场关注度在 2023 年后显著下降（热度被 Solana/Base 等新兴生态分流）
