# Swarms

## 基本信息
- 类型: 开源多 Agent 编排框架
- 创始人: Kye Gomez
- 定位: 让多个 AI Agent 协作，利用集体智慧解决复杂问题
- 代币: $SWARMS

## 核心特点

### 多 Agent 协作
为多个 Agent 提供透明且可追踪的环境，使不同 Agent 能够协作提升任务执行效率。

### 激励机制
使用代币作为 Agent 的激励工具，根据任务难度和最终结果质量动态分配代币——这是 Swarms 与其他框架最显著的差异点。

### 数据安全
采用分布式存储和多方安全计算（MPC）技术，确保 Agent 间交换数据时保护隐私和数据安全。

## 生态建设

### 生态基金
- 1000 万枚 $SWARMS 代币（价值 338 万美元）作为生态基金
- 创始人 Kye Gomez 亲自为合作伙伴提供技术与营销支持

### Marketplace 路线图（即将上线）
- 自动生成和上传：无缝创建代理、工具和群并直接上传到市场
- 付费墙集成：以一定价格列出代理→货币化
- $SWARMS 代币集成：通过 Phantom 钱包使用 $SWARMS 购买和出售代理
- Auto-Cloud：只需一个 Prompt 即可在云中启动 Swarm API
- 代理质量奖励：发布高质量代理可获得 $SWARMS 代币
- 实时聊天和 API：每个代理/群组/工具/提示的实时交互
- 使用情况跟踪：监控代理实时使用量
