# Brownie

## 基本信息
- 类型 / 赛道: 以太坊智能合约开发框架（Python 生态）
- 基础: 基于 web3.py 构建
- 语言支持: Solidity + Vyper
- 定位: Python 工程师友好的智能合约开发框架

## 核心用户
- [[curve|Curve.fi]] — 作为主要框架
- [[yearn-finance|Yearn Finance]]
- Badger DAO

## 竞争优势
- 专为厌恶 JavaScript 的 Python 工程师设计
- 大多数传统金融科技领域使用 Python，降低了从 TradFi 转向 DeFi 的门槛
- "Mixes"（类似 starter kit）生态丰富，如 chainlink-mix、dao-mix 等
- 同时支持 Solidity 和 Vyper

## 历史地位
- 作者（Chainlink 开发者倡导者）最偏好的框架，自称为 "brownie 开发者倡导者"
- 在 Python 开发者社区中有强大影响力
- 与之竞争的 Python 框架 [[ApeWorX]] 后来从 Brownie 社区分支出来
