# Meta（Llama 模型系列）

## 基本信息
- 公司: Meta Platforms, Inc.（前 Facebook）
- Llama 系列: Meta 发布的开源大语言模型系列
- 最新版本（截至 2024.12）: Llama 3.3
- 定位: 开源 LLM 生态的核心玩家

## AI Agent 构建者视角的定位
根据 Agent 构建者 superoo7（2024.12）的实战评价：
- **性能稳定可靠**：作为开源模型在多个任务上表现优异
- **开源、灵活自由**：用户可以自行部署和运行，无需依赖第三方 API
- **加密 x AI 项目的核心基础设施**：[[virtuals]] 等加密 AI 项目正基于 Llama 开发产品
- 可通过 OpenRouter 或 Groq 进行低成本试用

## 在加密/AI Agent 生态中的角色
- Llama 是开源 Agent 框架（如 [[ai16z]] 的 Eliza）最常集成的基础模型之一
- 开源特性使其适合需要隐私/本地部署的 Agent 场景
- Groq LPU 提供了极快的 Llama 推理速度，适合生产环境部署
- 是"开源 vs 封闭源"AI 辩论中的核心代表

## 元宇宙战略（基于 Matthew Ball 框架）
除了 AI 开源 LLM 之外，Meta（前 Facebook）是元宇宙赛道最重要的玩家之一，其战略可通过 Matthew Ball 的 8 层堆栈框架进行系统分析（参见 [[来源_2022_Metaverse_元宇宙_巨头对比_MatthewBall]]）：

- **体验**：Facebook 和 Instagram 作为社交网络是关键的元宇宙入口，"自我"感是元宇宙的基本属性，AR/VR 中称为"具身"体验
- **创作者经济**：Facebook Horizon 是 Meta 的内容创作平台
- **空间计算**：Oculus VR 平台及其相关软件投资
- **人机界面**：Oculus VR 头显、Ray-Ban Stories 智能眼镜（带摄像头和语音识别），以及以超过 50 亿美元收购的神经接口公司 CTRL-Labs
- **去中心化**：Meta 在去中心化方面的计划不明确，曾推出 Novi 数字钱包和 Diem（前 Libra）稳定币项目。提到 NFT 可作为互操作性手段，但 NFT 也可在私有中心化区块链上创建，不一定需要去中心化
- **基础设施**：Meta 正在追赶苹果和微软，Oculus 主要由供应商组件构成，但招聘计划显示大量投资材料科学和半导体工程（新型集成电路、OLED 电路设计、近眼显示新材料、光子设备）
