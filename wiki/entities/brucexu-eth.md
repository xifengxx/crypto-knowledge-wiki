## 基本信息
- 身份: LXDAO 联合创始人，Web3 建设者社区核心人物

## 核心业务/产品
LXDAO 是中文 Web3 开发者社区，致力于推动区块链和去中心化技术的开发与普及。

## 关键观点
- **MCP 作为去中心化基础设施**：brucexu.eth 最早（2025年3月）在中文社区系统阐述 MCP 对 Web3 的意义，将 MCP 定位为"AI 的去中心化革命"，而非仅是一个互操作协议参见 [[来源_2025-03_MCP_去中心化_以太坊_brucexu]]
- **OpenMCP.Network 设想**：提出基于以太坊智能合约构建 MCP 创作者的激励网络，实现自动化、透明、抗审查的支付结算
- **Slim LLM 架构**：未来 LLM 只做语言处理和推理，具体能力由 MCP Server 分布式提供
- **普通人参与 AI 经济**：通过 MCP Server 让非技术人员也能将个人知识/数据变现
