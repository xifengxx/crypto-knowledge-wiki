# 10KTF

## 基本信息
- 类型: NFT 个性化商品/IP 应用平台
- 创始人/运营者: Wagmi-san (@wenewlabs)
- 赛道: NFT 生态/数字时尚/IP 衍生品
- 核心产品: 10KTFshop — 为 Yuga Labs PFP 系列（BAYC/BAKC 等）制作个性化穿戴物品
- 定位: 重新定义 NFT 体验——"收藏 NFT 意味着新的连接和新的故事"

## 核心业务/产品
10KTF 是一个为 Yuga Labs 旗下 NFT 角色制作个性化商品和时装的项目，通过 10KTFshop 平台运营。其核心创新在于让 NFT 持有者为其数字头像购买和穿戴由知名设计师创作的虚拟服装，这些服装直接与 NFT 的元数据关联，改变了 NFT 从"静态收藏品"到"可装扮数字角色"的范式。

## 关键合作与事件
- **Gucci Grail**：Gucci 作为奢侈品牌首次在 NFT 领域的大规模合作，选择通过 10KTFshop 落地。BAYC 和 BAKC 持有者可以让其角色穿上由 Gucci 创意总监 Alessandro Michele 设计的奢华服装。这标志着传统奢侈品牌正式进入可编程 IP 生态系统。
- **Gucci 合作验证了 10KTF 的平台价值**：Gucci 选择成为 10KTFshop 的合作方之一，说明该平台充当了品牌与 Yuga Labs 生态之间的桥梁角色。没有 10KTFshop 的分发和互操作能力，品牌单独对接每个 NFT 系列的难度大得多。

## 竞争优势 / 护城河
- 与 Yuga Labs IP 生态的深度绑定——Yuga 旗下最核心的 PFP 系列（BAYC/BAKC）的"虚拟服装接口"
- 连接传统奢侈品牌与 Web3 NFT 持有者的信任中介——品牌不必直接管理 NFT 智能合约和分发
- Wagmi-san 团队（@wenewlabs）在 NFT 个性化领域的先发优势
