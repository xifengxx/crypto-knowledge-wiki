# YesNoError (YNE)

## 基本信息
- 类型: AI 驱动的科学论文审查协议
- 赛道: DeSci + AI
- 链: Solana
- 代币: YNE（截至 2024.12）
- 创建时间: 2024年12月20日
- 创始人: Matt Schlicht
- AI 模型: OpenAI o1

## 核心业务/产品
利用 OpenAI o1 模型大规模审计科学论文中的数学错误、伪造数据和数值错误，通过区块链技术实现审查过程的透明化和代币激励。

### 运作方式
1. AI（o1）自动扫描科学论文
2. 发现问题后通过网站和 Twitter 公开发布
3. 代币持有者获得优先审核自己论文的权利

### 现实案例
2024年10月，一篇同行评审（peer-reviewed）研究声称黑色塑料厨房具有毒——但因计算错误（乘法错误），报告的毒性水平比实际高出10倍。o1 模型仅用30秒、$0.30费用即识别出该严重错误。该错误论文引发了广泛公众恐慌和媒体报道。

## 竞争优势 / 护城河
- 技术壁垒：OpenAI o1 级推理能力 + 规模化审查 = 人工无法替代的效率
- "加密原生公共产品融资"范式——传统科学领域筹集$3,000万是大工程，加密领域10天即获$50M市值
- 与 BIO Protocol 形成 DeSci 互补：BIO = 上游科研策展 + 资金分配 / YNE = 下游科研成果质量验证

## 风险 / 争议
- Kyle Samani 反对意见：二八原则——重要论文已受充分关注，不太可能存在已知但未纠正的错误
- 市场需求存疑：ChatGPT 问世起 AI 审核论文就已存在，加密化的必要性待验证
- 论文审查的正确率本身需要验证（AI 也可能误判）
- 从 $60M（上线当天）→ $30M（12月底）→ ~$50M（1月初）的剧烈波动反映市场对其价值的高度不确定
