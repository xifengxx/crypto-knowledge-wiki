# DeBank

## 基本信息
- 类型：去中心化数字资产管理平台 / DeFi 数据聚合器
- 赛道：链上资产管理工具、DeFi 数据追踪
- 融资：2021年12月以 $2 亿估值完成 $2500 万股权融资，红杉中国领投，Dragonfly、Hash Global、Youbi、Coinbase Venture、Crypto.com、Circle、Ledger、分布式资本参投
- 收录规模：30+ 条链、1000+ DeFi 项目

## 核心产品
- **资产追踪与投资组合管理**：多链资产总览，跨所有链追踪钱包余额、DeFi 仓位、NFT 持仓
- **巨鲸监控**：关注 Smart Money 地址，实时跟踪其资产变化和链上行为
- **DeFi 项目信息聚合**：收录各 DeFi 项目排行、利率对比、代币分布、池类型等信息
- **DeBank Hi**：Web3 社交功能，用户可通过 Web3 钱包登录进行社区互动和治理投票
- **Web3 ID**：链上身份标识，铸造费用 $96/个
- **DeBank Pro**（计划中）：付费高级服务

## 商业模式
- Web3 ID 铸造费 $96/个
- DeBank Hi 发消息 $1/条
- 计划推出 DeBank Pro 版进行更多服务收费
- 相比竞品 Zapper（API 数据销售）和 Zerion（Swap 手续费 0.5%），DeBank 走的是社交+身份变现路线

## 竞争优势
- **最早布局**：在链上资产追踪工具赛道中占据先发优势
- **多链覆盖深度**：30+ 链、1000+ 协议，收录范围领先
- **巨鲸监控心智份额**：Smart Money 追踪功能在中文加密社区中形成强认知

## 实用发现案例
- **LAGOON 协议**（通过地址追踪发现）：$7,000 万 TVL 的 Vault 策略提供商，ETH 存款可获 9% 年化收益。此案例显示了 DeBank 地址追踪功能在发掘超额收益机会上的独特价值——相较于在 X 平台浏览热点，直接观察投资者资金动向更有效（来源：[[来源_2025-06_7大工具_新协议_潜力股_深潮TechFlow]]）

## 弱项 / 待改进
- 缺少实时提醒功能，需手动刷新页面
- 移动端体验与网页版功能不一致
- 部分链和项目尚未收录

## 竞品对比

| 维度 | DeBank | Zapper | Zerion |
|------|--------|--------|--------|
| **定位** | 资产管理+数据跟踪 | Web3 首页/投资管理 | DeFi 投资+交易 |
| **核心差异** | 巨鲸监控、社交（Hi）| 收益农业、流动性池 | 法币入金、Swap |
| **商业模式** | 社交变现+ID | API 数据出售 | Swap 0.5% 手续费 |
| **融资** | $2500万（2021.12）| $1500万 A 轮（2021.5）| $820万 A 轮（2021.7）|
