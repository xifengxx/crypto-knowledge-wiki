# Hyperfy

## 基本信息
- 类型：元宇宙平台 → AI Agent 沉浸式空间平台
- 赛道：AI + Metaverse / AI Agent 交互空间
- 成立时间：约 2022 年（NFT Summer 时期）
- 创始人：Ash Connell（ASH）
- 代币：2025 年 1 月 6 日发币（具体代币名称原文未提及）
- 所属生态：ai16z / ElizaOS / M3（Metaverse Makers）

## 核心业务/产品
- **Hyperfy V1**：元宇宙土地平台，支持任何网络浏览器（含手机和 Meta Quest 3 VR 头显）即时访问，内置工具可制作画廊、场馆、俱乐部、商店、作品集、教育体验、游戏等场景，支持从钱包导入 2D/3D NFT，拖放 3D 模型、图片、音频、视频
- **Hyperfy V2（核心转型）**：从元宇宙平台转型为 AI 代理赋能的沉浸式空间平台，全部工具和层级开源，与 ElizaOS 架构的 AI Agent 集成
- **核心差异化**：不再是"让人进入虚拟世界"，而是"为 AI Agent 提供可交互的多元宇宙空间"——AI Agent 与 AI Agent、人类与 AI Agent 可在 3D 空间中进行最直观的交流

## 关键使用场景
1. **AI 理事会**：AI 代理在工作组/项目/案例研究中接受训练后，在 3D 空间中讨论提案并协助决策
2. **Stonk 交易所**：类似于股票交易所场景，实时观看 AI 代理的交易行为
3. **可互操作宠物**：与 tubbycatsnft（CC0 NFT，20k 个优化的 3D 模型）集成，适用于未来 VR 宠物系统
4. **更多场景**：pmairca 会议室、AI 评委游戏节目、3D 数据可视化（ai16z 国库钱包可视化）、加密货币自动售货机

## 竞争优势 / 护城河
- ai16z 生态深度绑定：Shaw 链上买入 + DAO 成员 Jin 参与项目文档和场景设计 + 社区推广
- M3（Metaverse Makers）社群网络效应：汇集 ASH、Jin、7OROY 等 3D/AI 领域人才
- 先发优势："AI Agent 的 Figma"概念——类似设计工具 Figma 在协作设计领域的地位

## 风险 / 争议
- $280M 市值在 10 小时内达成 → 高度投机性，可能只是叙事 FOMO 而非价值发现
- V2 产品未上线：所有使用场景均为路线图/演示，实际 Agent 交互效果未知
- 转型风险：从元宇宙土地平台转向 AI Agent 空间，社区和用户基础能否跟上
- 代币经济模型未明确：原文未披露代币名称、供应量、分配机制等关键信息

## 我的判断
Hyperfy 代表了"AI Agent 拯救元宇宙"叙事的第一枪。核心理念——让 AI Agent 而非人类成为虚拟世界的主要"居民"——确实解决了 2022 年元宇宙失败的硬件瓶颈问题。但 $280M 的速通市值更多是 ai16z 社区的叙事发动机 + Shaw 的喊单效应 + "AI 版 Figma"的概念包装。真正的考验在 V2 上线后：Hyperfy 能否成为 AI Agent 实际交互的基础设施，还是又一个路线图代币。关注指标：V2 上线时间、ElizaOS 集成的实际功能深度、平台内活跃 Agent 数量。
