# Discord

## 基本信息
- 类型: 社交/通讯平台（Web2，未上市）
- 赛道: 社区通讯、语音/文字/视频聊天
- 成立: 2015年（Jason Citron & Stan Vishnevskiy）
- 定位: 从游戏语音工具演化为通用兴趣社区平台
- 用户规模: 数亿级别（MAU未定期披露）

## 核心产品
Discord 是功能最丰富的社区协作平台之一，核心产品架构包括：

1. **服务器（Server）**：可自定义的社区空间，每个服务器内可创建多个频道
2. **频道类型**：
   - 文字频道（传统聊天）
   - 语音频道（多人实时语音）
   - Stage 频道（单向语音广播，2021年推出，对标 Clubhouse）
   - 视频会议
3. **权限系统**：基于角色的精细权限管理（管理员/版主/成员/访客）
4. **Bot 生态**：开放 API 允许第三方开发者创建自动化工具（Mee6、Guild.xyz 等）
5. **Stage Discovery**：公开 Stage 频道的发现入口

## Web3 社区的关键基础设施
Discord 事实上已成为 Web3 社区的"默认市政厅"：
- 几乎所有 Crypto 项目都有 Discord 服务器，用于社区大会、AMA、公告、治理讨论
- Stage Channels 提供了"少数人发言、多数人旁听"的结构化广播能力，天然适合 AMA 和项目路演
- 与传统语音频道不同，Stage 频道观众默认静音、断开时不通知，降低参与门槛和社交压力
- 社区服务器模式要求：经验证邮箱、显式内容过滤器、独立规则/更新频道——本质是以审核门槛过滤低质量社区

## 与 Telegram 的定位差异
- Discord：结构化频道 + 权限体系 + 长期信息沉淀 —— 适合深度社区运营和技术讨论
- Telegram：即时通讯 + Bot 自动化 + Channel 广播 —— 适合快速信息分发和轻度互动
- Web3 项目通常同时使用两者：Discord 做深度社区，Telegram 做公告和快速响应

## 相关事件时间线
- 2015: Discord 正式上线，最初面向游戏玩家
- 2021-03: 推出 Stage Channels，对标 Clubhouse 音频社交热潮
- 2021-07: Stage Channels 功能完善，支持话题创建、发言请求、Stage Discovery
- 2022: 已成为 Crypto/Web3 社区的核心运营平台

## 我的判断
Discord 是 Web2 平台中最适合 Web3 社区的通讯工具，其基于服务器的频道架构天然契合 Web3 项目"社区即产品"的组织形态。Stage Channels 填补了社区从"嘈杂聊天"升级到"有序内容生产"的关键空白。但 Discord 是中心化平台——关闭服务器、封禁账号的权限在平台方——这也是 Web3 SocialFi 项目（Towns、Farcaster）试图争夺这块市场的原因。
