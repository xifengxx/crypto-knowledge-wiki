# 美国证券交易委员会 (SEC)

## 基本信息
- 类型: 美国政府独立监管机构
- 成立: 1934年（依据《证券交易法》）
- 主席: [[paul-atkins]]（2025年提名，待确认）/ [[mark-uyeda]]（2025年担任代理主席）
- 核心使命: 保护投资者、维护公平有序的市场、促进资本形成

## 核心业务/职能
- **证券监管**: 监管美国证券市场，包括股票、债券和加密资产的证券属性认定
- **执法**: 对违反证券法的行为进行调查和起诉
- **规则制定**: 制定和执行证券市场规则，包括对加密货币等新兴资产类别
- **全球影响力**: SEC的决策常被其他国家的监管机构作为参考标杆，特别是加密资产领域

## 加密监管历史

### Gary Gensler时期（2021-2024）
- 执行"监管即执法"(Regulation by Enforcement)策略，不提供明确的加密监管指导
- 起诉Ripple（XRP）违反证券法
- 将Kraken的质押服务归类为未注册证券，罚款$3000万
- 对Coinbase、Binance、Consensys、Uniswap展开调查
- 签署SAB 121，要求公司将加密托管资产列为负债
- 信号效应导致许多加密公司迁往国外（如阿布扎比）

### Mark Uyeda过渡期（2025年初）
- Uyeda于2022年起担任SEC专员，对加密行业持友好态度
- 2025年初担任代理主席，推动政策从执法转向协作
- 1月22日成立Crypto Task Force（由[[hester-peirce]]领导），Hester Peirce列出十项优先任务，重点审视加密资产分类与监管
- 1月24日撤销SAB 121（通过SAB 122替代）——SAB 121要求数字资产托管人将资产视为负债，被认为是阻止银行参与加密市场的障碍
- 撤回对Coinbase的诉讼，终止对OpenSea、Robinhood、Uniswap的调查
- 2月27日终止对Gemini Trust的调查；3月同意撤销对Kraken的诉讼（不罚款、不承认违规）
- 通过工作人员声明澄清稳定币和Meme币政策立场
- 评估重新定义"交易所"的提案，为加密交易平台提供更清晰的监管框架

### Paul Atkins时期（2025年及之后，预期）
- 被Trump提名为SEC主席，以亲加密立场著称
- 预期将建立明确的加密监管框架，促进行业创新

## 内部争议
- 专员Caroline Crenshaw公开批评SEC的亲加密转向
- 对Crypto Task Force的特定声明表示担忧
- 显示SEC内部对加密监管方向存在分歧

## 关键数据
- SEC Bitcoin ETF于2024年初获批，直接引导其他市场（如香港）在3个月内跟进
- SAB 122替代SAB 121，解除机构参与加密市场的重大障碍
