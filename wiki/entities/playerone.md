# PlayerOne

## 基本信息
- 定位：多链元宇宙沙盒游戏平台
- 官网：https://www.playerone.world/
- 赛道：区块链元宇宙 / GameFi
- 核心理念："Everyone Can Build Metaverse"（人人都可创建元宇宙）
- 天使轮：SIG（TikTok 最大外部股东）和 The9（魔兽世界早期运营商）领投
- 第二轮投资者：FBG、TsingTing Capital、Waterdrip、Element、Winkrypto、WePiggy、Alchemy Pay、Betterverse DAO、TAGVentures
- 团队背景：核心成员来自游戏引擎团队、游戏公链、数字货币交易所、上市游戏公司，兼具游戏引擎 + 区块链多年经验

## 核心产品矩阵
- **RoleEditor**：可组合 NFT 角色编辑器。通过链上随机生成的 ERC-1155 部件盲盒 → 用户自由组合 → 销毁部件铸造 ERC-721 VoxelRole NFT。支持联名款（第三方 IP 合作）和第三方 PFP 导入（Meebits 为首个合作项目）
- **SpaceEditor**：体素风格空间编辑器，零门槛建筑创作。独创 BluePrint 蓝图系统——用户可购买 ERC-1155 蓝图 NFT 一键建造建筑，价格仅为原生建筑的千分之一。支持道具商城（5-10 USD 价位的 ERC-1155 装饰 NFT）
- **VoxelEditor**：精细体素道具编辑器，支持实时渲染、体素动画、模型商城，制作后可一键发布为 ERC-1155 NFT 至道具商城
- **GameEditor**：Scratch 式模块化可视化游戏编辑工具，无需编码即可创建 FPS、RPG、创造类 3D 游戏

## 多链架构
- 基于 LayerZero 全链互操作协议
- NFT 创世即支持 7 条公链：以太坊、Polygon、Arbitrum、Optimism、BSC、Avalanche、Fantom
- 原子级跨链转移（非复制，源链减少 / 目标链增加）
- 支持用户使用任意链的钱包进入元宇宙，跨链用户可互相同步交互

## 创世大陆规划
- 第一期：创世大陆（Genesis Continent），包含 1 个中心区和 6 个分区
- 分区命名：Snow Crash、Oasis、Metaverse、BTC、Ethereum，其余 2 个由社区投票
- 地理特征：山脉（山景房）、河流（河景房 + 游轮航线）、湖泊（湖景房 + 独享小岛）、岛屿（可向海扩建）、地铁（地铁房）
- 社区 DAO：借鉴曼哈顿社区规划，每个小区中间留出公共空间由 DAO 治理决定用途
- 第一期白名单：限量 1000 块土地
- 最低土地价格：0.2 ETH（附带价值 $100+ 的创世建筑）

## 经济模型
- **O2E（Operate to Earn）**：激励用户创建内容、吸引访问量，通过有效访问量和 P2E 游戏表现获得代币奖励
- **土地租赁**：土地投资者出租土地，租赁者获得运营激励
- **土地协作**：多角色权限支持土地所有者添加协作者（仅编辑权限，无交易权限）
- **资产回购及销毁**：合约持有者可销毁自有土地合并为公共设施，项目方先通过二级市场回收再销毁
- **RarityScore 算法**：RarityScore = (bs + vc) * 11 * ln(q+1)，用于 P2E 奖励权重、宠物捕获概率、空间访问量权重计算，兼作反女巫机制

## 自研游戏设计
- 宝可梦式宠物捕获系统：宠物分布在创世大陆各地，角色 RarityScore 越高捕获概率越高
- 宠物培养繁殖 → PVE / PVP 战斗获取游戏代币
- 每日捕获次数有限，通过质押治理代币可提高上限

## 技术创新
- 首个可交互土地 NFT（OpenSea 上可查看土地位置并缩放）
- 多角色权限管理（土地所有者/租赁者/协作者/第三方平台）
- 跨平台技术方案（Web 访问 + Electron 客户端版本，支持 Windows/Mac/Linux）
- 首个接入 LayerZero 的元宇宙平台
