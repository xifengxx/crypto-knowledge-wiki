# Foundry

## 基本信息
- 类型 / 赛道: 以太坊智能合约开发框架
- 开发团队: Paradigm（[[paradigm]]）
- 核心开发者: Georgios Konstantopoulos（@gakonst）
- 基础语言: Rust
- 定位: DappTools 的 Rust 重写版 / 高性能命令行智能合约开发工具

## 核心特性
- 用 Rust 编写，性能优于同类工具
- 与 [[DappTools]] 相似的文件结构和命令体系
- 使用 Solidity 编写测试（不依赖 JavaScript 或 Python）
- 内置模糊测试（fuzzing）
- 命令行优先的工作流

## 竞争优势
- Rust 正在成为区块链基础设施中最受欢迎的语言之一
- 快速、强大，专注在 Solidity 中构建测试
- Paradigm 团队持续投入
- 被视为 DappTools 的"继任者"

## 行业地位
- 2021年12月 Paradigm 发布文章正式推出
- 发布文章中向 DappTools 致敬
- 被作者归类为"优秀选手"（仅次于"明星选手" Hardhat/Brownie/DappTools）
- 与 DappTools 共同代表"命令行范式"的智能合约开发
