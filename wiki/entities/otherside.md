# Otherside

## 基本信息
- 类型: 元宇宙平台
- 开发方: [[yuga-labs]]
- 链: Ethereum
- 核心资产: Otherdeed（虚拟地块，20万块）、Koda（游戏角色，依附于特定地块）
- 定位: 排他性元宇宙（仅限 Otherdeed 持有者进入）

## 核心业务/产品
Otherside 是 Yuga Labs 开发的元宇宙项目，与 BAYC、MAYC、BAKC、CryptoPunks、Meebits 等 Yuga 旗下 NFT 系列进行互操作。其核心差异在于：

- **与 Decentraland / Sandbox 的本质区别**：Otherside 围绕与 Yuga 现有 NFT 社区的互操作性设计，而非用户生成内容（UGC）。当 Decentraland 和 Sandbox 聚焦 UGC 时，Otherside 已设计为促进其现有和未来 NFT 系列的效用。
- **排他性入口**：只能通过拥有 Otherdeed NFT 进入，是一个排他性而非开放性的元宇宙。

## 关键数据
- Otherdeed 和 Koda 共 20 万个 NFT
- Yuga Labs 旗下 10 个最大隐含市值 NFT 项目中的 5 个均与 Otherside 互操作（BAYC、MAYC、BAKC、CryptoPunks、Meebits）
- Otherside 生态建设者（2022 年 8 月数据）：OtherGuild（220 名签约成员/3,900 名 Twitter 关注者）、CreatorDAO（80+ 创作者/60 个平台订单）、Arcade（开发 Ape VS 混斗游戏）、Worldwide Webb（2D 可互操作 Play-to-Own 元宇宙）、Otherside Meta Guild（与 Horizon Labs 合作）、CryptoCities Development（Sandbox Alpha Season 3 BAYC 体验）

## 独特的 IP 结构
Otherside 在 IP 权属方面采用了 Yuga Labs 旗下最复杂的结构：

- **Otherdeed（虚拟地块）**：Yuga Labs 发布的首批不授予商业权利的 NFT。条款和条件明确声明"买方拥有转让 NFT 的产权，产权不包括知识产权"。Otherdeed 所有者不能拥有与虚拟地块相关的艺术作品或其他媒体的版权。
- **Koda（游戏角色）**：提供完整的商业许可，与 BAYC 许可一致。Koda 持有者拥有完整的商业使用权。
- 这种"地块无IP + 角色有IP"的双轨制在 NFT 元宇宙项目中具有独特性。

## 竞争优势 / 护城河
- 与 Yuga 旗下最高市值的 NFT 系列深度绑定
- 拥有 $APE 代币经济系统支持
- 排他性设计增强持有者稀缺感（但也是风险来源）

## 风险 / 争议
- 2022年 Otherdeeds 土地销售引发争议，市场对 Yuga Labs 的沟通滞后感到不满
- 排他性元宇宙与 Web3 开放精神存在内在张力
- 明确不转移知识产权限制了持有者的商业化能力

## 我的判断
Otherside 在元宇宙 IP 设计上体现了 Yuga Labs 的战略矛盾：一方面需要给 NFT 持有者足够的权利来维持社区忠诚度，另一方面又希望通过保留 IP 所有权来保持商业灵活性。Otherdeed 的无 IP 模式是这一矛盾的直接体现，也解释了为何 Yuga 在 Otherside 上的进展缓慢——IP 不清晰的情况下，持有者和第三方开发者缺乏长期投入的激励。
