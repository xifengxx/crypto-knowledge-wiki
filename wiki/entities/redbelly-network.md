# Redbelly Network

## 基本信息
- **赛道**: RWA 专用 Layer 1 区块链
- **定位**: 使资产发行人能够将资产代币化为合规的链上结构化产品的专用区块链
- **网络**: 自有 Layer 1（非基于现有 L1/L2 构建）
- **成立时间**: 2021 年开始开发，经过多年酝酿
- **创始人/CTO**: Vincent Gramoli，悉尼大学计算机科学研究中心（CSRG）负责人、分布式计算研究员
- **开发背景**: 由悉尼大学与澳大利亚国家科学机构 CSIRO 合作开发
- **专利**: 美国专利 #12093247
- **代币**: 原生代币 RBNT，即将推出
- **合规认证**: 唯一获得澳大利亚政府机构（CSIRO）种子资金支持的 RWA 项目

## 核心技术/产品
- **共识机制**: 正式验证的 DBFT（Democratic Byzantine Fault Tolerance）共识
- **性能**: 每秒处理 20,000 笔交易（TPS），高性能可扩展网络
- **身份与合规**: 在交易层集成完整用户身份和责任体系，使用零知识证明（ZKP）和可验证凭证保护用户 PII
- **合规自动化**: 可根据资产类别和管辖范围自定义合规规则，自动执行，无需离线注册和纸质检查
- **消除重复 KYC**: 获得适当许可后，跨管辖范围自动识别用户身份，消除重复 KYC 流程
- **原生 ID 协议**: 用户和企业可通过可验证凭证证明身份，实施问责制

## 关键数据
- TPS: 20,000
- 开发时间: 2021 年至今
- 专利: 美国 #12093247

## 竞争优势 / 护城河
- **学术+政府双重背书**: 悉尼大学 + CSIRO（澳大利亚国家科学机构）联合开发，在 RWA 赛道中独树一帜
- **合规深度集成**: 在 Layer 1 层面内置身份验证、ZKP 隐私保护和管辖权合规——而非事后拼接
- **正式验证共识**: DBFT 经过形式化验证，理论上安全性优于未经验证的共识协议
- **美国专利保护**: 核心技术受专利保护，有一定技术壁垒
- 澳大利亚政府种子资金支持赋予独特的合规信任度

## 风险 / 争议
- 学术团队商业化能力存疑：悉尼大学教授主导 vs 加密原生团队，能否在生态建设和市场推广上竞争？
- 专用 RWA L1 赛道竞争激烈：Plume、MANTRA 等也在争夺同一市场，网络效应尚未建立
- 从 2021 年开始开发至今多年，主网和代币迟迟未上线，执行速度较慢
- 高性能（20,000 TPS）声称需主网上线后实际验证
- 澳大利亚作为监管辖区的吸引力 vs 美国/新加坡/瑞士——能否吸引足够的资产发行方？
