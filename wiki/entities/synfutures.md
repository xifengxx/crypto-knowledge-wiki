# SynFutures

## 基本信息
- **赛道**: 去中心化衍生品（Perp DEX）
- **成立时间**: 2021 年（创始人 Rachel 于 2021 年初创立）
- **创始人**: Rachel（2018 年加入比特大陆，后参与创立 Matrixport）
- **融资**: 累计超 3740 万美金，投资方包括 Pantera、Polychain、Dragonfly、SIG 等东西方知名机构
- **上线链**: Polygon（V1/V2）→ Base（V3 主力）
- **代币**: F token，2024-12-06 TGE，Bybit 首发

## 核心业务/产品

### DeFAI 路线图（2025-02 公布）
SynFutures 于 2025 年 2 月公布三阶段 DeFAI 路线图，旨在将 AI Agent 深度整合至衍生品交易生态：

#### 第一阶段：单体 AI Agent
- **Trading AI Agent Synthia**: 自动执行Swap、Bridge、Transfer等链上操作，用户输入目标即可；结合 Spot Aggregator 支持跨协议交易
- **Alpha Hunter Agent**: 监测链上交易动态，筛选高收益流动性池、套利机会、价格异常等，AI 自动推送交易信号并支持一键交易
- **AI社交交易助手**: 用户在 Twitter、Discord 直接发送交易指令，实现"一句话交易"，AI 自动生成市场分析和策略调整

#### 第二阶段：开放 AI Agent 生态（Web3 AI Framework）
- 开放开发者框架（API/SDK）、可视化无代码构建界面、多种场景模板、内置变现机制（代币发行/质押/空投）、AI Agent 市场（交易代理模板/插件/数据 API）

#### 第三阶段：Meta Agents
- AI Agent 自主生成和演化，根据任务需求自动创建和管理 AI Agent，多 Agent 协作完成复杂任务，通过强化学习和反馈机制自我优化

### 竞争优势补充
- **资金储备充足**: 累计手续费收入 5848 万美元为 AI 研发提供资金保障
- **AI 团队建设**: 过去半年吸纳 AI 领域专业人才，在顶级期刊发表研究成果
- **DeFi 原生优势**: 相比纯 DeFAI 初创项目，更懂 DeFi 交易者痛点，拥有真实用户和交易量基础

### 三个版本迭代
1. **V1 (2021)**: 到期合约 AMM，上线 Polygon，支持最高 10x 杠杆；开发全网首个 BTC 挖矿难度交割合约；一年半交易量 187 亿美金
2. **V2**: 纯链上去中心化期货和永续合约交易平台，允许无许可创建衍生品市场；支持 BTC/ETH 及 Polygon 主流资产；成为 Polygon 上交易量最高的 Perp DEX 之一
3. **V3 (2024)**: 推出 Oyster AMM (oAMM)，专为衍生品交易设计，最高资金效率 26,666x

### Oyster AMM 四大特性
- **集中流动性**: LP 可将流动性集中到指定价格区间，最大化资金效率
- **纯链上订单薄**: 不依赖中心化服务器，做市商通过下限价单做市，直接获得 1/3 手续费分成
- **无许可上币**: 任何 ERC-20 token 做保证金，30 秒内完成上币流程
- **Perp Launchpad**: 业界首个衍生品永续合约发行平台，参考 Pump.fun 模式

## 竞争优势
- Oyster AMM 创新：集中流动性 + 纯链上订单薄 + 无许可上币三重组合
- 先发平台优势：Perp DEX 中首个 Perp Launchpad
- Base 链生态龙头：Base 上最大的 Perp DEX，份额接近垄断级
- 顶级 VC 背书：Pantera、Polychain、Dragonfly、SIG

## 风险/争议
- 初始流通量仅 12%，远低于 Hyperliquid 的空投比例，长期解锁压力大
- Perp Launchpad 冷启动挑战：项目方代币流动性可能不足，滑点风险
- 赛道竞争激烈：Hyperliquid 领先，dYdX 品牌力强，新进入者持续涌现
- Base 链依赖：高度集中于 Base，链级风险（Base 无原生代币，依赖以太坊 L2 基础设施）
