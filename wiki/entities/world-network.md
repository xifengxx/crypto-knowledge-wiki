# World Network (原 Worldcoin)

## 基本信息
- 类型：链上身份 + L2 区块链网络
- 创始团队：Alex Blania + Sam Altman (OpenAI CEO)
- 更名：Worldcoin → World Network (2024年10月)
- 三大支柱：World Chain + World ID + Worldcoin (WLD)
- 定位：由真实/经验证人类组成的网络，支持 AI 进一步发展

## 核心业务/产品
- **World ID 3.0**：人类证明协议。Verified Passport (NFC护照验证年龄国籍/无需Orb)+ Deep Face (抗深度伪造人脸识别)+ AMPC (下一代SMPC/大学第三方主机)
- **World Chain**：OP Stack L2/已验证人类免Gas+优先区块空间/原生Mini Apps分发。用户交易量曾占OP Mainnet 44%/高峰>80%
- **World App 3.0**：Mini Apps平台(类Telegram小程序)+ World Pay(全球免费支付)+ 资产收益Vault
- **Orb**：虹膜扫描硬件(原核心验证方式)→World ID 3.0降低了Orb依赖(新增NFC护照)

## 关键数据
- 用户交易量占OP Mainnet: 44%(平均)/>80%(高峰)
- WLD 直播前后：$2.3→$2.08(-10%)→$2.2
- World Chain: OP Stack/已验证用户免Gas/主网已上线
- World ID 3.0: NFC护照(美/马来西亚/英)+ Deep Face

## 竞争优势 / 护城河
- Sam Altman 品牌背书 + OpenAI 关联(叙事层面)
- 链上人类证明的先发优势(Orb + 虹膜扫描)
- 从"注册验证"扩展到"持续验证"(Deep Face)
- World Chain = 应用做链(用户量大到自建L2)

## 风险 / 争议
- WLD 代币需求不足/应用场景不清晰(通胀代币/每周解锁给Orb验证者)
- OpenAI 联动预期从"利好"变"双刃剑"(预期落空=币价下跌)
- Orb 硬件部署成本+地理覆盖限制+隐私争议
- 已验证用户免Gas→降低WLD原生需求
