# BlockBooster

## 基本信息
- 类型: 研究机构 / 投资机构
- 活跃领域: Web3, AI+Crypto, DeFAI
- 研究者: Kevin (the Researcher at BlockBooster)
- 专栏: PANews 入驻专栏作者

## 核心业务/产品
BlockBooster 是 Web3 领域的研究机构，在 PANews 开设专栏，发表对 AI+Crypto 赛道的深度分析。其研究者 Kevin 提出了多项有影响力的分析框架。

## 关键贡献
- **AI Agent "波粒二象性"分析框架**（2024年12月）：提出 AI Agent 同时具有"波"（Memecoin 特征——社区文化/传播能力）和"粒"（行业预期——技术深度/实际用例）的双重属性，并给出五类 Agent 项目分类法（Launchpad/应用/引擎/框架/其他）。参见 [[来源_2024-12_AI_Agent框架_波粒二象性_PANews]]。
- **DeepSeek对Web3 AI生态影响分析**（2025年2月）：系统分析 DeepSeek 对 Web3 AI 上下游各层级（基础设施层/中间件层/模型层/应用层）的不同影响，提出"DeepSeek戳破Agent泡沫、DeFAI或成新增长点"的判断。
