# Agent YP

## 基本信息
- 类型: Web3 游戏 AI KOL
- 生态: Virtuals Protocol（Base 链）
- 创建者: @yellowpantherx（YellowPanther，Virtuals Protocol 顾问、Mocaverse 和 Xai 大使，此前专注于游戏内容创作）
- 定位: 成为 Web3 游戏的"AIXBT"——提供最快、最准确的游戏内容

- **AI 游戏内容创作**: 基于最新市场新闻和数据，自主生成 Web3 游戏相关内容

## 关键数据
