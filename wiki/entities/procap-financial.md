# ProCap Financial

## 基本信息
- 类型: SPAC 上市的比特币财库+金融服务公司
- 赛道: PCV (Public Crypto Vehicle)/BTC 财库
- 成立时间: 2025年
- 创始人/支持方: Anthony Pompliano（知名比特币布道者、Pomp Investments 创始人）
- 上市方式: SPAC（借壳上市）

## 核心业务/产品
ProCap Financial 的规划包括三层：
1. **比特币财库**：以比特币为核心储备资产
2. **加密借贷**：在比特币财库基础上提供加密货币借贷服务
3. **质押基础设施**：构建机构级别的加密资产质押基础设施
4. **机构收益产品**：开发让机构获取比特币收益的金融产品

## 关键数据
- Anthony Pompliano 作为主要推动者，为项目带来比特币社区的信任背书
- 专注于机构级加密金融服务，目标客户为合规机构投资者

## 竞争优势 / 护城河
- Anthony Pompliano 的品牌效应和比特币社区人脉网络
- 与纯持有型 PCV 不同，ProCap 试图构建有实际收入来源的金融服务业务
- 机构级合规定位，可能获得更多传统金融机构的合作

## 风险 / 争议
- SPAC 从零构建金融服务业务的运营复杂性
- 质押和借贷引入信用风险和智能合约风险
- 收入模式尚未验证，路线图依赖于市场环境
