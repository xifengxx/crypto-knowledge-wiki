# SZNS

## 基本信息
- 类型: 区块链数据索引与数据解决方案提供商
- 公链: [[sui]]
- 定位: Sui 区块链专属的数据索引基础设施，解决基于对象模型的稳定币追踪与 DeFi 流动性索引难题

## 核心业务/产品
- **对象级余额重建**：扫描与钱包关联的所有对象，仅保留最新版本用于实时余额查询，旧版本归档用于历史查询
- **统一 DeFi 流动性映射**：识别 DEX 池对象、借贷平台凭证、托管合约等，将各协议特有数据结构规范化为标准内部模型
- **异常处理**：支持锁仓/委托/质押等特殊情况，为非标准对象结构协议引入专门逻辑
- **最终聚合与 API**：提供实时稳定币余额、跨 DEX 流动性、历史状态查询 API

## 关键数据（2025年2月）
- 为 Sui 上《深入探讨 Sui 的流动性激增》一文提供稳定币指标数据来源
- 处理的技术挑战包括：对象版本管理、部分转移导致的碎片化、DeFi 协议数据结构多样性
- 来源: [[来源_2025-02_Sui流动性激增_稳定币_深潮TechFlow]]

## 竞争优势 / 护城河
- **Sui 专属**：专注于 Sui 的基于对象模型索引，与通用的多链索引器形成差异化
- **数据深度**：从对象级精确追踪到 DeFi 流动性映射的全栈能力
- **技术壁垒**：Sui 的对象版本管理和部分转移机制需要专门的索引逻辑，非通用索引工具可替代
