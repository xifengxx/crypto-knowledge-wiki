# Blur

## 基本信息
- **类型**: protocol
- **赛道**: NFT marketplace / NFT lending
- **定位**: NFT 交易市场 + 聚合器 + NFT 借贷协议
- **成立时间**: 2022年10月
- **创始人**: Pacman (Tieshun Roquerre)
- **融资**: Paradigm 领投（金额未披露），Paradigm 合伙人 Matt Huang 支持

## 核心业务/产品

1. **NFT 聚合交易市场** — 支持零费率挂单和竞价，提供批量扫货（sweep）、集合竞价（collection-wide bids）等专业交易工具，聚焦高净值专业交易者
2. **Blend（NFT 借贷）** — 2023年5月推出的点对点永续 NFT 借贷协议，持有者可将 NFT 抵押出借 ETH，无需定期还款
3. **BLUR 代币激励体系** — 多赛季（Season 1/2/3）积分空投系统，通过交易费返还和竞价奖励激励流动性提供，被称为"积分游戏集大成者"
4. **Blast L2** — 2024年2月由同一创始人推出的以太坊 L2，与 Blur 生态紧密关联

## 关键数据

- **市场份额**: OpenSea + Blur 在 2023 年初合计占领约 80% 的 NFT 市场交易份额 ([[来源_2023-04_Web3确定性_金字塔分析框架_The_Quibbler]])
- **替代效应**: Blur 通过代币激励取代 OpenSea 成为主要 NFT 交易市场 ([[来源_2024-02_GSR数字资产参考包_Web3入门指南_BlockBeats]])
- **行业背景**: NFT 市场整体交易量从 2021 年底峰值下降约 95%，价格从峰值下跌 80% 以上 ([[来源_2024-02_GSR数字资产参考包_Web3入门指南_BlockBeats]])
- **投资者**: Paradigm — 同时也是 Blur 积分游戏模式的核心支持者 ([[来源_2023-08_friend_tech深度解析_Paradigm加持_吴说]])
- **BLUR 代币**于 2023 年 2 月上线，通过多赛季空投分发

## 竞争优势 / 护城河

- **代币激励飞轮**: 首创积分+赛季空投模式，将用户锁定在平台内持续提供流动性，后被 friend.tech 等大量借鉴
- **专业交易工具**: 集合竞价、批量扫货、组合管理仪表盘等面向专业交易者的功能，在 trader-friendliness 上明显优于 OpenSea
- **零费率定价**: 不收取平台交易费，通过代币激励代替传统收入模式，迅速抢占交易量市场份额
- **一鱼多吃**: 从交易市场到借贷协议（Blend）再到 L2（Blast），构建多层捕获价值的 NFT 生态体系
- **Paradigm 背书**: Paradigm 的投后赋能和生态资源支持

## 风险 / 争议

- **洗盘交易质疑**: 零费率+代币激励模式被批评为鼓励洗盘交易（wash trading），交易量数据可能存在虚高
- **创作者版税**: Blur 将版税设为可选设置，引发创作者社区强烈不满，与 OpenSea 的强制版税政策形成对比
- **鲸鱼导向**: 产品和代币机制偏向专业交易者和大户，零售用户和小型收藏家边缘化
- **NFT 市场结构性萎缩**: 2022 年后 NFT 交易量整体萎缩约 95%，即便 Blur 占据主导地位，整体赛道也在缩水
- **代币抛压**: 多赛季空投导致 BLUR 代币持续面临解锁和抛售压力
