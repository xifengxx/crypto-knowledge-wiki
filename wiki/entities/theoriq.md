# Theoriq (TheoriqAI)

## 基本信息
- 类型: AI Agent 协调层 / 群体智能平台
- 核心机制: 元智能体（Meta-Agent）+ 信誉跟踪
- 赛道: AI 基础设施 / Agent 协作 / 群体智能

## 核心业务
使用元智能体（Meta-Agent）识别最适合某项任务的智能体，自动组建"群体"（Swarm）来完成目标任务。平台还通过跟踪智能体的信誉和贡献，确保任务质量和责任分配。

## 关键差异化
- **Meta-Agent 调度**: 不是预设 Agent 协作关系，而是由元智能体动态识别→匹配→组队
- **信誉系统**: 跟踪每个 Agent 的历史表现和贡献，形成去中心化的 Agent 评价体系
- **任务驱动**: 以任务完成为导向的临时群体组建，而非固定的 Agent 编队

## 在 AI Agent 生态中的定位
属于去中心化 AI 基础设施六层架构中的"群体智能与协调层"（0xJeff 框架）。与 FXN（统一通信+商业协议）和 Virtuals Agent Society（Agent 间服务交换）共同构成 2025 年 Agent 协作基础设施的三条路径。Theoriq 的独特之处在于其信誉系统——在开源、无许可的 Agent 生态中，可信评价机制可能是最稀缺的基础设施。
