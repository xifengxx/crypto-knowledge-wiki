# Legion

## 基本信息
- 类型：社区驱动投资平台 / 新一代 IC0 平台
- 孵化方：Delphi Labs
- 定位：通过数据评估筛选"有意义的贡献者"，而非仅凭资本量分配投资额度
- 关联概念：价值驱动参与者选择（value-driven participant selection）

## 核心业务/产品
- **Legion Score 评分系统**：量化投资者价值的核心机制，评估四维度：
  - 链上活动（on-chain activity）
  - 社交影响力（social influence）
  - GitHub 贡献（GitHub contributions）
  - 项目团队背书（project team endorsements）
- **Cover Letter 机制**：投资者在提交 Legion Score 的同时需提交 Cover Letter，阐述自己能为项目贡献什么、有何计划，以此建立与项目的信任关系
- **社区投资轮次**：为项目匹配合适的社区投资者，而非仅追求融资金额最大化

## 竞争优势 / 创新点
- 从"资本民主化"转向"贡献民主化"——不是谁有钱谁投，而是谁能贡献谁投
- 多维数据评估降低纯财务投机者占比
- Cover Letter 机制增加了投资者与项目之间的双向筛选和信任建立

## 关键数据
- 投资案例：Fuel（27 倍收益，来源：[[来源_2025-01_Echo_Legion_Buidlpad_新一代IC0平台崛起]]）
- 与 Echo（天使联合投资）和 Buidlpad（大众 IC0）并列为 2024-2025 新一代 IC0 平台三巨头

## 风险 / 争议
- Legion Score 的四维权重设计可能制造比传统 VC 更隐蔽的准入偏见
- 链上数据和社会影响力的量化能否真正筛选出"有意义的贡献者"待验证
- VC 抵制新一代 IC0 平台 → 反向验证新模式威胁性，但也意味着与主流资本对接困难
