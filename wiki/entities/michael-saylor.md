# Michael Saylor

## 基本信息
- 身份: MicroStrategy (MSTR) 联合创始人、执行主席，比特币最具影响力的企业级布道者
- 教育: 麻省理工学院 (MIT) 航空工程与科学史双学位
- 关键转折: 2020年8月带领MicroStrategy将公司储备资金转为比特币，开创上市公司BTC财政储备先河
- 个人风格: 以结构化幻灯片演讲著称，善于用比喻、历史类比和量化模型推广比特币策略

## 核心思想体系

### 货币物理学 (Monetary Physics)
Saylor 将特斯拉的"能量、频率、振动"宇宙观翻译为货币领域：
- **能量** = 货币/资本/财富
- **频率** = 持续时间/生命周期
- **振动** = 每一次交易/转移/资产转换
- **核心公式**: 资产寿命 = 资产价值 / 维护成本 (与 stock-to-flow 概念等价)

### 资产寿命层级
Saylor 将所有资产按寿命排列为三层：
1. **金融资产**: 平均30年寿命（阿根廷比索2年 → 共同基金最优约100年）
2. **实物资产**: 50-75年（法拉利5年 → 英国皇家地产958年但经7个家族更迭）
3. **数字资本(比特币)**: 1000-100000年（机构托管1000年 → AI托管100000年）

### 交易的根本原则
"沿这个方向交易永不出错":
- 暂时的 → 永久的
- 货币 → 资本
- 脆弱的 → 韧性的
- 本地的 → 全球的
- 实体的 → 数字的
- 证券 → 商品 → 稀缺性资产

### 四级策略梯度
为个人/公司/机构/国家分别建模5级策略（普通人/10%/最大主义/双重/三重），核心洞察：
- **个人**: 三重最大主义需15.9 BTC，21年→$2.14亿；6.25 BTC即可"成为富人"
- **公司**: MicroStrategy 48个月实现1300%增长，是三重最大主义策略的活证据
- **国家**: "第一个通过发行自身货币购买比特币的国家将会赢"
- 国家层面三重最大主义者"名额不多，可能只有一个或两个"

### 比特币价格预测 (2024年提出)
- 基准2045年: $1300万/枚，占全球资产7%
- 熊市: $300万/枚
- 牛市: $4900万/枚
- 年回报率从55%逐渐收敛至~20%（仍为S&P指数两倍）

### BTC评级与BTC风险框架（2025年提出）
为论证Strategy可转换债券的信用利差过宽（500-1250基点），Saylor提出两个新概念：
- **BTC评级**（BTC Rating）：当前BTC价格下，比特币持有量对债券面值的倍数。例如2028年9月债券的BTC评级为52.1倍，意味着BTC价值是该债券面值的52.1倍
- **BTC风险**（BTC Risk）：通过期权定价模型，基于当前BTC价格和波动率计算BTC价格跌破清算价格的概率
- **BTC信用**（BTC Credit）：将BTC风险输入债券定价模型后生成的"合理"信用利差
- Saylor认为信用评级机构未能充分评估BTC抵押物价值，导致市场误判Strategy的债券违约概率

### MicroStrategy 9条BTC原则
1. 无限期、独家、安全地购买并持有BTC
2. 优先考虑MSTR普通股的长期价值创造
3. 尊重、一致和透明地对待所有投资者
4. 通过智能杠杆构建MSTR，以超越BTC
5. 持续购买BTC，同时实现正向BTC收益
6. 根据市场动态快速且负责任地增长
7. 发行由BTC支持的创新固定收益证券
8. 保持健康、稳健、纯净的资产负债表
9. 促进全球采用BTC作为财政储备资产

## 历史类比方法论
Saylor 擅长用历史上的"万亿美元交易"论证比特币价值：
- 曼哈顿岛: $24的纺织品→$2.5万亿，398年复合回报10.5亿倍
- 路易斯安那购地: $1500万→$12万亿+，80万倍回报
- 阿拉斯加: $700万→数万亿美元石油
- 比特币 = "网络曼哈顿"：现在买入如同1867年买阿拉斯加
