# focEliza

## 基本信息
- 类型：AI Agent 链化基础设施（DA 层 + Agent 链）
- 生态归属：ai16z (ElizaOS) 生态系统
- 定位：为 AI Agent 提供专属 Data Availability（DA）能力的链化解决方案
- 叙事阶段：早期（2024年12月时点）

## 核心业务/产品
- **AI Agent 专属 DA**：专为 LLM 上下文和大模型语义设计的区块空间，不同于传统 EVM 公链的 DA 方案（如 Celestia/EigenDA 主要服务 Rollup 交易数据）
- **DA 四大难题攻坚**：LLM 上下文有效语义的区块空间精准记录、Character 角色设定插件与 DA 区块的实时交互、多区块空间中多模态数据的有效匹配、多层存储成本优化（短期记忆/长期记忆/工作记忆的分层存储）
- **链化破局点**：以 DA 能力作为切入 AI Agent 链化的核心差异化定位，成为 ai16z 生态在链化方向的关键布局

## 关键数据
- 所属叙事阶段：AI Agent 链化（叙事五阶段中的第五阶段）
- 竞争对手框架：Virtuals (Base 链 Agent 平台)、其他 Agent 框架（Eliza/arc/ZerePy 等）
- 链化基建需求栈：TEE + DA + Oracle + zkVM + 链抽象（focEliza 占据 DA 层）

## 竞争优势 / 护城河
- 背靠 ai16z (ElizaOS) 生态——市占率约 60% 的 AI Agent 框架，生态网络效应强
- DA 作为差异化切入点——避开与 Celestia/EigenDA/ Avail 在传统 Rollup DA 市场的正面竞争，开辟 AI Agent 专属 DA 新赛道
- 第一波链化叙事先发优势——"第一波的「链化」叙事一定来自 ai16z 生态系列"

## 风险 / 争议
- 2025年实际进展未兑现预期——链化叙事整体降温，focEliza 的产品落地和生态进展未达 2024 年底的乐观预期
- AI Agent 专属 DA 需求是否真实存在尚未被验证——当前 AI Agent 仍处于 MEME 化「发行资产」的初级阶段
- 链化基础设施建设周期极长，且需要 TEE/Oracle/zkVM/链抽象等多模块协同——单点突破的价值有限
