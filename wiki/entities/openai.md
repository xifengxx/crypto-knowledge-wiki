# OpenAI

## 基本信息
- 全称: OpenAI LP / OpenAI Inc.
- 成立时间: 2015 年（非营利），2019 年引入有限盈利结构
- 创始人团队: Sam Altman, Greg Brockman, Ilya Sutskever, Elon Musk（已退出）等
- 总部: 美国旧金山
- 产品: GPT 系列大语言模型（GPT-4/4o/5）、DALL-E、Sora、ChatGPT

## AI Agent 构建者视角的定位
根据 Agent 构建者 superoo7（2024.12）的实战经验，OpenAI 模型在 Agent 场景中具备以下特点：
- **性能稳定可靠**：经过广泛的实际测试，是"行业中的佼佼者"
- **强大的安全机制**：适合需要合规和安全保障的生产环境
- **大多数项目的理想起点**：被推荐为通用用途和推理能力需求的首选
- 定位为封闭源代码模型，按使用量付费，由提供商托管运行

## 关键数据
- **2025年Q1融资$400亿**：为2025年Q1美国最大单笔VC交易，占美国VC总支出的显著份额
- **累计融资**：已超过$400亿（含2025年Q1 $400亿轮）——历史上融资最多的AI公司

## 在加密货币/AI Agent 生态中的位置
- 多数 AI Agent 框架支持 GPT API 调用（OpenRouter 集成）
- 与 Claude 构成封闭源 LLM 的双寡头格局
- 在 AI 推理质量要求高的 Agent 场景（如交易策略分析、复杂决策）具有竞争力
- 2025 年 9 月与 Stripe 联合推出 ACP（Agentic Commerce Protocol），定义 Agent 经济中的商业标准，在 ChatGPT 中率先实现 Instant Checkout 功能

## Agent 支付相关事件
- **ChatGPT Instant Checkout 失败**：2025 年 9 月高调发布，五个月后悄然下线。百万 Shopify 商户中只有大约 12 个接入。消费者乐意让 AI 推荐产品，但并不愿意在聊天界面里直接付款——这是「AI 辅助的人类支付」和「Agent 自主支付」之间区别的标志性反面案例
- **MPP 首批接入**：Stripe 发布的 MPP（Machine Payments Protocol）发布首日，OpenAI 作为 100+ 接入服务之一

## 关键争议
- 2023-2024 年经历多次高层人事动荡（Sam Altman 短暂被罢免/Ilya Sutskever 离职创业）
- 安全与商业化之间的平衡争议（Anthropic 创始团队原为 OpenAI 安全研究成员，因安全理念分歧出走）
- 封闭源策略 vs 开源社区的对立
- **o1推理模型战略失误**：2024年9月发布的o1推理模型（推理范式开创者）既不开源、不公布技术细节，且收费极高，导致无法像DeepSeek-R1那样触达全球C端用户。清华大学刘知远认为这相当于"把原属于ChatGPT的身位让给了DeepSeek"——DeepSeek-R1凭借免费+开源+完整思考过程展示迅速登顶全球140国App市场。谷歌Gemini Flash 2.0 Thinking随后发布但同样未掀起波澜
