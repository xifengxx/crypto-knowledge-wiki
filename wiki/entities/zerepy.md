# ZerePy

## 基本信息
- 类型: Python 开源 AI Agent 框架
- 编程语言: Python
- 定位: 简化个性化 AI Agent 的开发和部署，专注社交平台内容创作

## 核心功能
通过框架轻松创建能在社交媒体上发布、回复、点赞和转发的 AI Agent。特别适用于音乐、备忘录、NFT 以及数字艺术等创意领域。

## 市场地位（2025.01）
- 市占率约 5%（2024.12 数据，在四大框架中最小）
- 追赶者角色，落后于 G.A.M.E / Eliza / Swarms

## 竞争优势
- Python 语言门槛低（vs Rust/Rig）
- 社交创意领域差异化定位
- 适合快速部署轻量级 Agent

## 局限
应用范围相对较窄，集中于社交内容创作和创意领域，不如 G.A.M.E（通用平台）和 Eliza（跨平台多 Agent）覆盖面广。
