# Soulgraph

## 基本信息
- 类型: AI Agent 个性化基础设施平台
- 赛道: AI Agent 基础设施 / 人机交互
- Twitter: @soulgra_ph
- 网站: soulgra.ph
- 代币: GRPH（Solana 链，截至 2024.12）
- 创建时间: 2024年12月20日
- 历史市值: 最高 $23M / Odaily 选取时 $23.5M（2024.12.31）

## 核心业务/产品
一个智能体基础设施平台，致力于通过赋予 AI Agent 丰富的个性、记忆能力和自然的交流方式，使其更加真实和贴近人类。

### 三大核心工具

1. **Soulscript**：一套开源规范，用于定义 Agent 的个性。使其能够在不同平台上保持一致，并基于用户交互进行思考、反应和成长。相当于 Agent 的"性格操作系统"。

2. **Soulgraph Memory**：Agent 的持久性记忆功能，支持记住对话内容并持续学习，从而与用户建立独特且个性化的长期联系。不是简单的聊天记录，而是结构化记忆系统。

3. **Soulgraph Presence**：实时通信基础设施，包括语音通话功能，以及即将推出的响应式虚拟形象，使交互更加自然和吸引人。

### 定位
通过标准化 Agent 的行为、记忆和表达方式，将 AI Agent 从简单的工具转变为令人难忘的虚拟伙伴，促进更真实的情感连接和更广泛的应用普及。

## 竞争优势 / 护城河
- 标准化的 Agent 个性框架（Soulscript）有成为行业标准的潜力——类似 ERC-20 之于 Token
- 三个工具覆盖 Agent "人格闭环"：定义→记忆→表达
- 持久记忆+跨平台一致性解决了当前 AI Agent "无记忆、无个性" 的核心痛点

## 风险 / 争议
- "让 Agent 更人性化" 的叙事虽动人，但落地路径长，短期商业价值不明确
- 记忆功能涉及隐私问题，如何在个性化与隐私保护间平衡
- 与 Eliza 的角色系统、Virtuals 的个性化功能存在功能重叠
