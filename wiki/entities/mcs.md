# MCS

## 基本信息
- 全称: MCS（Medical Coding System / 医疗诊断多智能体系统）
- 类型: 基于 Swarms 的多 Agent 医疗诊断应用
- 创建者: Kye Gomez（Swarms 创始人）
- 公链: Solana（推测，基于代币合约地址 pump 后缀）
- 代币合约: ALHFgnXSenUv17GMdf3dL9gtFW2KKQTz9avpM2Wypump

## 核心业务
基于 Swarms 多代理协作框架构建的生产级医疗诊断和编码系统。用户通过与 MCS 对话，可以免费诊断和分析医疗及保健相关问题。API 宣称即将为美国最大的医疗供应商之一投入生产。
