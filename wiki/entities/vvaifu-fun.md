# vvaifu.fun

## 基本信息
- 类型：AI Agent 无代码发射台
- 链：Solana
- 代币：VVAIFU
- 定位：面向社交媒体影响力的快速 Agent 部署平台
- 首次出现于英文媒体：2024.11（Bankless）

## 核心业务/产品
vvaifu.fun 是一个在 Solana 上无需技术背景即可快速创建 AI Agent 的平台。与 Virtuals 的 IAO 范式和 ai16z 的开发者框架不同，vvaifu.fun 追求"秒级部署"——将 AI Agent 发射简化为填写表单+支付代币，产物直接通过 pump.fun 绑定曲线合约自动上币。

## 双框架支持
1. **Eliza Framework（ai16z）**：支持高级个性化定制，但使用需额外付费
2. **自有框架**：为快速部署优化的简化路径

## 与 pump.fun 的集成
- Agent 代币通过 pump.fun 的绑定曲线合约自动发行
- Agent 在 pump.fun 和 vvaifu.fun 双平台可见
- 这意味着 vvaifu.fun 的 Agent 本质上是带有 AI 外壳的 Meme 币——快速冷启动的优势 vs pump.fun 约 1% 代币毕业率的现实

## Agent 功能
- 管理微支付
- 执行智能合约
- 建立所有权证明（支持共同所有权和民主化参与）
- 可选连接 Twitter 账户，上线后自动发推

## 代币经济学
- VVAIFU 为平台实用代币
- 用途：创建 Agent、推广内容、训练 AI
- 创建费用：2,500 VVAIFU + 0.1 SOL（2024.11）

## 竞争定位
- **vs Virtuals**：vvaifu.fun 是"快餐式"Agent 工厂 vs Virtuals 的"精品店"IAO 模式。Virtuals 有 $4.2K/$420K 双阈值激活机制（Agent 需市值证明才解锁功能），vvaifu.fun 无此约束——Agent 上线即全功能
- **vs pump.fun**：vvaifu.fun 是 pump.fun 的上层应用——给 Meme 币加上 AI Agent 的"智能"外衣。pump.fun 提供底层债券曲线基础设施，vvaifu.fun 提供 Agent 人格/行为定制

## 风险 / 争议
- pump.fun 代币毕业率约 1%，vvaifu.fun Agent 的实际存活率缺乏公开数据
- "无代码+秒级部署"意味着 Agent 质量可能参差不齐，大量低质量 Agent 稀释平台价值
- VVAIFU 代币价值捕获不清晰——创建费 vs 生态增长的关系未论证
