## 核心要点
- BRC-20 基于 Ordinals 协议，通过 JSON 铭文格式在比特币链上实现同质化代币发行，本质是文本类型铭文而非智能合约
- 与 ERC-20 相比无法与智能合约交互、不支持小数点和销毁功能，但反向成为优势：杜绝项目方和 VC 预留，实现真正公平分配
- ORDI 作为 domodata 部署的首个实验性 BRC-20 代币，发行后涨幅超 100%，被视为 BRC-20 发展雏形
- 实操流程：注册 Unisat 钱包 → 存入 BTC → ordinalswallet 链接 → brc-20.io 交易，同时支持自行通过 Deploy/Mint/Transfer 协议指令操作
- 与 Omni 协议对比：Omni 基于染色币逻辑（分割比特币地址写入数据）推出过早，错失发展良机；Ordinals 直接用 sats 铭刻更简洁
- 行业担忧四方面：用户参与门槛高（节点搭建 + 高昂 BTC）、协议是否昙花一现、内存池严重拥堵、代码漏洞暴露生态治理困境
