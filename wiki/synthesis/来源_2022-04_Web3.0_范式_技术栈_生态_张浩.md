# Web 3.0 的范式、技术和生态全景综述

## 阅读证据
- 总行数: 440
- Q1 (前25%): Web 3.0 核心原则是去中心化——"在 Web 2.0 中，计算机以唯一网址的形式使用 HTTP 来查找信息，这些信息存储在固定位置，通常存储在单个服务器上。使用 Web 3.0，由于信息将根据其内容找到，因此可以同时存储在多个位置。"即打破互联网巨头对数据库的垄断，将控制权交还用户。

## 核心要点
- Web 3.0 的定义经历了从 Tim Berners-Lee "语义网"（机器可读的集成通信框架）到 Gavin Wood "去中心化区块链互联网"（基于共识引擎和密码学的无须信任交互系统，终极目标是"Less trust, more truth"）的范式转移，当前讨论以 Gavin Wood 版本为主。
- 三代互联网范式对比清晰：Web 1.0（只读，1991-2004，平台创造/所有/控制/受益）→ Web 2.0（读写，2004-至今，用户创造/平台所有/控制/分配）→ Web 3.0（价值互联网，用户创造/所有/控制，协议分配）。核心矛盾是 Web 2.0 下用户数据不属于自己，平台倒闭则所有个人数字资产随之消失。
- 技术栈采用 Web3 Foundation 的 L0-L4 五层架构：L0（P2P 覆盖协议 + 平台中立计算描述语言如 EVM/Wasm）→ L1（数据分发协议如 IPFS、零/低信任交互协议如 Polkadot/Bitcoin、瞬时数据消息如 Whisper）→ L2 中间件（状态通道如 Lightning/Raiden、Plasma、加密存储、预言机、分布式秘密管理）→ L3（开发者 API/语言层如 Solidity/Vyper/Rust + ethers.js/web3.js）→ L4（DApp 浏览器层如 MetaMask/Status/imToken）。
- Web 3.0 生态六大板块：Web3 应用（开放协议回归，社区使用和维护基础设施可获得激励）、DAO（链上治理，智能合约替代公司章程和董事会选举）、DeFi（低成本/实时/无边界/点对点价值转移，为全球 20 亿无银行账户人口提供金融服务）、稳定币与 CBDCs（私人发行与政府发行并存，竞争创新）、隐私与数字基础设施（数学证明信息有效性而无需提供信息本身）、创作者经济与 GameFi（NFT 赋能创作者绕过中介，游戏资产真正归玩家所有并可跨游戏流通）。
- 文章对 Web 3.0 的态度是"谨慎乐观"——既肯定其"将互联网恢复成设计者所希望的那样：完全透明、可靠且易于使用"，又警示市场乱象："起得最早是理想主义者，跑得最快的是骗子，胆子最大的是冒险家，害怕错过的是韭菜。"对核心栈之外还定义了"扩展核心栈"（侧链、支付通道、跨账本协议、不可变结构化数据库、零知识证明），作为值得投资机构关注的潜力领域。

## 关键数据
- 全球 20 亿无银行账户人口理论上可通过 DeFi 获取金融服务（跨境汇款、价值储存、金融产品接入）
- 技术栈五层架构 L0-L4，从 P2P 网络层到面向用户的 DApp 浏览器层
- Web 1.0 约 1991-2004 年（约 13 年），Web 2.0 自 2004 年起延续至今，Web 3.0 自 2014 年 Gavin Wood 重新定义该词后萌芽——但截至文章发表（2022 年 4 月）仍处于早期
- 四大基本特性：去中心化、去信任化与无权限化、人工智能与机器学习、连通性与无边界网络
- 六大生态板块：Web3 应用、DAO、DeFi、稳定币与 CBDCs、隐私与数字基础设施、创作者经济/链游
- Berners-Lee 于 1990 年 10 月编写了构成 Web 基础的三种技术：HTML（标记语言）、URI/URL（统一资源标识符/定位符）、HTTP（超文本传输协议）

## 与已有知识的关系
- 补充 [[defi]] — 从 Web 3.0 整体技术栈和生态全景的视角，解释了 DeFi 的位置与价值：不仅是"去中心化的金融服务"，更是 Web 3.0 生态中实现无边界、低成本价值转移的核心组件，改变了金融后端基础设施
- 补充 [[gamefi]] — 阐明了链游与 Web2 游戏（如 Fortnite/Roblox/Minecraft）的关键区别：游戏内物品是玩家拥有的 NFT，可交易成通货后兑换其他游戏资源，Axie Infinity 为代表案例证明了"边玩边赚"模式
- 补充 [[stablecoins]] — 明确了稳定币（私人发行加密货币，恒定价值）与 CBDCs（政府发行数字货币，象征国家主权和义务）的定义边界，二者共存竞争创新
- 补充 [[nft]] — 从创作者经济角度阐述 NFT 价值：创作者绕过中介直接与支持者联系，粉丝通过持有 NFT 参与创作者事业并获取份额，且创作者可从二次销售中持续获益
- 补充 [[privacy]] — 引入"数学证明信息有效性而无需提供信息本身"的隐私理念，使隐私与可扩展性不再是取舍关系，从根本上扩展了应用设计空间

## 我的笔记
- 文章写于 2022 年 4 月（上一轮牛市末期），对 Web 3.0 的叙事偏乐观，未涉及 Luna/FTX 等随后爆发的行业危机。2026 年回看，DAO "代码即法律"愿景在实践中遭遇治理攻击、投票冷漠、鲸鱼主导等挑战，理想中的完全去中心化自治远未实现；文章提及的大量项目（如 Loom PlasmaChain、OmiseGO、Coda）已沉寂或转型，说明 Web 3.0 项目死亡率极高。
- 文章本质上是一份行业科普综述而非独立研究，大量引用二手材料（a16z、Chainlink、IOSG VC、甲子光年等）。技术栈 L0-L4 分类框架来自 Web3 Foundation，虽有助于理解整体架构，但实际生态中各层边界模糊——预言机被归入 L2 中间件层，但实际上它与 L1 协议和 L4 应用都有紧密交互，五层线性模型有简化之嫌。
- 文章对 Web 3.0 的定义存在内在张力：同时引用了 Tim Berners-Lee（语义网、机器可读）和 Gavin Wood（区块链、去中心化信任）两个截然不同的路径。两个版本的 Web 3.0 目前融合度很低——语义网方向由 W3C 和 Linked Data 社区推动，区块链方向由 Crypto 社区推动，二者在技术哲学和组织形态上几乎无交集。
