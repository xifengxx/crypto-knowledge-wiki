## 核心要点
- "VC币已死"的根本原因是CEX接盘流动性枯竭——15-20%的市场总流动性已迁移到链上，链上流动性溢出是这个周期 meme 爆火的根本原因
- AMM 与订单簿的本质区别：AMM 在每个价格点都有确定的流动性（通过 TVL 公开），而订单簿流动性由做市商控制，价格和流动性无直接关联，可被操纵——对于长尾资产，订单簿模式本质上是类似互助盘的庞氏结构
- 链上流动性四大来源：DEX LP（含土狗 dev 注入底池和 Meteora DLMM 等策略）、JLP/GLP（LP 所有权打包成理财产品）、各种链上机器人（MEV/狙击/跟单，相当于 AMM 一样确定性的流动性）、散户（占比最小，且很多是自动化策略的附庸）
- 机器人占比高不代表真实用户少——链上流动性的确定性使大量中心化场景无法运行的策略成为可能，这在低流动性资产上尤其明显
- Solana 土狗数量爆炸但毕业率低，不应理解为阴谋集团在抽离流动性——恰恰相反，阴谋集团越赚钱越扩编，吸引更多资金进入土狗盘，总流动性反而在增长（类比 Ethena 的逻辑）
- 收割链上流动性的核心框架：必须具体回答三个问题——流动性以什么形式提供？由谁提供？为什么提供？不能主观臆断某个生态流动性充足
- Pump.fun 仿盘失败的根本原因不是运营或内卷，而是 Bonding Curve 上的策略机器人围绕 Pump.fun 原生生态构建——仿盘无法共享这个机器人流动性网络，必须从零搭建，Makenow 的失败（Twitter API 问题）即是明证
- DEX 直接发射 vs Bonding Curve 是两种完全不同的流动性环境：DEX（如 Raydium/Meteora）上的抢开盘机器人和流动性是跨项目共享的，Bonding Curve 则每个平台独立

## 关键数据
- 15-20%：已从 CEX 迁移到链上的市场总流动性比例（2024年8月，作者估算）
- Pump.fun Bonding Curve 阶段：策略机器人围绕原生 Pump 生态构建，仿盘无法共享
- MakeNow.Meme 案例：已开始有机器人陆续支持，但因 Twitter API 问题功亏一篑——证明机器人流动性对 Bonding Curve 平台是生死线
- Solana/主链土狗总量：数量爆炸但"毕业"率低（具体比例未给出，定性描述），作者认为这反而是流动性扩张的信号而非萎缩

## 我的笔记
这篇文章的价值不在于数据（几乎没有硬数据），而在于提供了一个分析链上流动性的认知框架——特别是将"机器人"定性为"与 AMM 一样确定性的流动性来源"，这在当时是反直觉的（多数人认为机器人占比高=虚假繁荣）。但从2024年8月到2025年的市场演变来看，作者的判断基本成立：Pump.fun 的机器人生态确实成为了其最深的护城河，仿盘无一例外都败在无法复制这个流动性网络上。文章对"Bonding Curve vs DEX直接发射"的区分也极具实操价值——很多项目方至今仍在犯这个错误。

一个值得警惕的盲点：作者是利益相关方（文章末尾暗示"这里因为跟我有利益冲突，不继续深讲"），其"土狗越多=流动性越健康"的逆向观点可能有自我服务偏差。如果阴谋集团真的在持续扩编且越来越赚钱，最终的结局可能是散户被系统性地榨干——这正是2025年 Meme 市场 PvP 极端化的预演。
