## 核心要点
- 币圈自媒体（如上币提醒公众号）因交易所出海陆续关闭，自建上币监控成为替代方案
- 获取上币信息有4条渠道（Telegram、官网、Twitter、API），但发布时间存在差异
- 币安英文版公告比中文版发布时间更早，这是关键发现——许多机器人正是利用这个时间差提前买入新币
- 使用 Python 的 requests-html 库即可从币安英文公告列表页面抓取最新的上币信息
- 爬虫代码可封装为循环检测函数，只在新币种出现时发送通知，实现自动化监控
- 本课程为系列教程的第一课，后续将覆盖通知推送等进阶内容
