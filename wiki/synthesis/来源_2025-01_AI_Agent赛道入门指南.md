## 核心要点

1. **AI Agent vs 大模型**：大模型 = 强大的搜索引擎，被动回答。AI Agent = 从"感知"到"行动"的完整闭环，能自主决策和执行。核心区别在于**自主行动能力**

2. **为什么 AI Agent 需要 Crypto**：三个赋能点——(a) 去中心化运行和验证环境，解决信任问题；(b) 代币激励机制，为团队提供现金流，催生创新；(c) 智能合约实现"永生"，理论上可无限期运行

3. **两阶段叙事**：大模型阶段（基础设施层—算力/算法/数据代币化）→ AI Agent 阶段（应用层落地）。后者再分为三阶段：Meme 币（GOAT/ACT）→ 单体 AI 应用（Game/DeFi/审计/数据分析）→ 框架标准（Eliza/RIG 等）

4. **AI Agent 代币的演化**：从纯 Meme（情绪价值+财富效应）→ 有使用场景支撑的价值币。AI Meme 币的特殊性在于让普通人能参与 AI 革命

5. **框架标准大乱斗**：Eliza（ai16z）、RIG（ARC）等正在竞争 AI Agent 框架标准地位
