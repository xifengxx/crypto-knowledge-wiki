## 核心要点

1. **Virtuals = Base 上最大的 AI Agent 协议**：估值接近 $25 亿（2024.12）。核心产品是让开发者创建和代币化 AI Agent，投资者购买代币分享 Agent 的收益。AI Agent 变成"生产性资产"

2. **AI Agent 的两个核心要素**："眼睛"（感知行为结果/反馈）和"手"（在环境中执行具体动作）。缺任何一个都不能称为真正的 Agent。Truth Terminal 和 GOAT 有趣但缺少自主行动能力——只是微调过的 LLM 说人话

3. **Luna — 第一个雇佣人类的 AI**：Virtuals 的旗舰 Agent，没有银行账户，通过链上钱包直接支付给全球艺术家（在印尼、加拿大、美国、马来西亚墙上绘制她的形象）。体现了"无国界支付 + AI Agent"的实际应用

4. **AIXBT — AI KOL 的商业模式验证**：AI 驱动的加密 KOL，互动率超过人类 KOL（如 Anthem）。Weekee 认为如果 AIXBT 开始收费推广代币，月度收入可达数百万美元。收入通过代币化分配给持有者——这是 AI Agent + 代币经济的闭环

5. **Crypto 两个核心 PMF → AI Agent 同时满足**：(a) 投资/投机——代币化 AI Agent 让人们投资 AI 的生产力；(b) 无国界支付——AI Agent 通过链上钱包全球自由交易。去中心化/DAO 等其他叙事尚未被验证

6. **"每个 SaaS 独角兽对应一个 AI Agent 独角兽"**：未来的 AI Agent 会像 SaaS 一样垂直化——财务 Agent、交易 Agent、医生 Agent、教师 Agent。比 SaaS 潜力大 10 倍（Y Combinator 观点）

## 值得记住的引用

> "一个真正的代理需要'眼睛'和'手'。'眼睛'意味着它能观察到自己行为的结果，'手'则意味着它能在环境中执行具体的动作。通过配合，代理能够形成反馈循环。"

> "加密货币目前有两个核心的产品市场契合点：一个是投资和投机，另一个是无国界支付。去中心化、DAO 这些概念虽然有趣，但尚未被真正验证。"

> "通过代币化，我们可以将一个能够创造财富的 AI 代理转变为生产性资产。人们可以购买这些资产的代币，分享其收益。"

> "每个 SaaS 独角兽都可能对应一个垂直领域的 AI 智能体独角兽。"

## 我的笔记

这篇播客的核心洞察不是技术细节，而是对 Crypto PMF 的诚实判断。Weekee 没有像其他 Crypto 创始人那样大谈"去中心化"和"DAO"，而是承认 Crypto 目前只有两个验证过的 PMF：投机和无国界支付。AI Agent 恰好能同时满足这两个——代币化 = 投机，链上钱包 = 支付。

这和我在 [[stablecoins-reshaping-finance]] 论点中的判断一致：稳定币的无国界支付是最扎实的 PMF，其他 Crypto 叙事（DAO/去中心化治理/数据主权）仍是实验性的。

Virtuals 选择 Base 链也值得关注。Solana 拿下了 DePIN（io.net/Render/Helium），Base 拿下了 AI Agent——不同链正在按赛道分工。这个趋势如果持续，多链生态不是各链做所有事情，而是各链深耕不同赛道。
