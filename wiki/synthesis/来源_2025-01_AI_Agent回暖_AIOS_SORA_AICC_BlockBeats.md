# AI Agent回暖，过去一周有哪些值得关注的新项目 - BlockBeats

- 总行数: 79

- Q3 (中后25%): SORA 代币一经发射，2 小时内市值速通 $19M，24H 交易量高达 $75M，随后市值在 $10M 之上波动
- Q4 (最后25%): AICC 市值最低跌至约 $5000 万，较此前 $3.7 亿高点跌去近 80%；顾问包括 ai16z 创始人 Shaw、Virtuals Protocol 核心贡献者 EtherMage、EigenLayer 开发者关系主管 Nader Dabit、Story Protocol 联合创始人 Jason Zhao

## 核心要点
- 2025年1月中旬 AI Agent 板块经历了一轮"急跌-急反弹"行情：市值从 $190亿 → $115亿 → $184亿，比特币从 $9万以下反弹至 $9.8万带动了整个市场情绪复苏
- AIOS 是产品级 AI Agent 操作系统（GitHub 3700+ stars），将 LLM 嵌入 OS 层解决调度/内存/存储/工具管理等开发部署痛点；基金会宣布销毁 66.61% 总供应量后短时暴涨 150%，市值达 $1.7 亿，但随后因国人盘/FUD 回落至 $40M
- SORA（Sora Labs）是用 Go 语言构建的开源 AI 对话框架，产品矩阵包括 Zen 框架/Hana Twitter Agent/Toolkit/Solana Toolkit，项目方锁定代币 6 个月，上线 2 小时速通 $19M 市值
- AICC（AiccelerateDAO）是 AI 投资与开发 DAO，拥有豪华顾问阵容但上线后参与者迅速抛售引发代币分配争议，从 $3.7 亿市值暴跌至 $5000 万，成为"VC 币"反面教材
- 三个项目均来自 Solana 生态，反映了 AI Agent 在 Solana 上的集中爆发趋势，但也暴露了代币分配结构不透明、抛售风险的行业普遍问题
- 文章暗示 AI Agent 板块已从单纯的概念炒作进入产品化竞争阶段——有实际产品（AIOS 的 OS、SORA 的框架）比纯叙事项目获得更高市场认可

## 关键数据
- AI Agent 总市值波动：$190 亿（1月6日）→ $115 亿（1月13日最低）→ $184 亿（反弹后）
- AIOS：GitHub 3700+ stars，基金会销毁 66.61% 总供应量（64.03% + 2.58%），销毁消息后短时暴涨 150% 市值达 $1.7 亿，后续回落至约 $40M
- SORA：上线 2 小时市值 $19M，24H 交易量 $75M，稳定在 $10M 以上；产品包括 4 个 GitHub 开源项目（Zen/Hana/Toolkit/Solana Toolkit）
- AICC：开盘市值突破 $4 亿，回落后再次突破 $3.7 亿，最终最低跌至约 $5000 万，跌幅约 80%
- Buzz、ai16z、ARC、zerebro 等代币在此前下跌中跌幅达约 50%

## 值得记住的引用
> "AIOS 是人工智能代理操作系统，它将大型语言模型 (LLM) 嵌入到操作系统中，并促进基于 LLM 的人工智能代理的开发和部署。AIOS 旨在解决基于 LLM 的代理在开发和部署过程中遇到的问题（例如调度、上下文切换、内存管理、存储管理、工具管理、代理 SDK 管理等）"

## 我的笔记
- AIOS 的"销毁 66.61% 供应量"是一个极其激进的操作，短时拉盘效果显著但后续跌回 $40M——这种"销毁拉盘"模式不可持续，实质上是把流通盘缩小制造稀缺假象，但基本面未变
- AICC 的崩盘是加密市场反复上演的老剧本：豪华顾问阵容 + 闭门白名单募资 = 内幕抛售。真正的去中心化 AI DAO 需要在代币分配和锁定机制上有根本性的机制创新，而非依赖名人背书。BlockBeats 原文用"群星璀璨到跌落神坛"的叙事框架非常精准
- 值得注意的是 SORA 和 AIOS 都是"先有产品后有代币"的模式（AIOS 的 GitHub 3700+ stars，SORA 的 4 个开源项目），这可能是让它们在此轮反弹中跑赢纯叙事项目的原因——市场开始用是否有实际产品来筛选 AI Agent 项目
