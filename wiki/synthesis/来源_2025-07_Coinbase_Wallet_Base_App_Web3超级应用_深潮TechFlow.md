# Coinbase Wallet 更名为 Base App：从钱包到 Web3 超级应用的转型

## 阅读证据
- 总行数: 121
- Q1 (前25%): Base App 推出 Base Pay，支持 USDC 即时支付，持有 USDC 可获 4.1% APY，已与电商巨头 Shopify 合作
- Q3 (中后25%): $AERO (Aerodrome Finance) 作为 Base 链龙头 DEX，占据 Base 链 TVL 约 14.6% 的份额
- Q4 (最后25%): Flashblocks 技术将区块时间缩短至 200 毫秒，大幅提升交易处理速度，使 Base 交易速度"远远优于 ETH 主网和 Optimism"

## 核心要点
- Base 于 2025 年 7 月 18 日举办"A new day one"活动，正式将 Coinbase Wallet 更名为 Base App，从单一加密钱包转变为集资产、支付、社交于一体的 Web3 超级应用
- Base Pay 推出 USDC 即时支付功能，与 Shopify 合作覆盖全球数百万商家，用户持有 USDC 可享 4.1% APY，并将推出 1% 消费现金返还
- Flashblocks 技术将 Base 区块时间缩短至 200 毫秒，显著提升交易处理速度，支持高频交易、链上游戏和实时应用
- Base Build 计划提供 SDK、API 和资金支持，目标吸引 100 万开发者加入 Base 链生态，"Sign in with Base"简化 dApp 开发流程
- 集成 Farcaster 协议接入去中心化社交平台，支持发帖、分享、查看链上动态、运行 Mini Apps（游戏/DeFi 工具）、创建个人主页和内置聊天
- 文章从投资者机会角度分析受益标的：$AERO（Aerodrome）、$UNI（Uniswap）、$BRETT（Base Meme 币）、$COIN（Coinbase Global）、$CRCL（Circle）

## 我的笔记
- 本文本质上是一篇深潮 TechFlow 的事件报道+投资机会分析，偏乐观叙事，对 Base App 的战略风险（中心化排序器、Coinbase KYC 控制、监管不确定性）几乎没有提及。需要注意该文是 Base 活动后第一时间发布的"利好"报道而非深度分析。
- 将 $BRETT（迷因币）与 $COIN（纳斯达克上市公司）和 $CRCL（Circle 股票）并列为"投资标的"是一个有趣的框架跳跃——把投机标的与传统股票并列，反映了当前 Web3 投资叙事中高风险资产与传统金融资产界限模糊的特征。
- 文章将 Base App 类比为"Web3 世界的 iPhone 时刻"以及"支付宝模式"，但 Base App 能否真正成为超级应用，核心挑战在于用户获取成本、法币出入金摩擦、以及现有 Web2 超级应用（微信/支付宝）的用户粘性和网络效应壁垒。文章未深入讨论这些现实障碍。
