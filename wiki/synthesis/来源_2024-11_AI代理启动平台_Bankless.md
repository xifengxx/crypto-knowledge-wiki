## 核心要点
- 2024年11月 AI Agent 平台已形成四大势力：Virtuals（Base 链 IAO 模式）、ai16z（Solana 开源框架+VC DAO）、vvaifu.fun（Solana 无代码 launchpad + pump.fun 集成）、Holoworld（Base 链 3D 角色+娱乐品牌方向）
- Virtuals 的核心创新是 IAO（Initial Agent Offering）和双阈值激活机制——Agent 必须有足够市值才能获得功能，将代币价格与 Agent 能力直接挂钩，形成自我实现的增长飞轮
- ai16z 的核心差异化在于开源 Eliza Framework 而非封闭平台——开发者可自行部署 Agent 无需平台许可，但这也意味着代币经济价值捕获弱于 Virtuals 的封闭生态
- vvaifu.fun 代表"速度优先"路径——与 pump.fun 共享绑定曲线合约，Agent 代币自动在两平台可见，将 AI Agent 视为 Meme 币的高级形式
- Holoworld 走差异化路线——不是通用 Agent 平台，而是聚焦"娱乐品牌/IP 孵化"，被 Binance 孵化，定位为"下一个迪士尼的发射台"

## 关键数据
- Virtuals 激活阈值：$4.2K 基本功能 / $420K 完整功能（含 Uniswap V2 LP 锁定10年）
- Virtuals 创建 Agent 所需：2,400 VIRTUAL 代币（按当时 ~$0.50/枚 约 $1,200）
- vvaifu.fun 创建 Agent 所需：0.1 SOL + 2,500 VVAIFU + 交易费
- Virtuals 知名 Agent 案例：LUNA（直播AI虚拟偶像）、SEKOIA（链上VC AI）
- ai16z 核心 AI：pmairca（以 Marc Andreessen 为原型的 AI 投资代理），用机器学习评估 DAO 成员投资建议并分配信任评分

## 我的笔记
- Bankless 这篇文章本质是一篇平台导览而非深度分析——四个平台各有一个"How does it work"操作指南，信息密度在操作层面高但在竞争分析层面低。值得注意的遗漏：完全没有提到各平台的代币经济模型差异（如 Virtuals 的交易税 vs vvaifu.fun 的 VVAIFU 实用代币），也没有比较用户基数和 Agent 创建数量。
- 从时间线看，这篇文章发表于 2024.11.27，恰逢 AI Agent 赛道从 Meme 阶段向平台阶段过渡的关键节点。文章中对四个平台"平起平坐"的处理方式本身就是一个有趣的信号——在当时的叙事中，Virtuals 还没有像后来那样以 $50 亿市值碾压对手，ai16z 的 Eliza 也还没有达到 60% 市占率。
- vvaifu.fun 的 pump.fun 集成是本文揭示的一个重要细节：Agent 代币通过 pump.fun 绑定曲线合约自动发行。这意味着 vvaifu.fun 的 Agent 本质上是带有 AI 外壳的 Meme 币——这既是快速冷启动的优势，也是价值可持续性的潜在弱点。pump.fun 代币毕业率约 1% 的背景下，vvaifu.fun Agent 的实际存活率值得关注。
