# Friend.Tech：Web3 社交的新思路还是昙花一现？

## 阅读证据
- 总行数: 83
- Q1 (前25%): Paradigm 融资消息公布后，friend tech 活跃用户迅速增长，单小时买家超过 1.7k，创下历史新高

## 核心要点

1. **Friend.Tech = KOL 影响力代币化**：用户买卖 Twitter KOL 的"股份（Share）"，持有股份 = 进入 KOL 私人聊天室。定价公式 Price = Supply²/16000——二次曲线，越买越贵。每笔交易 10% 费用（5% 归协议，5% 归被交易的 KOL）

2. **数据爆炸**：上线 10 天交易量 1.1 万 ETH，独立用户 3.9 万，51.8 万笔交易。两天收入 $50 万+，Paradigm 投资。Base 链日活因此创新高（13.6 万）。但热度在几周内迅速冷却——这是 SocialFi 的典型生命周期

3. **核心矛盾 = SocialFi 的通用矛盾**：社交需要长期关系，代币投机是短期行为。当赚钱预期消退→社交留存归零。产品本身存在"注意力上限"——每个用户关注的 KOL 数量有限

4. **创始人背景**：Racer 之前做了 TweetDAO（NFT 控制 Twitter 账号）+ Stealcam（Arbitrum 上的"付费开图"图片分享）。Friend.Tech 是 Stealcam 的定位重塑——从图片分享变成社交代币交易。团队最终选择 Base 而非 Arbitrum

## 我的笔记

Friend.Tech 是 SocialFi 最纯粹的形式——把 KOL 的社交价值直接代币化。但它的生命周期的短暂（几周内从"革命"变成"已死"）完美验证了 SocialFi 的核心矛盾：代币投机能带来爆发式增长，但不能带来长期留存。

有趣的是，AIXBT（AI Agent KOL）似乎在走 Friend.Tech 的升级版路线——不是让人类 KOL 被代币化，而是让 AI 自己成为 KOL 并产生收入。AI KOL 不需要社交留存——它们不会累、不会过气、不会有丑闻。这可能是 SocialFi 真正的出路：不是"帮人类 KOL 发币"，而是"AI 自己就是 KOL"。
