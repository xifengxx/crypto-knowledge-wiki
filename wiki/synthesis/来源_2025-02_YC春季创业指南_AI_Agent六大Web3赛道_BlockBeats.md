# YC 2025 春季创业指南中的 AI Agent 趋势：Web3 视角的六大赛道框架

## 核心要点
- YC 2025 春季 RFS 揭示了 Web2 AI Agent 的 13 个创业方向，但作者 Defi0xJeff 认为其中 6 个赛道将主导 Web3 AI Agent 趋势：AI 商业开源软件、Agent 开发工具、垂直 AI Agent、个人 AI 助理、AI 应用商店、B2A（Business-to-Agent）
- AI 商业开源软件赛道中，@ai16zdao 的 ElizaOS 框架为 Web3 开源 AI 运动树立标杆（14k GitHub stars，4,227 次 Fork），DeepSeek 新模型和 OpenAI o3 加速了开源 AI 与 Web3 AI 的融合需求
- Agent 开发工具的核心差异化在于 Web3 引入去中心化、无信任性和开源协作，代表性工具链包括 ElizaOS（最多插件集成）、Solana Agent Kit（@sendaifun）、Coinbase CDP Agent Kit、以及 Virtuals/Holoworld/Cod3x 等无代码平台
- 垂直 AI Agent 已从通用工具进化为高度专业化的领域 Agent（税务、法律、金融），Web3 原生版本（AI 影响者如 aixbt、代币分析 Agent、研究 Agent、DeFAI Agent）更注重自主性和链上集成
- 个人 AI 助理的下一阶段是从被动响应进化为自主 AI 副驾驶（co-pilot），Web3 应用包括空投扫描 Agent、收益耕作/LP 管理 Agent、AI 驱动的 GitHub 代码库分析、自动化交易 Agent
- B2A 将 AI Agent 视为数字经济中的独立客户——需要自己的支付方案（Nevermined）、算力资源（Hyperbolic）、隐私保护（Phala/Ora/brevis）、数据访问（Grass/Vana/Masa/Cookie DAO）、Agent 间通信协议（Virtuals）、知识产权管理（Story Protocol）

## 我的笔记
这篇文章的价值在于它用 YC 的创业框架（一个相对客观的外部信号）来校准 Web3 AI Agent 叙事的合理性。YC RFS 本身没有推任何 Crypto 方向，但作者 Defi0xJeff 做了一次「翻译」工作——把 13 个主流创业方向映射到 Web3 已有的 Agent 生态。这种映射不是投射幻想，因为 Web3 在开源 AI（ElizaOS）、无代码 Agent 构建（Virtuals）、Agent 间通信（M2M→A2A）上的确存在结构性优势。

但有两个警惕点：第一，文中对每个赛道都列出大量项目但未区分成熟度——像 @Nevermined_io 的「AI Agent 的 PayPal」和 @StoryProtocol 的「AI IP TCP/IP」仍然是早期概念，不应与 ElizaOS 的 14k stars 等量齐观。第二，B2A 是一个有力的叙事框架，但它的前提——AI Agent 成为自主经济参与者——在今天（2026年7月）仍然远未实现。B2A 基础设施的搭建速度可能远超 Agent 自主经济行为的发生速度，这意味着这些项目的价值捕获窗口可能很长。
