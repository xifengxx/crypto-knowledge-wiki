# Galaxy Interactive：11 类 NFT 初创企业的 VC 视角

## 阅读证据
- 总行数: 288
- Q1 (前25%): 自2021年以来链游已获130笔约50亿美元投资
- Q3 (中后25%): D&G x UNXD NFT合作销售额达3000万美元
- Q4 (最后25%): NFT元数据存储分布：10%链上、40%中心化服务器、50%IPFS
- 图片: 5处引用（1个外部URL不可访问，4个本地路径图片 — 含标题图与数据图表）

## 核心要点

1. **317 家 NFT 初创企业分 11 类**：白名单/AMM/分析/评估/分期付款/创作工作室/衍生品/所有权分配/基础设施/市场聚合器/借贷。核心判断："NFT 领域已非常拥挤，相对其 TAM 已获得足量资金——大多数初创企业只是在相同构件上做微小改变"

2. **最盈利的是市场平台（Opensea），最难规模化的是借贷和衍生品**：(a) 市场平台竞争靠 Token 激励+低手续费，但交易量难维系（LooksRare/X2Y2）；(b) NFT 借贷 TAM 受限于少数蓝筹资产和借款人——年利率 15-75% 但底层流动性不足；(c) NFT 衍生品（期权/CDS/合成资产）的致命伤是底层资产流动性不够，做市商不愿提供连续市场

3. **核心矛盾——估值与基本面脱节**：Token 定价 = 期权定价模型（禁售期+流动性深度+叙事热度），而非基本面。某些未发产品的 FDV 已超 Bethesda 卖给微软的价格。2022 Q3 开始只有经验丰富的创始人能以 Token FDV 融资——纯 Token 公开发行已很少见

4. **基础设施的中心化现实**：10% NFT 链上存储、40% 中心化服务器、50% IPFS——与 NFT 关联的媒体有丢失风险。市场结构远比宣称的去中心化程度中心化得多

5. **下一个"零到一"在 Soulbound Token + 信任原语**：Vitalik 的 SBT + 微软研究院/Flashbots/以太坊基金会的研究——将身份/信任与开放市场原语结合

## 关键数据

- 2021年以来链游获 130 笔约 $50 亿投资（DappRadar 认为可达 $110 亿）
- 分析 317 家 NFT 初创，分 11 类别
- 80-95% 的 NFT 交易量可能是清洗交易
- NFT 借贷年利率 15-75%，LTV 25-75%
- NFT 媒体存储：10% 链上 + 40% 中心化 + 50% IPFS
- LooksRare/X2Y2 抢夺 Opensea 份额但交易量难维系

## 我的笔记

Galaxy Interactive 是 Crypto 游戏/NFT 领域最活跃的 VC 之一。这篇文章最诚实的部分是承认了 NFT 基础设施的 TAM 可能被严重高估——317 家初创抢一个不大的市场，80-95% 的交易量可能是假的。这和 ChainCatcher 的"产能过剩"判断一致。

但他们对 Soulbound Token + 信任原语的判断非常有远见（2022 年 10 月）。回头看 2024-2025 年：SBT 概念确实没有大规模落地，但 DID + 链上声誉的方向是对的——只是比预期慢得多。
