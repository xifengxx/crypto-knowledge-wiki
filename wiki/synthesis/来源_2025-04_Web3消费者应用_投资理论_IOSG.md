# 综述 Web3 消费者应用范式及投资理论思考 — IOSG Ventures

## 核心要点
- Alliance DAO 的投资偏好从 2021-2023 上半年的 Games 和创作者经济，在 2023 下半年切换为 Crypto 投机类、SocialFi 类以及财务类，反映出对"靠 Token 金融属性驱动增长"模式更明确的押注
- Web3 消费者应用存在三种范式：(1) 利用 Web3 技术特性（隐私/可信执行环境）优化传统产品；(2) 利用加密资产设计市场策略、用户忠诚度或直接变现；(3) 完全服务于 Web3 原生用户，创造新资产类别或提供工具化产品
- 每种范式都有对应的难点：第一种面临"隐私保护 vs 商业模式"的根本矛盾；第二种面临"投机用户扭曲 PMF 验证"的核心陷阱；第三种则面临定价权争夺的激烈竞争和耐心建设的挑战
- 超越投机周期是 Web3 消费者应用首要考虑的问题——Friend.Tech 案例表明 Token 过度捆绑产品实用性会导致用户脱离产品价值本身
- 提出"应用工厂模式"：参考字节跳动策略，在累计大量用户资源后，不断试错、由市场选择成功方向，降低创意验证成本
- 四种最有潜力找到 PMF 的类别：Web3 社交应用、链上交易工具、支付类应用、DeFi（特别是高性能高频交易场景）

## 关键数据
- Alliance DAO 累计孵化/投资 28 个 Web3 消费者应用，覆盖 7 个细分赛道
- Friend.Tech 累计 Protocol Fee $24,313,188，累计用户 918,888 个
- Solana 被认为更有利于 Consumer 应用成功，原因包括：社区活力更强、生态资源支持更快、基础设施成本更低、非 EVM 技术选型带来更高产品竞争壁垒（Copy 成本更高）
- 四种最有潜力类别：Web3 社交、链上交易工具（如 GMGN/OKX Wallet 的爆火验证需求）、支付类应用（跨境支付/闲置资金理财）、DeFi（Hyperliquid 式去中心化高性能金融）

## 值得记住的引用
> "对消费者用户对隐私的重视是建立在发生大规模的隐私泄露与侵权事件的基础上，但在大部分情况下，通过更完善的法律法规的制定，是可以有效缓解该方面问题，因此若对隐私的保护是建立在更复杂的产品体验或更昂贵的使用成本上时，其竞争力将明显不足。"

> "利用 Token 的金融属性直接变现，也就是项目直接卖币套现...这是一种不可持续的商业模式，原因在于当项目发展度过早期高成长阶段后，由于缺乏增量资金流入，这种零和博弈的模式将不可避免的让项目方的利益站在用户利益的对立面。"

> "Friend.Tech 将代币与产品的实用性做了过度的捆绑，导致其产品中 Web3 投机用户过多，让用户脱离对产品的实用性的关注，最终导致现在的局面。"

## 我的笔记
- 本文最核心的贡献是对 Web3 消费者应用的三种范式做了清晰的分类学归纳，尤其是对每种范式"机会点 vs 难点"的结构化分析，框架性很强，超越了单纯的项目罗列。这三种范式相互之间并不互斥，但在战略选择上需要明确优先级。
- 关于"应用工厂模式"的提法值得注意：这实际上变相承认了"寻找 PMF 是一个高失败率过程"这一残酷现实，而 Web3 的高流动性和 Token 激励可能使试错成本比 Web2 更高。Friend.Tech 虽然在意识形态上被视为"失败"，但从工厂模式看它的营收能力和用户基数反而是下一阶段成功的资产——这个视角打破了非黑即白的项目评判。
- 文章对 Alliance DAO 投资理念的总结非常清晰，但缺乏对这些理念实际效果的验证数据。例如，Alliance DAO 2023 下半年切换至 Crypto 投机类/SocialFi 类是否带来了更好的回报？Pump.fun 的成功是否复现了 StepN 当年的增长曲线差异？这类回溯验证的缺失让本文更像一份"路演综述"而非投资业绩归因。
