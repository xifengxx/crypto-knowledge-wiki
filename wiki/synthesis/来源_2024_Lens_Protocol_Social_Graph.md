# Lens Protocol：链上社交图谱

## 核心要点
1. Lens Protocol：Aave 团队关联的链上社交图谱协议。用户拥有自己的社交关系（关注者+内容），不依附平台
2. NFT 化社交关系：关注=NFT、发布=NFT——社交行为变成可组合的链上资产
3. 与 Friend Tech 不同路线：Lens 是基础设施层，Friend Tech 是应用层

## 与已有知识的关系
- 补充 [[socialfi]] 概念页：Lens vs Friend Tech 是 SocialFi 的两条路线

## 我的笔记
Lens 的愿景是"社交关系的 HTTP 协议"——一个任何应用都能读写的开放社交图谱。这比 Friend Tech 的 Ponzi 模型更有长期价值，但迁移用户从 Twitter/Facebook 过来的难度是天文级别的。社交网络是人质交换——你离不开 Twitter 不是因为 Twitter 好用，是因为你的朋友都在上面。

## 关键数据
- Lens Protocol 由 Aave 团队关联方开发，已集成 50+ 应用
- Friend Tech 巅峰期 TVL $3000 万+，日活从峰值暴跌 >95%

## 值得记住的引用
> "Lens 是基础设施层（社交图谱协议），Friend Tech 是应用层（金融化社交）。"

## 我的笔记
SocialFi 的核心矛盾：社交需要网络效应（人质交换），但代币投机是短期的。Friend Tech 的起落完美验证了这一点。Lens 选择做基础设施可能更聪明——不自己做社交应用，让开发者在其上构建。但问题是：开发者为什么要在 Lens 上构建，而不是在 Twitter API 上？
