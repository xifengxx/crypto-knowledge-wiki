# DePIN 赛道概览：2025 年值得关注的四个核心项目

## 核心要点
1. **DePIN 的定义与运作原理**：DePIN = Decentralised Physical Infrastructure Networks，用区块链激励众包物理基础设施（传感器、存储、算力、带宽、能源），取代传统中心化部署模式。文章系统介绍了 DePIN 的四组件架构：节点提供者、验证层、代币激励、应用层

2. **2025 年 DePIN 三大驱动力**：去中心化基础设施需求上升（AI 代理/DeFi/链游需要算力、存储和数据）、众包基础设施的成本优势（特别是在新兴市场）、AI/IoT/区块链三大技术趋势的交叉汇聚

3. **四个值得关注的项目**：
   - **Helium ($HNT)**：从 IoT LoRaWAN 转向 5G，2025 年加速全球部署
   - **Render Network ($RNDR)**：去中心化 GPU 渲染，向 AI 推理延伸
   - **io.net ($IO)**：Solana 原生 ML 算力市场，AWS 替代品
   - **SubQuery Network ($SQT)**：从数据索引扩展至去中心化 RPC，支持近 300 条链

4. **VC 资金涌入**：据 Messari 2025 报告，DePIN 项目自 2023 年以来吸引超过 $1B 风险投资

5. **SubQuery 的自我定位**：文章由 SubQuery Network 官方发布，强调其在 DePIN 叙事流行之前就已构建去中心化基础设施（数据索引、激励系统、争议解决），2025 年新增去中心化 RPC 服务

6. **DePIN 是新型经济模型**：文章结论认为 DePIN 已超越加密实验，成为"众包基础设施的新型经济模型"
