## 核心要点
- daos.world 是 Base 上的 DAO 对冲基金发行平台，灵感源自 Solana 上的 [[daos-fun]]，允许任何人创建和管理一个代币化的交易基金
- 基金创建者通过预售筹集资金（以 ETH 计价），完成后在 Uniswap V3 上线代币，采用**单边流动性**设计（仅基金代币侧）——预售参与者无法立即抛售，需等待外部 ETH 流动性进入
- 基金经理的激励机制来自 Uniswap V3 交易费用分成：基金经理获得 LP 费用的 **0.4%**，平台收取 **0.6%**；用户也可自行添加流动性赚取收益
- 基金经理可调用任意链上智能合约，理论上可执行杠杆交易、套利、借贷杠杆挖矿等任意 DeFi 策略
- 平台试图通过基金净值机制为代币提供基础价值锚定，是对 memecoin"无基本面"批评的结构性回应，同时部分减轻了代币发行时的 sniper 抢跑影响
- 智能合约设有紧急退出功能——但仅在募资阶段有效，代币上线 Uniswap 后平台无法再接触资金

## 与已有知识的关系
- 补充 [[daos-fun]] — daos.world 是将 daos.fun 模式从 Solana 移植到 Base 的对应平台，继承了相同的"DAO 基金创建→代币化→资产管理"三阶段模型，但机制细节不同：Base/Uniswap V3 生态 vs Solana 原生 DEX、单边流动性设计（防止即抛）、费用结构（1%交易费/0.4%经理分成 vs 不同参数）
- 补充 [[base]] — 作为 Base 生态的 DAO 基金发行平台，丰富了 Base 链上 Meme/DAO 发行基础设施
- 与 [[memecoins]] 的关联 — daos.world 试图通过基金净值机制为 memecoin 类代币提供"基础价值锚定"，是对 memecoin"无基本面"批评的结构性回应
- 与 [[fundraising]] 的关联 — 提供了一种新的加密融资模式：预售→Uniswap 上线→基金经理主动管理，介于 Fair Launch 和 VC 代币之间

## 我的笔记
这篇文章的关键洞见不在于 daos.world 本身（作为 daos.fun 的 Base 移植版），而在于它揭示了一种"反向 pump.fun"的机制设计：代币上线时仅有单边流动性（基金代币侧），阻止了预售参与者立即抛售——这与 pump.fun 的"任何人都可以在开盘瞬间买入卖出"形成结构性对立。这种设计强制性地延长了持有期，但有效性取决于是否有足够的外部 ETH 流动性进入资金池。

另外，作者通过"我个人认识开发者"来建立信任的方式，恰恰暴露了这个赛道最大的软肋——基金经理声誉和智能合约安全都无法规模化验证，只能依赖个人信任网络。这与 daos.fun 最终转向 AI Agent 基金管理的演化路径形成了有趣的对比：AI Agent 正是试图用"代码信任"替代"人际信任"的尝试。daos.world 如果停留在"你认识开发者你就投"的阶段，无法与 AI Agent 基金形成有效竞争。
