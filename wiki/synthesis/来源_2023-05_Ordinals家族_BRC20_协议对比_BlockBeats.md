# 梳理比特币上的Ordinals家族 -- Ordinals 协议及其衍生标准全景

## 阅读证据
- 总行数: 153
- Q1 (前25%): Ordinals 协议稀有度六层体系的具体数量：普通 Common 约 2100 万亿聪、不凡 Uncommon 每个区块首聪 6,929,999、稀有 Rare 每个难度调整期首聪 3,437、史诗 Epic 每次减半后首聪 32、传奇 Legendary 每个周期首聪 5、神话 Mythic 创世区块首聪 1
- Q3 (中后25%): Generative BRC-721 通过将 NFT 图像特征拆分为"零部件"（背景颜色、头部造型、脸部表情等）并上传索引说明书来发行，用户铸造时仅获取索引说明书而非完整图片，首个系列为 OrdiBots
- Q4 (最后25%): SRC-20 基于 STAMPS 协议，数据存储在 UTXO 中而非见证数据中，因此每个完整节点都必须存储它们，比 Ordinals 更"区块链原生"，但也更受限（最高 24x24 像素或 8 色深的图像）

## 核心要点
- Ordinals 协议通过为聪编号并附加数据使比特币支持 NFT，并提出六层稀有度分级（Common / Uncommon / Rare / Epic / Legendary / Mythic）
- BRC-20 是 Ordinals 上的首个同质化代币标准，采用统一 JSON 格式定义 deploy/mint/transfer，催生了 ORC-20（增强版）、BRC-21/BRC-42（跨链版）等衍生协议
- 非同质化代币方向：BRC-721 标准支持 Trait、IPFS 存储、与 ERC-721 兼容；Generative BRC-721 通过特征拆分组合大幅降低链上占用和成本
- SRC-20 基于 STAMPS 协议，数据存于 UTXO 而非见证数据，更加"区块链原生"但空间受限（24x24 像素 / 8 色深）
- LTC-20 和 DRC-20 是 BRC-20 在莱特币和狗狗币网络上的分叉，优势在于更低成本和更快交易速度，LTC-20 还有莱特币减半叙事加持（2023 年 8 月）

## 关键数据
- 普通聪总供应量约 2100 万亿；不凡 6,929,999；稀有 3,437；史诗 32；传奇 5；神话 1
- SRC-20/STAMPS 协议的技术上限：最高 24x24 像素或 8 色深的图像
- ORDI 代币 JSON 包含 5 个核心字段（op/tick/max/lim/amt），BRC-21 增加 src 和 id 两个跨链字段
- 莱特币预计 2023 年 8 月减半，为 LTC-20 带来叙事优势

## 值得记住的引用
> "Ordinals 协议可以简单理解为一个为聪（SATS）编号的系统，通过赋予每个聪一个序列号，然后再附加上额外的数据（文本、图片、代码等），也就是 NFT 中常说的「元数据」，使每个聪都变成独一无二的 NFT"

> "由于比特币网络本身不支持智能合约，上限区块容量的限制，像原生 Ordinals NFT 直接上传图片的方式发行对于项目和用户来说成本都非常高，将数据存储在链下服务器又有违去中心化的初衷，而 Generative BRC-721 提出一种完全去中心化的方式来解决这个问题"

> "对于 STAMPS 协议而言，由于信息存储在 UTXO 中，每个完整节点都必须存储它们，因此比 Ordinals 更加「区块链原生」"

## 我的笔记
本文是一篇高质量的入门级科普，以"家族树"框架清晰展示了 Ordinals 协议发布不到半年内的生态扩张。结构上按同质化代币、非同质化代币、衍生、分叉四大类组织，逻辑清晰。但作为 2023 年 5 月的文章，它记录的只是早期状态 -- 后续 Runes 协议的崛起、BRC-20 市场份额下滑等关键发展均未覆盖。文中提到的 LTC-20 减半叙事（2023 年 8 月）是当时独特的市场判断，现在回看可以作为检验叙事驱动型投资假设的案例。Generative BRC-721 的"特征拆分再组合"思路是链上 NFT 发行的创新实践，但其对生态的实际影响远不如后续的 Runes 协议。
