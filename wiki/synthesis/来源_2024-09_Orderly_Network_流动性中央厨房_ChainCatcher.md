## 核心要点
- Orderly Network 定位为全链流动性基础设施，明确表示"不是 DEX，而是为 DEX 服务的后端"——提供统一的链上订单簿、订单匹配引擎和结算层，任何开发者可基于其 SDK 在几小时内搭建一个共享全链流动性的 DEX。
- 核心隐喻是"流动性中央厨房"：Orderly 提供后端（流动性聚合、交易撮合、结算），开发者只需做好面向 C 端的前端页面和用户运营，类似于餐饮业的中央厨房模式。
- 与常见的跨链桥/跨链消息协议不同，Orderly 通过整合不同链上的订单信息到统一订单簿，创建了跨链流动性生态系统；其结算层 Orderly Chain 基于 OP Stack + Celestia DA + LayerZero 跨链技术构建。
- ORDER 代币是实用性代币，核心价值捕获机制为：网络 60% 的新增收入以 USDC 形式分配给 ORDER 质押用户——这在 DeFi 领域较为罕见，是真正将收入赋能代币持有人的设计。
- ORDER 代币已于 8 月 26 日 TGE，以 $0.02 开盘最高冲至 $0.27（涨幅超 1000%），空投 9200 万枚给约 23 万个地址。加密交易员 DeFiSquared 认为 ORDER 市值为 2500 万美元/完全稀释估值 1.55 亿美元，存在错误定价，被市场低估。
- 生态已初具规模：支持的 DEX 超过 20 个（WooFi、LogX、EMDX、Elixir、Vooi 等），AscendEX 等 CEX 也通过集成 Orderly 提供链上 DEX 服务，形成了独有的"B 端基础设施 + C 端触点多样化"护城河。

## 我的笔记
这是一篇典型的项目 PR 稿（ChainCatcher + 项目方合作内容），但在当前时点（2024 年 9 月）具有特殊价值：它呈现了一个 DeFi 项目在 TGE 前后的完整状态快照——既有"发币前已实现自主盈利"的罕见叙事（$740 万净收入），也有发币后可能面临的 TVL/收入下降风险（参考 entity page 中的已有观察）。"中央厨房"模式本质上是一种 B2B2C 策略：用基础设施服务 B 端 DEX 开发者，再通过他们触达 C 端用户，跳过了自己获客的高成本。这个模式能否持续取决于两个条件：(1) Orderly 能否保持流动性深度上的竞争优势对抗 Hyperliquid 的社区做市模式和 dYdX 的全链订单簿；(2) 生态内的 DEX 能否真正产生差异化的用户价值，而非仅仅成为同一流动性的不同 UI 皮肤。"60% 收入以 USDC 分配给质押者"的设计在 DeFi 中确实少见——它把治理代币变成了类似股权的现金流分配工具，但这在监管层面也是更危险的信号。
