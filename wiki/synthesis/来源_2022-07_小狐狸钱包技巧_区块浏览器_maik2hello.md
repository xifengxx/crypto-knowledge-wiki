# 小狐狸钱包（MetaMask）使用技巧与区块链浏览器入门

## 核心要点
- MetaMask 钱包的语言设置、助记词管理、测试网络开关等基础配置步骤
- MetaMask 内置兑换功能收取约1%手续费，滑点调节（1%-3%区间）是减少无常损失的关键技巧
- 链上交易卡顿（nonce 未完成）时，可通过自定义交易 nonce（+1跳过）的方式强制清除卡滞交易
- 推荐使用 EVM Box (networks.vercel.app) 自动添加 MetaMask 支持的各种 EVM 网络
- 区块链浏览器（以 polygonscan 为例）可查询任意钱包的持币情况、交易时间线、代币来源与去向
- 通过合约地址检索代币信息，包括总供应量、持币地址数、价格、24小时涨跌、市值、精度、官网和社交媒体
- 区块链浏览器的"Transactions"页面可查看每种代币的详细交易记录：哈希值、区块高度、时间、Gas 消耗、ERC-20/ERC-721/ERC-1155 分类

## 关键数据
- MetaMask 内置兑换手续费: 约1%（通过兑换功能兑换代币时收取）
- 滑点建议范围: 1%-3%之间（百分比越高成功率越高，但损失越大）
- 区块浏览器中代币类型分类: ERC-20（同质化代币）、ERC-721（NFT）、ERC-1155（半同质化代币/NFT）
- EVM 网络自动添加网站: networks.vercel.app（EVM Box 工具）

## 我的笔记
本文是一篇面向加密新手的 MetaMask 实操教程，核心价值在于教用户如何使用 nonce 机制解决链上交易卡顿问题（这在大多数官方教程中很少提及）以及如何利用区块浏览器的持币地址分布数据做基础链上分析。但文章内容较为浅显，对于有一定链上操作经验的用户来说大部分内容属于基础常识；文章发表于2022年7月，距今已四年，部分 UI 截图可能已经过时。此外，文章提到的 EVM Box (networks.vercel.app) 和具体 UI 界面路径可能已随 MetaMask 版本更新而变化。
