# Web3 全栈开发指南

## 核心要点

1. DApp 完整架构四层：智能合约（Solidity）→ 前端 UI（HTML/JS/React）→ 数据聚合（The Graph）→ 钱包签名（MetaMask/Ethers.js）。节点提供原始日志，The Graph 将日志聚合为可查询的结构化数据

2. 技术栈：Solidity + JavaScript/TypeScript + Hardhat（合约工具）+ Ethers.js（合约交互）+ The Graph（数据索引）+ Web3Modal（多钱包支持）

3. DApp 开发流程：编写合约 → Hardhat 编译 → 部署到链（Polygon 测试网为例）→ 开发 UI → 集成钱包签名 → 创建 Graph 子图实现数据查询 → 发布到 GitHub Pages

## 关键数据
- 核心技能：Solidity + JavaScript + TypeScript + HTML/CSS（4 种语言）
- The Graph 替代自建后端——无需自己租服务器+数据库
- Uniswap 创始人 Hayden 原本是前端开发者，17 年失业后自学 Solidity 创建了 Uniswap

## 我的笔记
这是 Web3 开发的完整入门教程。核心洞察：Web3 "后端"不是传统数据库，是 The Graph 这样的数据索引服务。这解释了为什么 The Graph 有真实 PMF——它是 DApp 开发的刚需组件。

从开发角度看，Web3 全栈的门槛比 Web2 高——需要同时掌握 Solidity + JS/TS + 前端 + 钱包交互。Hayden 的 Uniswap 故事是激励性的：一个前端在几个月内就能创建改变 DeFi 格局的产品。但这在 2026 年已经几乎不可能了——现在创建有竞争力的 DApp 需要团队+审计+流动性引导，不再是个人开发者能做的事。
