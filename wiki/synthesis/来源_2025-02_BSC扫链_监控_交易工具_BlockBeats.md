# BSC 链上工具全景：从扫链、聪明钱监控到交易

## 阅读证据
- 总行数: 290
- Q1 (前25%): BSC 上的 pump 平台是 Four.meme，可在 Board 页面按条件筛选内盘币，Ranking 页面查看市值/交易量榜。UniversalX 是 Particle Network 首个官方应用，支持 BSC 和其他13条 EVM 链。
- Q3 (中后25%): debot 的钱包分组行为监控可实现"30分钟内5个不同地址买入再推送"策略，大幅减少推送噪音。Ave 的 Top 交易者仅列出 Top15 盈利地址，数据有限。
- Q4 (最后25%): UniversalX 针对主流币交易手续费已降至千一（0.1%），与 CEX 一致，且因 Binance Labs 投资有发币空投预期。EVN 链安全检查推荐 goplus、honeypot.is、tokensniffer 三款工具配合使用。

## 核心要点
1. BSC 链 meme 生态正由 CZ 亲自推动（喊单 $TST、提及宠物狗），Four.meme 是 BSC 上的核心 pump 平台，Ave 已专门为 Four.meme 做了独立版块支持扫链。
2. UniversalX（Particle Network 产品）提供链无关的资产交易体验，无需手动桥接和管理 Gas，支持移动端，交易速度极快且自动防夹。
3. 聪明钱发现可借用 ETH/BASE 链的聪明钱在 BSC 上的活跃度，debot 和 gmgn 是分析聪明钱行为的最佳工具——均提供 Top 持仓和 Top 收益地址分类标签。
4. 聪明钱监控的核心需求是消息降噪：debot 的"分组行为监控"允许设定多地址阈值触发推送，解决了传统监控工具消息过多的问题。
5. EVM 链最大的风险是貔貅盘，买入前必须用 goplus、honeypot.is、tokensniffer 等多款安全检查工具交叉验证。
6. BSC 链交易工具有多种选择：UniversalX（链无关/快/发币预期）、debot（多池子显示）、gmgn（数据集成）、OKX（多平台）、PinkPunk TG bot（挂单/狙击）。

## 关键数据
- UniversalX 支持 BSC + Solana + 其他13条主流 EVM 链，共15条链
- UniversalX 主流币交易手续费降至 0.1%（千一），与 CEX 一致
- Ave 的 Top 交易者仅列出 Top15 盈利地址
- PinkPunk 是 TG bot，支持挂单和狙击功能
- 文章推荐的安全工具组合：goplus（Binance Labs 投资）+ honeypot.is + tokensniffer 三款交叉验证
